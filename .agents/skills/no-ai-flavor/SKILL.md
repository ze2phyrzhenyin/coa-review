# 去 AI 味

AI 味是没人做过的选择：最常见的词、最常见的句式、最常见的版式。单个出现不一定有问题，扎堆出现就是。

## 用法

- 写或改文字：按下面的规则写，交付前逐句自查。
- 做网页或界面：再读 `references/design.md`。
- 法语或英语：再读 `references/fr-en.md`。
- 项目里有页面或源码：跑 `node <本目录>/scripts/lint-copy.mjs <dist 或 src>`。error 清零；warn 逐条看，是事实就留。
- 改已有的文字：保留所有事实，不加没有来源的事实、数字、名字。缺信息就问，或者写一句更简单的。用户自己写的字，只给建议，不擅自改。
- 交付只给改好的文字，不附「改了什么」，除非被问。

## 结构

1. 不写副标题。一个区块最多一个标题；标题说不清就换标题，不在下面补一行解释。
2. 不加眉标：标题上方或旁边的小号、大写、加字距标签。不用另一种语言做装饰。
3. 不数数：「5 种方式」「三大优势」。用户看得见有几个。
4. 列表和卡片不配描述，除非描述里有标题没有的事实：数量、时长、价格、进度、条件。
5. 事实后面不再加一句解释它的意义或好处。段落不用一句复述收尾。
6. 标题下的第一句不重复标题。
7. 不放没意义的数字：0、无法核实的统计、凑满一排的指标、「+500 位满意客户」。
8. 不写「为什么选择我们」「我们的使命」「核心价值」这类区块。价值用事实证明。

## 句式

出现就改：

- 三段式：先…再…最后…；快速、简单、可靠；三个并列的形容或例子。真有三项就留。
- 逗号切开的两段口号：先回想，再翻面；近义，也有不同；先看见，再决定；简单，却不简单。
- 对比和否定：不是 X，而是 Y；不只是 X，更是 Y；与其 X，不如 Y；不止于 X；换一种方式 X。只有读者真的这么以为时，才保留否定的那一半。
- 格言腔：X 是 Y 的语言；真正重要的是；本质上。换成具体的说法。
- 承诺句：让 X 更 Y；只需 X，即可 Y；每一个 X 都值得 Y；从此告别 X。
- 寒暄和拟人：以「今天，」「现在，」开头；让我们；为你；欢迎来到；一起；陪你。
- 设问：还在为 X 发愁？想要 X 吗？标题不用问句。
- 冒号标语：X：让 Y 更简单。
- 跟空气辩论：这并不是说；有人可能会觉得。没人提出的反对，不用回应。
- 夸大意义：彰显、诠释、见证、承载、赋予、标志着、扮演…角色、发挥…作用、至关重要、不可或缺、意义深远。用「是」「有」「做」。
- 聊天残留：希望对你有帮助、当然可以、综上所述、总的来说、值得一提的是、众所周知、随着…的发展、在这个…的时代。
- 写文档本身而不写内容：本文将介绍、下表对比了、本节按…排列。

## 词

不用：赋能、一站式、为您、让我们、打造、极致、完美、无缝、助力、引领、沉浸式、全新升级、一键、专属、匠心、臻选、尊享、震撼、惊艳、解锁、海量、精心打造、有温度、新可能、更好的自己、值得信赖、智能（「智能手机」这类产品名除外）。

少用，用前想一下：轻松、高效、便捷、探索、旅程、开启、独特的、丰富的、优质、贴心、用心、美好、精彩、质感、高级感、仪式感。

完整词表（中、法、英，分 error 和 warn）在 `scripts/phrases.json`。

## 符号

不用感叹号、emoji、破折号（——、—）、段落里的加粗、装饰箭头（→）、给普通词加引号。

## 怎么写

- 标题用名词，按钮用「动词 + 对象」，2 到 6 个字。
- 能写数字、名称、单位、日期、地点、人名，就不写形容词。写「710 张词卡」，不写「海量词卡」。
- 说明只放在用户会卡住的地方，一句，说怎么做，不说为什么好。
- 界面语言统一；外文只出现在内容本身：例句、单词、品牌名。
- 宁可留空也不凑字。一个区块只有一个元素也可以。
- 回复和说明：先给结论，只留读者缺的那一条理由。

## 自查

逐句过一遍：

1. 删掉这句，读者少知道了什么？说不出来就删。
2. 这句原样放到别的产品、别的公司上也成立吗？成立就换成只属于这里的事实，或者删。
3. 有没有命中上面的句式、词、符号？有就改。改完再查一遍，最容易留下来的是「不是…而是…」、收尾复述、三段式、破折号。

| 翻面词卡 / 先回想，再翻面 | 翻面词卡　已练 12 / 710 |
| 易混词辨析 / 近义，也有不同 | 易混词辨析 |
| 0 已练词卡 | 练过之前不显示 |

| 还在为背单词发愁？ | 删 |

## 什么时候不改

- 引文、产品名、专有名词、法律和安全声明。
- 真的操作步骤：「先选文件，再点导出」是说明，不是口号。
- 真有三项的列举：配料、导航、规格。
- 用户要求原样保留的文字。
