## 讲解：例题 LAD（网址 /5-cycle）

### 条件
- 字长：8 位，寄存器、数存单元和地址都在 0–255，数按十进制写
- 时序：一个 CPU 周期含 T1–T4 四个节拍；电位信号保持整个 CPU 周期，打入在 T3 或 T4
- PC：起始地址 32，每取一条指令加 1
- 通用寄存器：R0=5，R1=25，R2=3，R3=14
- 数存：9 号 48，10 号 7，14 号 60，15 号 91；没列出的单元读出 0
- 信号名：教材的写法（LDIR、LDAR、LDDR、RD(D)、WE(D)）
- 停机：PC 指到没有指令的单元，或执行满 1 条指令
- 四条总线：ABUS(I)：PC 送指令地址到指存；IBUS：指存读出的指令送 IR；DBUS：其余的数和地址都走它；ABUS(D)：AR 送数据地址到数存。指存和数存是两个存储器
- 三态门：能往 DBUS 送数的部件各有一道门：C1 管 ALU 的输出，C2 管通用寄存器的输出（不经 ALU），C3 管 IR 的地址码。门关着时输出是高阻，同一时刻最多开一道，数存读出也算一个来源
- 信号名：LDxx 把总线上的数打入寄存器 xx（脉冲，注节拍）；RD、C1–C3 是电位信号，从 T1 起保持整个 CPU 周期。选哪个通用寄存器由 IR 的寄存器字段决定，教材不给信号名，解析书写 LRi
- 为什么在 T3、T4 打入：电位信号在 T1 打开通路，数要在总线上稳定一段时间才能打入。DR 在 T3 打入，T4 才能再从 DR 打入通用寄存器；AR、PC 和通用寄存器在 T4 打入，是这个 CPU 周期的最后一拍；数存写入 WE(D) 在 T3（图 5.30）
- 操作数的先后：MOV Rx,Ry：Ry→Rx；NOT Rx,Ry：Ry 取反→Rx；ADD Rx,Ry：Rx+Ry→Ry；LAD Rx,A：数存 A→Rx；STO Rx,(Ry)：Rx→数存 (Ry)；JMP A：A→PC

## 讲解：例题 STO（网址 /5-cycle?ins=STO）

### 条件
- 字长：8 位，寄存器、数存单元和地址都在 0–255，数按十进制写
- 时序：一个 CPU 周期含 T1–T4 四个节拍；电位信号保持整个 CPU 周期，打入在 T3 或 T4
- PC：起始地址 32，每取一条指令加 1
- 通用寄存器：R0=5，R1=25，R2=3，R3=14
- 数存：9 号 48，10 号 7，14 号 60，15 号 91；没列出的单元读出 0
- 信号名：教材的写法（LDIR、LDAR、LDDR、RD(D)、WE(D)）
- 停机：PC 指到没有指令的单元，或执行满 1 条指令
- 四条总线：ABUS(I)：PC 送指令地址到指存；IBUS：指存读出的指令送 IR；DBUS：其余的数和地址都走它；ABUS(D)：AR 送数据地址到数存。指存和数存是两个存储器
- 三态门：能往 DBUS 送数的部件各有一道门：C1 管 ALU 的输出，C2 管通用寄存器的输出（不经 ALU），C3 管 IR 的地址码。门关着时输出是高阻，同一时刻最多开一道，数存读出也算一个来源
- 信号名：LDxx 把总线上的数打入寄存器 xx（脉冲，注节拍）；RD、C1–C3 是电位信号，从 T1 起保持整个 CPU 周期。选哪个通用寄存器由 IR 的寄存器字段决定，教材不给信号名，解析书写 LRi
- 为什么在 T3、T4 打入：电位信号在 T1 打开通路，数要在总线上稳定一段时间才能打入。DR 在 T3 打入，T4 才能再从 DR 打入通用寄存器；AR、PC 和通用寄存器在 T4 打入，是这个 CPU 周期的最后一拍；数存写入 WE(D) 在 T3（图 5.30）
- 操作数的先后：MOV Rx,Ry：Ry→Rx；NOT Rx,Ry：Ry 取反→Rx；ADD Rx,Ry：Rx+Ry→Ry；LAD Rx,A：数存 A→Rx；STO Rx,(Ry)：Rx→数存 (Ry)；JMP A：A→PC

## 讲解：例题 JMP（网址 /5-cycle?ins=JMP）

### 条件
- 字长：8 位，寄存器、数存单元和地址都在 0–255，数按十进制写
- 时序：一个 CPU 周期含 T1–T4 四个节拍；电位信号保持整个 CPU 周期，打入在 T3 或 T4
- PC：起始地址 32，每取一条指令加 1
- 通用寄存器：R0=5，R1=25，R2=3，R3=14
- 数存：9 号 48，10 号 7，14 号 60，15 号 91；没列出的单元读出 0
- 信号名：教材的写法（LDIR、LDAR、LDDR、RD(D)、WE(D)）
- 停机：PC 指到没有指令的单元，或执行满 1 条指令
- 四条总线：ABUS(I)：PC 送指令地址到指存；IBUS：指存读出的指令送 IR；DBUS：其余的数和地址都走它；ABUS(D)：AR 送数据地址到数存。指存和数存是两个存储器
- 三态门：能往 DBUS 送数的部件各有一道门：C1 管 ALU 的输出，C2 管通用寄存器的输出（不经 ALU），C3 管 IR 的地址码。门关着时输出是高阻，同一时刻最多开一道，数存读出也算一个来源
- 信号名：LDxx 把总线上的数打入寄存器 xx（脉冲，注节拍）；RD、C1–C3 是电位信号，从 T1 起保持整个 CPU 周期。选哪个通用寄存器由 IR 的寄存器字段决定，教材不给信号名，解析书写 LRi
- 为什么在 T3、T4 打入：电位信号在 T1 打开通路，数要在总线上稳定一段时间才能打入。DR 在 T3 打入，T4 才能再从 DR 打入通用寄存器；AR、PC 和通用寄存器在 T4 打入，是这个 CPU 周期的最后一拍；数存写入 WE(D) 在 T3（图 5.30）
- 操作数的先后：MOV Rx,Ry：Ry→Rx；NOT Rx,Ry：Ry 取反→Rx；ADD Rx,Ry：Rx+Ry→Ry；LAD Rx,A：数存 A→Rx；STO Rx,(Ry)：Rx→数存 (Ry)；JMP A：A→PC

## 讲解：例题 NOT（网址 /5-cycle?ins=NOT）

### 条件
- 字长：8 位，寄存器、数存单元和地址都在 0–255，数按十进制写
- 时序：一个 CPU 周期含 T1–T4 四个节拍；电位信号保持整个 CPU 周期，打入在 T3 或 T4
- PC：起始地址 32，每取一条指令加 1
- 通用寄存器：R0=5，R1=25，R2=3，R3=14
- 数存：9 号 48，10 号 7，14 号 60，15 号 91；没列出的单元读出 0
- 信号名：教材的写法（LDIR、LDAR、LDDR、RD(D)、WE(D)）
- 停机：PC 指到没有指令的单元，或执行满 1 条指令
- 四条总线：ABUS(I)：PC 送指令地址到指存；IBUS：指存读出的指令送 IR；DBUS：其余的数和地址都走它；ABUS(D)：AR 送数据地址到数存。指存和数存是两个存储器
- 三态门：能往 DBUS 送数的部件各有一道门：C1 管 ALU 的输出，C2 管通用寄存器的输出（不经 ALU），C3 管 IR 的地址码。门关着时输出是高阻，同一时刻最多开一道，数存读出也算一个来源
- 信号名：LDxx 把总线上的数打入寄存器 xx（脉冲，注节拍）；RD、C1–C3 是电位信号，从 T1 起保持整个 CPU 周期。选哪个通用寄存器由 IR 的寄存器字段决定，教材不给信号名，解析书写 LRi
- 为什么在 T3、T4 打入：电位信号在 T1 打开通路，数要在总线上稳定一段时间才能打入。DR 在 T3 打入，T4 才能再从 DR 打入通用寄存器；AR、PC 和通用寄存器在 T4 打入，是这个 CPU 周期的最后一拍；数存写入 WE(D) 在 T3（图 5.30）
- 操作数的先后：MOV Rx,Ry：Ry→Rx；NOT Rx,Ry：Ry 取反→Rx；ADD Rx,Ry：Rx+Ry→Ry；LAD Rx,A：数存 A→Rx；STO Rx,(Ry)：Rx→数存 (Ry)；JMP A：A→PC

## 讲解：例题 程序（网址 /5-cycle?ins=prog）

（评测员补：程序清单只画在场景的指存部件上，文字区没有。从场景读出：32 LAD R0,9；33 ADD R0,R1；34 STO R1,(R3)；35 JMP 37；36 NOT R1,R0；37 MOV R2,R1。）

### 条件
- 字长：8 位，寄存器、数存单元和地址都在 0–255，数按十进制写
- 时序：一个 CPU 周期含 T1–T4 四个节拍；电位信号保持整个 CPU 周期，打入在 T3 或 T4
- PC：起始地址 32，每取一条指令加 1
- 通用寄存器：R0=5，R1=25，R2=3，R3=14
- 数存：9 号 48，10 号 7，14 号 60，15 号 91；没列出的单元读出 0
- 信号名：教材的写法（LDIR、LDAR、LDDR、RD(D)、WE(D)）
- 停机：PC 指到没有指令的单元，或执行满 8 条指令
- 四条总线：ABUS(I)：PC 送指令地址到指存；IBUS：指存读出的指令送 IR；DBUS：其余的数和地址都走它；ABUS(D)：AR 送数据地址到数存。指存和数存是两个存储器
- 三态门：能往 DBUS 送数的部件各有一道门：C1 管 ALU 的输出，C2 管通用寄存器的输出（不经 ALU），C3 管 IR 的地址码。门关着时输出是高阻，同一时刻最多开一道，数存读出也算一个来源
- 信号名：LDxx 把总线上的数打入寄存器 xx（脉冲，注节拍）；RD、C1–C3 是电位信号，从 T1 起保持整个 CPU 周期。选哪个通用寄存器由 IR 的寄存器字段决定，教材不给信号名，解析书写 LRi
- 为什么在 T3、T4 打入：电位信号在 T1 打开通路，数要在总线上稳定一段时间才能打入。DR 在 T3 打入，T4 才能再从 DR 打入通用寄存器；AR、PC 和通用寄存器在 T4 打入，是这个 CPU 周期的最后一拍；数存写入 WE(D) 在 T3（图 5.30）
- 操作数的先后：MOV Rx,Ry：Ry→Rx；NOT Rx,Ry：Ry 取反→Rx；ADD Rx,Ry：Rx+Ry→Ry；LAD Rx,A：数存 A→Rx；STO Rx,(Ry)：Rx→数存 (Ry)；JMP A：A→PC

- 变化：
  - DBUS 的驱动者：空 → R1
  - DBUS 上的数：空 → 73
  - 三态门 C2：关 → 开
  - 电位信号：空 → C2
- 题目：数据 73 在 DBUS 上，地址 14 在 AR 里。T3 由哪个部件接收
  - 说明：点场景里的部件作答。
  - 作答：点选；按钮：看答案
### 第 40 步
（第 40 步，共 41 步，一个节拍）
- 舞台读数：执行二周期 T3 C2 WE(D)
- 标题：DBUS → 数存（AR 指定的单元）
- 为什么：T3 发数存写命令 WE(D)。它是脉冲信号（例 5.3 写成 M3·T3·STO）：地址和要写的数先在线上稳定，T3 才写，读命令 RD(D) 则从周期开始就有效，好让数存有时间读出。DBUS 上的 73 写进数存 14 号单元，原来的 60 被盖掉。写数存不经过 DR。教材 p158–159 图 5.11
- 变化：
  - 数存 14 号单元：60 → 73
  - 脉冲信号：空 → WE(D)
  - 节拍：T1 → T3
### 第 41 步
（第 41 步，共 41 步，一条指令）
- 舞台读数：停机
- 标题：停机，PC = 35
- 为什么：指存 35 号单元没有指令，程序到此结束。这台模型机没有停机指令，这里按人为停机处理。最后一个 CPU 周期的信号撤掉，总线空出来。教材 p160，p161
- 变化：
  - ABUS(D) 的驱动者：AR → 空
  - ABUS(D) 上的数：14 → 空
  - DBUS 的驱动者：R1 → 空
  - DBUS 上的数：73 → 空
  - 三态门 C2：开 → 关
  - 停机：否 → 是
  - 右路选中的寄存器（送 ALU 右输入，也接 C2 的输入端）：R1 → 空
  - 电位信号：C2 → 空
  - 脉冲信号：WE(D) → 空
  - 节拍：T3 → 空
  - CPU 周期：执行二 → 空
  - 第几个 CPU 周期：3 → 0
  - 本条指令的 CPU 周期数：3 → 0
