## 例题：LAD

### 条件
- 字长：8 位，寄存器、数存单元和地址都在 0–255，数按十进制写
- 时序：一个 CPU 周期含 T1–T4 四个节拍；电位信号保持整个 CPU 周期，打入在 T3 或 T4
- PC：起始地址 32，每取一条指令加 1
- 通用寄存器：R0=5，R1=25，R2=3，R3=14
- 数存：9 号 48，10 号 7，14 号 60，15 号 91；没列出的单元读出 0
- 信号名：教材的写法（LDIR、LDAR、LDDR、RD(D)、WE(D)）
- 停机：PC 指到没有指令的单元，或执行满 1 条指令

### 第 0 步
标题：初始状态
题目：LAD R0,9（数存 9 号单元 → R0）的指令周期有几个 CPU 周期
作答：输入框填一个数，回车或「确定」
另有「看答案」。
答错时显示：不对。数一数这条指令要让 DBUS 送几次数，每次占一个 CPU 周期，另加取指的一个。

### 第 1 步
第 1 步，共 14 步（一条指令）
标题：第 1 条指令 LAD R0,9：数存 9 号单元 → R0
为什么：PC 指着指存 32 号单元。LAD 访问一次指存、一次数存，地址和数据又都要走 DBUS，指令周期是 3 个 CPU 周期：取指、送地址、取数。教材 p156 图 5.7
变化：本条指令的地址：空 → 32；本条指令的 CPU 周期数：0 → 3；第几条指令：0 → 1

### 第 2 步
舞台读数：取指周期
第 2 步，共 14 步（一个 CPU 周期）
标题：取指周期
为什么：每条指令的第一个 CPU 周期都相同：按 PC 从指存取出指令装入 IR，PC 加 1，对操作码译码。这条通路走 ABUS(I) 和 IBUS，不占 DBUS。一个 CPU 周期有 T1 到 T4 四个节拍。教材 p154 图 5.5，节拍见 p178 图 5.30
变化：CPU 周期：空 → 取指；第几个 CPU 周期：0 → 1

### 第 3 步
舞台读数：取指周期  T1  RD(I)
第 3 步，共 14 步（一个节拍）
标题：PC → ABUS(I) → 指存
为什么：PC 的内容 32 直通 ABUS(I)，指存按这个地址译码。RD(I) 是指存读命令，电位信号，整个取指周期保持有效。教材 p154 图 5.5，节拍见 p178 图 5.30
变化：ABUS(I) 的驱动者：空 → PC；ABUS(I) 上的数：空 → 32；电位信号：空 → RD(I)；节拍：空 → T1
题目：指存读出的指令经哪条总线进 IR
作答：点场景里的部件
另有「看答案」。
答错时显示：不对。看指存的数据端接在哪条总线上，它和数存是分开的。

### 第 4 步
舞台读数：取指周期  T3  RD(I) LDIR
第 4 步，共 14 步（一个节拍）
标题：指存 → IBUS → IR
为什么：指存 32 号单元读出的 LAD R0,9 已在 IBUS 上稳定，T3 发 LDIR 把它打入 IR。取指令走 IBUS，DBUS 空着。教材 p154 图 5.5，节拍见 p178 图 5.30
变化：IBUS 的驱动者：空 → 指存；IBUS 上的数：空 → LAD R0,9；IR 操作码：空 → LAD；IR 地址码：空 → R0,9；脉冲信号：空 → LDIR；节拍：T1 → T3

### 第 5 步
舞台读数：取指周期  T4  RD(I) PC+1 LDPC
第 5 步，共 14 步（一个节拍）
标题：PC + 1
为什么：T4 发 PC+1 和 LDPC，PC 由 32 变成 33，指向下一条指令。PC 自带加 1 功能，这一步不经过 ALU 和 DBUS。教材 p154 图 5.5，节拍见 p178 图 5.30
变化：PC：32 → 33；脉冲信号：LDIR → PC+1；脉冲信号：空 → LDPC；节拍：T3 → T4

### 第 6 步
舞台读数：取指周期  T4  RD(I) PC+1 LDPC
第 6 步，共 14 步（讲解步）
标题：IR 的操作码 → 指令译码器
为什么：指令译码器认出这是 LAD，操作控制器据此决定后面发哪些控制信号。译码依附在取指周期的末尾，不另占 CPU 周期。LAD 的执行周期有 2 个 CPU 周期。教材 p154，译码不占 CPU 周期见 p161
变化：指令译码器：空 → LAD

### 第 7 步
舞台读数：执行一周期
第 7 步，共 14 步（一个 CPU 周期）
标题：执行周期的第 1 个 CPU 周期：送操作数地址
为什么：译码认出 LAD。读数存要给出地址，地址 9 在 IR 的地址码字段里，要经 DBUS 送进 AR。DBUS 同一时刻只能有一个数，这个 CPU 周期它被地址占着，数据只能等下一个 CPU 周期。教材 p156–157 图 5.8
变化：ABUS(I) 的驱动者：PC → 空；ABUS(I) 上的数：32 → 空；IBUS 的驱动者：指存 → 空；IBUS 上的数：LAD R0,9 → 空；电位信号：RD(I) → 空；脉冲信号：PC+1 → 空；脉冲信号：LDPC → 空；节拍：T4 → 空；CPU 周期：取指 → 执行一；第几个 CPU 周期：1 → 2

### 第 8 步
舞台读数：执行一周期  T1  C3
第 8 步，共 14 步（一个节拍）
标题：IR 的地址码 → C3 → DBUS
为什么：打开 IR 输出端的三态门 C3，地址码字段里的直接地址 9 上了 DBUS。C1、C2 和数存的读出端都关着。这时 DBUS 上是地址，数存的数还不能上来。教材 p156–157 图 5.8
变化：DBUS 的驱动者：空 → IR；DBUS 上的数：空 → 9；三态门 C3：关 → 开；电位信号：空 → C3；节拍：空 → T1
题目：地址码 9 在 DBUS 上，T4 把它打入哪个寄存器
作答：点场景里的部件（题目下另有按钮：DR、PC，另有「看其余部件」）
另有「看答案」。
答错时显示：不对。想一想访问数存时，地址由哪个寄存器保持。

### 第 9 步
舞台读数：执行一周期  T4  C3 LDAR
第 9 步，共 14 步（一个节拍）
标题：DBUS → AR
为什么：T4 发 LDAR，DBUS 上的地址 9 打入 AR。AR 把地址保持住，下一个 CPU 周期 DBUS 才能腾出来送数据。教材 p156–157 图 5.8
变化：AR：空 → 9；脉冲信号：空 → LDAR；节拍：T1 → T4
题目：地址 9 已经在 AR 里。下一个 CPU 周期数存读出的数上了 DBUS，由哪个部件接收
作答：点场景里的部件（题目下另有按钮：DR、PC，另有「看其余部件」）
另有「看答案」。
答错时显示：不对。看 DBUS 和通用寄存器之间有没有直接的连线。

### 第 10 步
舞台读数：执行二周期
第 10 步，共 14 步（一个 CPU 周期）
标题：执行周期的第 2 个 CPU 周期：取出操作数
为什么：上一个 CPU 周期的 C3 已经撤掉，DBUS 空出来了。AR 里有地址，数存读出的数可以上 DBUS，经 DR 装入 R0。教材 p156–157 图 5.8
变化：DBUS 的驱动者：IR → 空；DBUS 上的数：9 → 空；三态门 C3：开 → 关；电位信号：C3 → 空；脉冲信号：LDAR → 空；节拍：T4 → 空；CPU 周期：执行一 → 执行二；第几个 CPU 周期：2 → 3

### 第 11 步
舞台读数：执行二周期  T1  RD(D)
第 11 步，共 14 步（一个节拍）
标题：AR → ABUS(D) → 数存 → DBUS
为什么：AR 的地址 9 经 ABUS(D) 送到数存。RD(D) 是数存读命令，电位信号，整个 CPU 周期有效，9 号单元的 48 读出到 DBUS。C1、C2、C3 都关着，DBUS 上只有数存一个来源。教材 p156–157 图 5.8
变化：ABUS(D) 的驱动者：空 → AR；ABUS(D) 上的数：空 → 9；DBUS 的驱动者：空 → 数存；DBUS 上的数：空 → 48；电位信号：空 → RD(D)；节拍：空 → T1

### 第 12 步
舞台读数：执行二周期  T3  RD(D) LDDR
第 12 步，共 14 步（一个节拍）
标题：DBUS → DR
为什么：T3 发 LDDR，DBUS 上的 48 打入 DR。数存读出的数和 ALU 的结果一样，要过 DR 才能进通用寄存器。教材 p156–157 图 5.8
变化：DR：空 → 48；脉冲信号：空 → LDDR；节拍：T1 → T3

### 第 13 步
舞台读数：执行二周期  T4  RD(D) LDR0
第 13 步，共 14 步（一个节拍）
标题：DR → R0
为什么：操作控制器按 IR 的寄存器字段选中 R0 作目标，T4 发 LDR0，DR 里的 48 打入 R0，原来的 5 被盖掉。教材 p156–157 图 5.8
变化：R0：5 → 48；接收 DR 的寄存器：空 → R0；脉冲信号：LDDR → LDR0；节拍：T3 → T4

### 第 14 步
舞台读数：停机
第 14 步，共 14 步（一条指令）
标题：停机，PC = 33
为什么：指存 33 号单元没有指令，程序到此结束。这台模型机没有停机指令，这里按人为停机处理。最后一个 CPU 周期的信号撤掉，总线空出来。教材 p160，p161
变化：ABUS(D) 的驱动者：AR → 空；ABUS(D) 上的数：9 → 空；DBUS 的驱动者：数存 → 空；DBUS 上的数：48 → 空；停机：否 → 是；接收 DR 的寄存器：R0 → 空；电位信号：RD(D) → 空；脉冲信号：LDR0 → 空；节拍：T4 → 空；CPU 周期：执行二 → 空；第几个 CPU 周期：3 → 0；本条指令的 CPU 周期数：3 → 0

### 第 11 步
舞台读数：执行周期  T3  C1 LDDR

- 时序：一个 CPU 周期含 T1–T4 四个节拍；电位信号保持整个 CPU 周期，打入在 T3 或 T4
- PC：起始地址 32，每取一条指令加 1
- 通用寄存器：R0=5，R1=25，R2=3，R3=14
- 数存：9 号 48，10 号 7，14 号 60，15 号 91；没列出的单元读出 0
- 信号名：教材的写法（LDIR、LDAR、LDDR、RD(D)、WE(D)）
- 停机：PC 指到没有指令的单元，或执行满 1 条指令

标题：第 1 条指令 MOV R2,R1：R1 → R2
为什么：PC 指着指存 32 号单元。MOV 只在通用寄存器之间传数，DBUS 只送一次，指令周期是 2 个 CPU 周期：取指、执行。教材 p154 图 5.4，p162 图 5.15

标题：指存 → IBUS → IR

变化：ALU 的功能：传送 → 空；ALU 的输出：25 → 空；DBUS 的驱动者：ALU → 空；DBUS 上的数：25 → 空；三态门 C1：开 → 关；停机：否 → 是；ALU 左输入选的寄存器：R1 → 空；接收 DR 的寄存器：R2 → 空；电位信号：C1 → 空；脉冲信号：LDR2 → 空；节拍：T4 → 空；CPU 周期：执行 → 空；第几个 CPU 周期：2 → 0；本条指令的 CPU 周期数：2 → 0

- LAD 第 11 步「弄坏它：再打开 C2」：DBUS 上已有 数存 送来的 48，又打开三态门 C2，让 R0 送 5：两个数有 4 位不同，这几根线被一头拉高一头拉低，两个输出端之间流过很大的电流，线上的电平不确定，接收的寄存器打入的数不可信，器件还可能过热损坏。
