## 问题

### 中

1. 流水线的一个时钟周期，步骤旁的粒度标签写成「一个 CPU 周期」。`/5-spacetime?s=2` 到 `?s=10` 每一步都是。教材里 CPU 周期是含 T1–T4 的机器周期，流水线这里是时钟周期；页面正文、题面、结论都写「时钟周期」，只有这个标签不同，「需要先会」还正好指向讲 CPU 周期的那一页。

### 低

1. 手机上时空图左边被切：表头只剩「期」，行名 WB、EX、ID、IF 贴边被切掉一部分（`b1-m-q3-ask.png`）。
2. Tk、Ck、Tp 三块读数牌错落摆放，Tk 垫着一块底座、另两块没有，不成行（同一张图）。
3. 整除时仍写约等号：`?ex=five&s=13`「Ck = 30/10 ≈ 3」，`s=14`「≈ 12 MIPS」。
4. 试一试的报错用了内部名字：「时钟周期 dt 要是正数（ns）」，界面上那一栏叫 Δt。
5. 练习交卷时第 2 列 IF 段填错（I1）没有标红，只标了同列的 ID 段，而 Tk、Ck、Tp 三栏同时标红（`b1-d-quiz-graded.png`）。提示本身指对了地方，但学生可能以为没标红的 IF 是对的。练习填的内容刷新后丢失。
6. 弄坏它选「最慢的段 + τₗ」时没有任何反馈，也没说这就是对的取法。
7. Ck 只认 2.67，填 2.666、2.7、24/9 都判错，题面只写了「保留两位小数」。
8. 试一试 k=8、n=24 在手机上最后一步只看得到图的一角，行名列号都不在画面里（`b1-m-try-k8n24.png`）。
9. 1280×800 打开时舞台只露出上半截，「下一步」在屏幕外，要先往下滚。
