## 讲解：例题 (+1001) + (+0111)（网址 ）

条件：写法 定点整数；数值位 n = 4；运算 x + y；x +1001；y +0111；变形补码 6 位：2 个符号位加 4 个数值位，模 2^6；表示范围 −10000 到 +1111

共 12 步 初始状态

### 第 1 步
- 层级：讲解步
- 标题：写出 [x]变补 = 001001
- 为什么：x = +1001 不是负数，两个符号位写 00，后面接 4 位数值 1001。教材 p38
- 变化：
  - [x]变补 S_f1：空 → 0
  - [x]变补 S_f2：空 → 0
  - [x]变补 2^3：空 → 1
  - [x]变补 2^2：空 → 0
  - [x]变补 2^1：空 → 0
  - [x]变补 2^0：空 → 1

### 第 2 步
- 层级：讲解步
- 标题：写出 [y]变补 = 000111
- 为什么：y = +0111 不是负数，两个符号位写 00，后面接 4 位数值 0111。教材 p38
- 变化：
  - [y]变补 S_f1：空 → 0
  - [y]变补 S_f2：空 → 0
  - [y]变补 2^3：空 → 0
  - [y]变补 2^2：空 → 1

- 变化：
  - 进入 2^1 的进位：空 → 1
  - [x+y]变补 2^0：空 → 0

- 层级：一个节拍
- 标题：第二符号位：0 加 0 加进位 1，写 1，不进位

- 变化：

### 第 8 步
- 层级：一个节拍
- 标题：最高符号位：0 加 0 加进位 0，写 0，不进位

- 变化：

  - [x+y]变补 S_f1：空 → 0

### 第 9 步
- 层级：讲解步
- 标题：最高符号位没有向外进位，[x+y]变补 = 010000
- 为什么：变形补码按模 2^6 运算，结果只留 6 位。这次没有超出 6 位的进位，没有要丢的。有没有这个进位都不说明是否溢出，要看结果的两个符号位。教材 p38
- 变化：
  - 丢掉的进位：空 → 0
- **预测题**：结果的两个符号位是 01，这次运算属于哪一种

### 第 10 步
- 层级：讲解步
- 标题：结果的符号位是 01，两位不同，正溢
- 为什么：V = S_f1 ⊕ S_f2 = 0 ⊕ 1 = 1，有溢出。最高符号位 S_f1 始终是结果的真实符号，它是 0，真实结果为正，数值超过了上限，所以是正溢。教材 p38
- 变化：
  - S_f1：空 → 0
  - S_f2：空 → 1
  - V = S_f1 ⊕ S_f2：空 → 1
  - 判定：空 → 正溢

### 第 11 步
- 层级：讲解步
- 标题：用进位再判一次：V = C_f ⊕ C_0 = 0 ⊕ 1 = 1
- 为什么：去掉最高符号位，剩下的就是单符号位的补码加法。C_0 是最高数值位送进符号位的进位，写在进位行第二符号位上方，这里是 1；C_f 是符号位再向左送出的进位，写在最高符号位上方，这里是 0。两个加数各自的两个符号位相同，结果的两个符号位只会因为这两个进位不同而不同，所以两种判法结论一致：正溢。教材 p38
- 变化：
  - C_0：空 → 1
  - C_f：空 → 0
  - V = C_f ⊕ C_0：空 → 1

### 第 12 步
- 层级：讲解步
- 标题：结论：正溢，这 6 位里的数值不能当结果
- 为什么：按真值算，x + y = +10000，十进制 16。4 位数值位最大只能表示 +1111，十进制 15。结果超出上限，多出的一位数值挤进了第二符号位，符号位才成了 01。教材 p37
- 变化：
  - 结论：空 → 正溢，x + y = +10000 超出上限 +1111

- 标题：(+1001) + (+0111)：符号位没有向外进位，只看进位判无溢出，判错了
- 为什么：单符号位相加得 10000，符号位没有向外进位。按这条判法算无溢出；按真值算 x + y = +10000，正溢。教材 p38
- 变化：
  - 例 3 向外的进位：空 → 0
  - 例 3 只看进位：空 → 判无溢出
  - 例 3 和：空 → 10000
  - 例 3 实际：空 → 正溢

### 第 4 步
- 层级：讲解步
- 标题：(-1001) + (-1000)：符号位向外进 1，丢掉，只看进位判溢出，这次碰巧判对
- 为什么：单符号位相加得 01111，符号位向外进 1，丢掉。按这条判法算溢出；按真值算 x + y = −10001，负溢。教材 p38
- 变化：
  - 例 4 向外的进位：空 → 1
  - 例 4 只看进位：空 → 判溢出
  - 例 4 和：空 → 01111
  - 例 4 实际：空 → 负溢

### 第 5 步
- 层级：讲解步
- 标题：改用两个进位：V = C_f ⊕ C_0，四个都判对
- 为什么：C_0 是最高数值位送进符号位的进位，C_f 是符号位送出去的进位。只看 C_f 的那条判法漏了 C_0：两个进位相同时，符号位的进位只是按模丢掉的那一位，不是溢出。教材 p38
- 变化：
  - 例 1 C_f ⊕ C_0：空 → 0 ⊕ 0 = 0
  - 例 2 C_f ⊕ C_0：空 → 1 ⊕ 1 = 0
  - 例 3 C_f ⊕ C_0：空 → 0 ⊕ 1 = 1
  - 例 4 C_f ⊕ C_0：空 → 1 ⊕ 0 = 1
