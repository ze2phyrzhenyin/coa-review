# ROM、RAM 各占一段地址，译码器接哪几根线（3-decode）

页面的部分：讲解、试一试、练习、弄坏它


## 讲解：例题「ROM + 24K RAM」（网址 /3-decode）

### 舞台上方的文字
ROM、RAM 各占一段地址。译码器的每个输出管一样长的一段，低电平有效；把每一段接到放在那里的芯片的片选 CS 上。存储器按字编址。

- 需要先会：位扩展、字扩展和片选

### 条件
- CPU：地址线 A_15–A_0，数据线 D_7–D_0，控制线 MREQ、R/W
- 信号：MREQ 低电平表示访存；R/W 高读低写；芯片片选 CS 低电平有效
- 地址空间：ROM 0000H–3FFFH（已有）；RAM 8000H–DFFFH，用 8K×4 位 芯片
- 译码器：74138：输入 C、B、A，使能 G_1 高有效、G_2A 和 G_2B 低有效，输出 Y_0–Y_7 低有效

### 第 0 步
（共 16 步）
- 标题：译码器的输入接哪几根地址线，每个输出接到哪一组
- 为什么：画面上垫了深色纸的部件就是这一页要看的地方。按「下一步」开始。
### 第 1 步
（第 1 步，共 16 步，讲解步）
- 标题：画出地址空间分布
- 为什么：16 根地址线共 64K 个地址。ROM 占 0000H–3FFFH，共 16K；RAM 占 8000H–DFFFH，共 24K；4000H–7FFFH、E000H–FFFFH 空着。大小 = 尾地址 − 首地址 + 1。解析书 p51
- 变化：
  - ROM 区首地址：空 → 0000H
  - ROM 区种类：空 → ROM
  - ROM 区大小：空 → 16K
  - ROM 区尾地址：空 → 3FFFH
  - RAM 区首地址：空 → 8000H
  - RAM 区种类：空 → RAM
  - RAM 区大小：空 → 24K
  - RAM 区尾地址：空 → DFFFH
### 第 2 步
（第 2 步，共 16 步，讲解步）
- 标题：ROM 0000H–3FFFH：已有 16K×8 位，1 块
- 为什么：这块 ROM 已经配好，按一整块看，接全部 8 根数据线。教材 p122 习题 7
- 变化：
  - ROM 区芯片：空 → 已有 16K×8 位，1 块
### 第 3 步
（第 3 步，共 16 步，讲解步）
- 标题：RAM 8000H–DFFFH：8K×4 位 × 6 片（3 组，每组 2 片）
- 为什么：24K ÷ 8K = 3 组；字长 8 位 ÷ 芯片 4 位 = 每组 2 片。组内位扩展，各片分别接 D_3–D_0、D_7–D_4。教材 p76–77
- 变化：
  - RAM 区芯片：空 → 8K×4 位 × 6 片（3 组，每组 2 片）
### 第 4 步
（第 4 步，共 16 步，讲解步）
- 标题：按 8K 分组，组内地址 A_12–A_0
- 为什么：取最大的芯片字数每组 8K 个地址 = 2^(13)，低 13 位 A_12–A_0 送到芯片，不参加译码。剩下 3 位用来区分各组。解析书 p51
- 变化：
  - 组内地址线：空 → A_12–A_0
  - 每组地址数：空 → 8K
### 第 5 步
（第 5 步，共 16 步，讲解步）
- 标题：74138（3:8 译码器），输入 A_15–A_13
- 为什么：紧挨着组内地址的 3 位 A_15–A_13 送进译码器，高位接 C。MREQ 接低有效的使能端，不访存时所有输出都无效，芯片都不选中。用不上的使能端接成有效电平。解析书 p51–53
- 变化：
  - 使能端 1：空 → G_1 ← 高电平
  - 使能端 2：空 → G_2A ← MREQ
  - 使能端 3：空 → G_2B ← 接地
  - 输入 1：空 → C ← A_15
  - 输入 2：空 → B ← A_14
  - 输入 3：空 → A ← A_13
  - 译码器：空 → 74138（3:8 译码器）

### 常见错误

- 容易只把 Y0 接到 ROM，因为它是一整块
  - 点开后（跳到第 7 步）舞台下的说明：ROM 有 16K，占 Y_0、Y_1 共 2 段。只接 Y_0，访问 2000H–3FFFH 时 Y_1 有效，可它没接到 ROM，这一段读不出来。这几个输出低电平有效，要经与门合成一个片选。 ｜ 恢复
- 容易漏接 MREQ，因为只盯着地址线
  - 点开后（跳到第 14 步）舞台下的说明：使能端一直有效，CPU 不访存的时候（地址线上是别的东西），译码器照样译出一个 Y，某组芯片被选中，可能往数据线上送数，和正在用数据线的部件撞上。MREQ 接使能端，只在访存时才选芯片。 ｜ 恢复

### 常见错误

- 容易把 RAM4 直接接 Y7，因为它也落在这一段
  - 点开后（跳到第 14 步）舞台下的说明：Y_7 管 E000H–FFFFH，RAM4 只有 4K。直接接上，E000H 起的那一半也选中它：同一片在这一段里出现两次，写 E000H 就改了 F000H。所以还要用组内的高位再分一次。 ｜ 恢复
- 容易只把 Y0 接到 ROM，因为它是一整块
  - 点开后（跳到第 8 步）舞台下的说明：ROM 有 16K，占 Y_0、Y_1 共 2 段。只接 Y_0，访问 2000H–3FFFH 时 Y_1 有效，可它没接到 ROM，这一段读不出来。这几个输出低电平有效，要经与门合成一个片选。 ｜ 恢复
- 容易漏接 MREQ，因为只盯着地址线
  - 点开后（跳到第 15 步）舞台下的说明：使能端一直有效，CPU 不访存的时候（地址线上是别的东西），译码器照样译出一个 Y，某组芯片被选中，可能往数据线上送数，和正在用数据线的部件撞上。MREQ 接使能端，只在访存时才选芯片。 ｜ 恢复
