## 讲解：例题「例题：LAD」（网址 /5-flow）

开头说明：方框图里一个方框是一个 CPU 周期，框里写这个周期的数据通路「源→目的」；菱形是译码，「～」是公操作（教材 p161–162）。框旁边的电位信号直接写，脉冲信号注明在哪个节拍。台面上面是方框图，下面是图 5.1 的模型机：每画一个方框，模型机就把这个周期走一遍；点方框可以再看一遍它的通路。LAD R0,9 把数存 9 号单元的数取进 R0。

需要先会：模型机的指令周期

### 条件
- 机器：图 5.1 模型机
- 指令：LAD R0,9（数存 9 号单元 → R0）
- 信号名：教材

### 第 0 步
（共 5 步）
- 标题：一个方框是一个 CPU 周期；框旁的信号哪些直接写，哪些要注 T
- 为什么：画面上垫了深色纸的部件就是这一页要看的地方。按「下一步」开始。
### 第 1 步
（第 1 步，共 5 步，一个 CPU 周期）
- 舞台读数：取指周期 T4 RD(I) PC+1 LDPC
- 标题：LAD R0,9，第 1 个方框（取指）：PC→ABUS(I)；IBUS→IR；PC+1
- 为什么：每条指令都从取指方框开始，取指走 IBUS，不占 DBUS。电位信号 RD(I) 整个周期有效，直接写在框旁；LDIR(T3)、PC+1(T4)、LDPC(T4) 是打入或写入的时刻，要注明节拍。教材 p154–155，p162 图 5.15
- 变化：
  - 第 1 个方框的CPU 周期：空 → 取指
  - 第 1 个方框的指令：空 → LAD R0,9
  - 第 1 个方框的电位信号：空 → RD(I)
  - 第 1 个方框的周期号：空 → M1
  - 第 1 个方框的操作：空 → PC→ABUS(I)
  - 第 1 个方框的操作：空 → IBUS→IR
  - 第 1 个方框的操作：空 → PC+1
  - 第 1 个方框的脉冲信号：空 → LDIR(T3)
  - 第 1 个方框的脉冲信号：空 → PC+1(T4)
  - 第 1 个方框的脉冲信号：空 → LDPC(T4)
  - 正在画的指令：空 → LAD R0,9
### 第 2 步
（第 2 步，共 5 步，讲解步）
- 舞台读数：取指周期 T4 RD(I) PC+1 LDPC
- 标题：译码（菱形）
- 为什么：菱形表示按操作码分支，它在时间上依附于取指方框所在的 CPU 周期，不另占周期（p161）。教材 p161
- 变化：
  - 译码菱形：空 → LAD R0,9
- 题目：这个方框里的 LDAR 在哪一拍发
  - 说明：点场景里的部件作答。
  - 作答：点选；按钮：看答案
  - 答错时：点「选 T1」→ T1 时数还在总线上走，没稳定；这时打入，收进去的不是这个数。 不对。打入要等数据在总线上稳定：进 DR、IR 和写数存在 T3，进 AR、PC、通用寄存器在 T4（图 5.30）。（点非候选部件时：指存 不是这道题的选项。在 T1、T2、T3、T4、整个周期 里选。）
### 第 3 步
（第 3 步，共 5 步，一个 CPU 周期）
- 舞台读数：执行一周期 T4 C3 LDAR
- 标题：LAD R0,9，第 2 个方框（执行一）：IR(地址码)→DBUS；DBUS→AR
- 为什么：执行一周期占一个方框。电位信号 C3 整个周期有效，直接写在框旁；LDAR(T4) 是打入或写入的时刻，要注明节拍。教材 p161–162，p178 图 5.30
- 变化：
  - 第 2 个方框的CPU 周期：空 → 执行一
  - 第 2 个方框的指令：空 → LAD R0,9
  - 第 2 个方框的电位信号：空 → C3
  - 第 2 个方框的周期号：空 → M2
  - 第 2 个方框的操作：空 → IR(地址码)→DBUS
  - 第 2 个方框的操作：空 → DBUS→AR
  - 第 2 个方框的脉冲信号：空 → LDAR(T4)
### 第 4 步
（第 4 步，共 5 步，一个 CPU 周期）
- 舞台读数：执行二周期 T4 RD(D) LDR0
- 标题：LAD R0,9，第 3 个方框（执行二）：AR→ABUS(D)，数存→DBUS；DBUS→DR；DR→R0
- 为什么：执行二周期占一个方框。电位信号 RD(D) 整个周期有效，直接写在框旁；LDDR(T3)、LDR0(T4) 是打入或写入的时刻，要注明节拍。教材 p161–162，p178 图 5.30
- 变化：
  - 第 3 个方框的CPU 周期：空 → 执行二
  - 第 3 个方框的指令：空 → LAD R0,9
  - 第 3 个方框的电位信号：空 → RD(D)
  - 第 3 个方框的周期号：空 → M3
  - 第 3 个方框的操作：空 → AR→ABUS(D)，数存→DBUS
  - 第 3 个方框的操作：空 → DBUS→DR
  - 第 3 个方框的操作：空 → DR→R0
  - 第 3 个方框的脉冲信号：空 → LDDR(T3)
  - 第 3 个方框的脉冲信号：空 → LDR0(T4)
- 题目：LAD R0,9 一共画几个方框
  - 作答：输入框；按钮：确定｜看答案
  - 答错时：填 250 → 多出来的方框里 DBUS 没有数要送，也没有寄存器要打入，机器白等一个周期。 不对。DBUS 一次只能送一个数，地址和数据要分在两个方框里。
### 第 5 步
（第 5 步，共 5 步，讲解步）
- 舞台读数：执行二周期 T4 RD(D) LDR0
- 标题：LAD R0,9 结束：～
- 为什么：这条指令共 3 个方框，也就是 3 个 CPU 周期。末尾的「～」是公操作：处理外设请求，没有请求就去取下一条指令（p161）。教材 p161–162
- 变化：
  - 公操作「～」：空 → LAD R0,9
- 〔结论〕一个方框就是一个 CPU 周期，框里写这个周期的「源→目的」；框旁的电位信号（RD、C1–C3 这类开通路、保持整个周期的）直接写，脉冲信号（LDxx、PC+1、WE(D) 这类打入、写入的）要注明在哪一拍：进 DR、IR 和写数存在 T3，进 AR、PC 和通用寄存器在 T4。

### 解题表（最后一步）
| 指令 | CPU 周期 | 方框里的操作 | 电位信号 | 脉冲信号 |
| LAD R0,9 | 取指（M1） | PC→ABUS(I)；IBUS→IR；PC+1 | RD(I) | LDIR(T3)，PC+1(T4)，LDPC(T4) |
| LAD R0,9 | 执行一（M2） | IR(地址码)→DBUS；DBUS→AR | C3 | LDAR(T4) |
| LAD R0,9 | 执行二（M3） | AR→ABUS(D)，数存→DBUS；DBUS→DR；DR→R0 | RD(D) | LDDR(T3)，LDR0(T4) |


### 常见错误（点开后页面演示时给出的说明）

1. 容易给 RD(I) 也注上节拍，写成 RD(I)(T1)，因为同一个方框里的脉冲信号都注了
   - 点开：跳到第 1 步；说明：RD(I) 是电位信号，要从 T1 一直保持到这个周期结束。只给 T1 的话，到 T3 打入 IR 时存储器已经不读了，IR 收不到这条指令。电位信号在方框旁直接写，不注节拍。
2. 容易把 LAD 的两个执行方框画成一个，因为它们都在为同一个操作数忙
   - 点开：跳到第 5 步；说明：一个方框是一个 CPU 周期，DBUS 一个周期只能送一个数。先送地址进 AR，再送数据，要两个方框。
3. 容易把译码画成一个方框，因为它也是一步要做的事
   - 点开：跳到第 2 步；说明：译码是菱形，在取指周期的末尾按操作码分支，不占 CPU 周期。画成方框就多算了一个周期，所有指令的周期数都错一个。

- 「LDAR 在哪一拍发」选 T3 →「T3 时数还在总线上走，没稳定；这时打入，收进去的不是这个数。 不对。打入要等数据在总线上稳定：进 DR、IR 和写数存在 T3，进 AR、PC、通用寄存器在 T4（图 5.30）。」
- 同一题选「整个周期」→「打入信号要是整个周期都有效，T1 门刚打开、总线上的数还没稳定时寄存器就开始收，收进去的可能是上一拍的数。所以打入用脉冲，只在一拍里有效。」
- 信号名切到「解析书」时 LAD 的解题表：取指 IR/W̄=1；SIR(T3)，PC+1(T4)。执行一 C3；SAR(T4)。执行二 DR/W̄=1；SDR(T3)，SR0(T4)。
