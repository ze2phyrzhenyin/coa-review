## 变式（只看 steps.md）
2 路组相联，cache 4 行（u = 2，v = 2），每块 2 字，按字编址，地址 5 位，LRU，写回法，开始全空。地址格式（照例题）标记 3 位 | 组号 1 位 | 字地址 1 位；j = 地址 ÷ 2 取整，q = j mod 2；组 0 = 行 0、行 1。

| 次 | 访问 | 二进制 | j | q | 标记 | 结果 | 处理 | 计数器（行 0, 行 1）|
|---|---|---|---|---|---|---|---|---|
| 1 | 读 0 | 000 0 0 | 0 | 0 | 0 | 缺失 | 两行都空，进行号最小的行 0 | 0, – |
| 2 | 读 9 | 010 0 1 | 4 | 0 | 2 | 缺失 | 行 1 空，进行 1 | 1, 0 |
| 3 | 读 16 | 100 0 0 | 8 | 0 | 4 | 缺失 | 都占着，换计数器大的行 0：块 0 出（修改位 0）| 0, 1 |
| 4 | 写 1 | 000 0 1 | 0 | 0 | 0 | 缺失 | 换行 1：块 4 出；块 0 调入后写，行 1 修改位 1 | 1, 0 |
| 5 | 读 25 | 110 0 1 | 12 | 0 | 6 | 缺失 | 换行 0：块 8 出 | 0, 1 |
| 6 | 读 8 | 010 0 0 | 4 | 0 | 2 | 缺失 | 换行 1：块 0 出，修改位 1，写回 | 1, 0 |

命中 0 次，h = 0/6 = 0。用到的规则在 steps.md 里都有：「空行：候选行里有空行时先用空行，取行号最小的」、LRU 计数器一行、第 9 步「写回法下写缺失也先把块调入，再在 cache 里改，修改位设为 1」、第 19 步「块 5 的修改位是 1，换出前先写回主存」、第 26 步 h 的算法。与引擎（试一试同一串）逐行相同。

## 两步手算对照教材（docs/textbook/ch03.md）
- 直接映射第 1–2 步，读 9：9 = 01001。w = 1 → 字地址 1；r = 2 → 行号 00；标记 01（格式 `标记 s−r | 行 r | 字地址 w`，s = 4，第 92 行）。j = 4，i = 4 mod 4 = 0（式 3.7）。页面「切出标记 1、行号 0、字地址 1」「4 mod 4 = 0」，对。
- 组相联第 19 步，读 22：22 = 10110，j = 11，q = 11 mod 2 = 1（式 3.8），组 1 = 行 2、行 3。此时行 2 块 3 计数 0，行 3 块 5 计数 1、修改位 1（第 2 次访问写 10）。LRU 换出计数值最大的行（第 211 行）→ 行 3；写回法换出时修改位为 1 才写回（第 220 行）→ 写回；新标记 101 = 5，修改位清 0。页面第 19 步变化「换出的块 5、所在行 3、写回 是、行 3 标记 2 → 5、修改位 1 → 0」，对。
