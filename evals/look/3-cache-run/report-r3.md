## 答题（每种题答对一次、答错一次）
命中吗（缺失错/命中对）、块 j 放在哪一行（行 0 错/行 1 对）、换出哪一行（行 2 错/行 3 对）：答错都演后果后退回，提示属实（「比较行 2、行 3 的计数器，LRU 看最大的」，此时行 2 计数 0、行 3 计数 1）；答错后 hash 回到出题时。试一试序列框：32 →「地址 32 超出范围，地址 5 位，最大 31」；空 →「至少写一个地址」；「写 3」→ 看不懂「写」。
