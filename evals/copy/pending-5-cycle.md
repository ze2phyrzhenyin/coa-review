# 5-cycle 文案改动建议

`src/pages/5-cycle/**` 正由别的任务修改，这里只列建议，没有动文件。行号按 2026-11-15 读到的版本，改之前按原文重新定位。

## 1. `src/pages/5-cycle/practice.ts:118`

- 原：`` `第 ${i + 1} 行（${row.cycle}）的操作不对。想一想：${lead}。` ``
- 改：`` `第 ${i + 1} 行（${row.cycle}）的操作不对。看${lead}。` ``
- 理由：「想一想：」是口头引导，后面那句已经说了看什么。引擎里同类提示（`src/engines/cpu/model.ts` 的两条 hint）已同样改掉。

## 2. `src/pages/5-cycle/machine.ts:388`

- 原：`…要在同一个 CPU 周期里同时上 DBUS，DBUS 上就有两个数，打架。`

- 理由：「打架」是比喻，换成引擎冲突提示用的说法（`src/engines/cpu/model.ts` 的「线上的电平不确定」）。

## 3. `src/pages/5-cycle/machine.ts:475`
