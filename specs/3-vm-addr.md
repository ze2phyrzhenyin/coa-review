# 3-vm-addr：页式虚地址变换引擎

困惑：虚地址怎么变成物理地址。学完能把虚地址切成逻辑页号和页内地址，查页表看有效位，拼出物理地址或判断缺页；加一层快表时先看快表。
教材依据：3.7.2，p112–114，图 3.33、图 3.34；习题 23、24（p124）。解析书分析题 22（十进制地址）、选择题 27（p33、p45）。
代码：`src/engines/vm/model.ts`，入口 `run(params)`；另有 `validateParams`、`translate(params, address)`、`generate(seed)`。

## 参数

| 名 | 取值 | 说明 |
|---|---|---|
| `pageSize` | 2 的幂，2–2^20 | 每页的编址单位数，页内地址 log2 位 |
| `pages` | 2 的幂，2–2^20 | 虚页数；虚地址位数 = log2(pages × pageSize) ≤ 32 |
| `frames` | 2 的幂，1–2^20 | 主存页数；物理地址位数 = log2(frames × pageSize) ≤ 32 |
| `table` | `{ page, valid, frame }[]` | 页表里列出的项；没列出的页有效位为 0。`valid` 为 0 或 1；有效时 `frame` < `frames`，同一页只列一次 |
| `tlb` | `{ page, frame }[]`，可选，至多 16 项 | 快表内容，必须是页表里有效项的副本 |
| `addresses` | 1–8 个虚地址 | |
| `radix` | `hex`（缺省）或 `dec` | 地址写法：十六进制带 H，位数 ⌈位数/4⌉；十进制原样 |

## 要求

1. 每个虚地址的步骤顺序：切分（二进制，高位逻辑页号、低位页内地址）→ 给了 `tlb` 时查快表 → 快表没命中（或没有快表）时查页表（页表基址加逻辑页号找到表项）→ 看有效位：1 则物理页号与页内地址拼接成物理地址，0 则缺页（p112–113）。
2. 前几步是 `explain`，每个地址最后一步是 `access`，结果是物理地址或「缺页」。
3. 快表命中时直接用快表的物理页号，不再查页表（p114）。快表不因访问而改变。
4. 物理地址是拼接，不是相加：物理地址 = 物理页号 × pageSize + 页内地址。
5. 状态：`current` 为 `{ n, address, bits, pageBits, offsetBits, page, offset, tlb, valid, frame, physical, physicalBits, result }`（`tlb` 为 `命中`、`未命中` 或 null；`result` 为 `物理地址`、`缺页` 或 null），另有 `faults`（缺页次数）、`tlbHits`。
6. `table` 列为 虚地址 | 逻辑页号 | 页内地址 | 快表（只在有快表时）| 有效位 | 物理页号 | 物理地址，每个地址一行，指回它的 `access` 步。缺页时物理页号、物理地址两格写「缺页」。快表命中时有效位格写「—」。
7. `result` 以虚地址的写法为键（如 `0AC5H`），值为物理地址或「缺页」；另有 缺页次数，有快表时加 快表命中次数。
8. 条件里列出 虚地址格式（逻辑页号 x 位 | 页内地址 y 位）和 物理地址格式（物理页号 | 页内地址）。
9. 预测题：页表里有有效位为 0 的项时，看有效位那一步问「这一页在主存吗」（在主存 / 缺页）；拼接那一步问「物理页号是几」（数字）。
10. `translate` 返回 `{ page, offset, frame, physical, fault, tlbHit }`，与 Trace 一致。

## 场景

- WHEN 页长 1K、虚页 3 在主存页 5、虚地址 0DB4H THEN 逻辑页号 3，页内地址 1B4H，物理地址 15B4H。
- WHEN 32 页、页长 1K、主存 16 页，虚页 0–3 在 8、7、4、10，虚地址 0AC5H 和 1AC5H THEN 12C5H 和缺页。
- WHEN 十进制 8644、页长 4K、页 2 在主存页 8 THEN 33220。
- WHEN 快表里有该页 THEN 不出现查页表的步，结果与没有快表时相同。
- WHEN 快表项与页表不一致，或虚地址超出虚存空间 THEN `run` 抛出错误。

## 性质

1. 页内地址不变：物理地址 mod pageSize = 虚地址 mod pageSize。
2. 有快表和没快表的物理地址、缺页判断都相同。
3. 缺页当且仅当页表里该页没有有效项。
4. 与朴素参照实现（除法和取余）逐个地址一致；同样的参数得到同样的 Trace，`validateTrace` 为空。

固定用例：`evals/golden/vm-addr.json`：本站自拟 0DB4H、习题 24（p124，自行推算）、解析书分析题 22、选择题 27 的数值。
不做：段式、段页式（3-vm-seg）；二级页表、反向页表；快表的装入和替换；有效访问时间；缺页后的调页过程。
