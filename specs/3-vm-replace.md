# 3-vm-replace：页面替换列表法引擎

困惑：FIFO 和 FIFO+LRU 的表每一列怎么填。学完能按「a 进 c 出」的表逐列填出主存页面，标出命中，求命中率、缺页次数和依次淘汰的页号。
教材依据：3.7.4，p117–118，例 3.11；习题 19（p123，LRU）。解析书分析题 18、23、28（p43–47）。
代码：`src/engines/vmreplace/model.ts`，入口 `run(params)`；另有 `validateParams`、`simulate(params)`、`generate(seed)`。

## 参数

| 名 | 取值 | 说明 |
|---|---|---|
| `frames` | 1–8 | 主存页面数，自上而下叫 a、b、c… |
| `policy` | `FIFO`、`FIFO+LRU`、`LRU` | |
| `pages` | 1–40 个非负整数 | 虚页号序列 |
| `addresses`、`pageSize` | 1–40 个非负整数；正整数 | 代替 `pages`：给字地址，页号 = 地址 ÷ 页大小取整（解析书分析题 28），二者与 `pages` 只能给一种 |
| `initial` | 至多 `frames` 个不同页号，可选 | 开始时已在主存的页，从 a 往下排；这些页的装入不算缺页 |

## 要求

1. 每列的规则（p118）：
   - 缺页：新页放进 a，原有各页依次下移一格；最下一格原来有页时把它换出（淘汰）。
   - FIFO 命中：各页不动。
   - FIFO+LRU 命中：命中的页移到 a，它上面的页各下移一格，它下面的页不动。
   - LRU：表和 FIFO+LRU 完全相同（a 是最近用过的页，最下一格是最久没用的页），只是讲法按 LRU。
2. 每次访问两步：比较（`explain`，给了 `addresses` 时先写出地址 ÷ 页大小）→ 填这一列（`access`）。
3. 状态 `frames`（长度为页面数，空格为 null）、`current` 为 `{ n, page, hit, evicted, marked }`（`marked` 为命中页所在格的下标，供加圈；未命中为 null），另有 `hits`、`faults`、`evicted`（已淘汰页号的列表）。
4. `table` 的版式跟例 3.11：列为 `页面访问序列`、每次访问一列（列名是页号，命中时写成带圈数字如 ②，超过 50 写成 (51)）、`命中率`。行依次为 a、b、c…（每格是这一列之后该格的页号，命中的页加圈，空格为空串）和最后一行「命中」行（命中的列写「命中」）。命中率写在 a 行最后一格，其余行该格为空串。这张表是横排的，行不指回步；第 k 列对应第 k 个 `access` 步。
5. `result` 有 命中次数、缺页次数、命中率（如 `2/11=18.2%`，百分数 1 位小数、去掉末尾 0）、淘汰页号（如 `0、1、2`，没有写「无」）。
6. 预测题：比较步上，页号与上一次不同、且这个页之前出现过（或在 `initial` 里）时问「命中吗」（命中 / 缺页）；FIFO+LRU 或 LRU 命中且该页不在 a 时，填列步问「命中后 a 格是哪一页」（数字）。
7. `simulate` 返回每列的 `{ page, hit, frames, evicted }`，与 Trace 一致。

## 场景

- WHEN 3 个页面、序列 0 1 2 4 2 3 0 2 1 3 2、FIFO THEN 命中 2 次，2/11=18.2%。
- WHEN 同一序列 FIFO+LRU THEN 命中 3 次，3/11=27.3%，第 5 列 a、b、c 为 2、4、1。
- WHEN 字地址 115 228 120 88 446 102 321 432 260 167、页大小 100、3 页、第 0 页已在主存 THEN FIFO 缺页 5 次淘汰 0、1、2；LRU 缺页 6 次淘汰 2、0、1、3。
- WHEN `pages` 和 `addresses` 都给，或 `initial` 有重复页 THEN `run` 抛出错误。

## 性质

1. 命中次数 + 缺页次数 = 访问次数；淘汰次数 = 缺页次数 − 开始时的空格数（不小于 0）。
2. 每列之后各格的页互不相同，且刚访问的页一定在表里。
3. FIFO+LRU 与 LRU 的每一列相同；FIFO+LRU 的最下一格总是最久没访问的页。
4. 与朴素参照实现（FIFO 用调入时刻，LRU 用最近访问时刻）逐列一致。
5. 同样的参数得到同样的 Trace，`validateTrace` 为空。

固定用例：`evals/golden/vm-replace.json`：例 3.11 两种算法（p118）、本站自拟 2 3 2 1 5 2 4 5、习题 19（自行推算缺页 6 次）、解析书分析题 28。
不做：LFU、OPT、Clock；页框固定不动的通用表格；修改位与写回辅存。
