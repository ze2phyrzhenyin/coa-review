# 引擎约定

所有引擎共同遵守。类型和校验在 `src/engines/trace.ts`。

## 必须

- 引擎必须是纯函数：`run(params) → Trace`。同样的参数必须得到完全相同的 Trace。
- 必须用 `TraceBuilder` 生成每一步；`validateTrace(trace)` 必须返回空列表。
- 状态必须是纯数据。状态里位置的路径（如 `reg.DR`、`rows.2.tag`）是场景和页面引用它的 id。
- 每一步必须有 `title`（做了什么）和 `why`（为什么能发生），有教材出处的写 `ref`。
- 步的层级必须如实：同一拍里拆开讲的小步是 `explain`，不许标成 `beat` 或 `cycle`。
- `ask` 的答案必须取自引擎的状态。选择题的答案必须在选项里。
- `trace.table` 必须是学生在纸上写的那张表，版式跟教材例题；每行指回对应的步。
- `trace.result` 必须包含题目要求的每个量。
- 非法参数必须抛出说明原因的错误，不许返回半截 Trace。

## 测试必须有

- 规格里列的性质（fast-check）。
- 与独立写的朴素参照实现对拍。
- `evals/golden` 里的固定用例。
- 小规模能穷举的就穷举。

## 不许

- 引用界面代码、浏览器对象、随机数、当前时间。
- 在 `why` 里写教材原句。
