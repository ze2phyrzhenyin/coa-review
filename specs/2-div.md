# 2-div：原码加减交替除法引擎

困惑：余数为负为什么不恢复，下一步反而加；最后的余数为什么还要乘 2^-n。学完能按例 2.25 的版式写出每一行，求出商和余数，并说出阵列除法器每一行的 P 和商位从哪来。
教材依据：2.4.1（p48–50）：商符 p49，够减判断与进位 p50，加减交替的推导和纠余 p50；2.4.2（p50–53）：CAS 单元式 2.28，阵列规则与式 2.30；例 2.25（p53–54）。习题 8（p68）要求整数先乘比例因子化成小数。
代码：`src/engines/div/model.ts`，入口 `run(params)`、`generate(seed, options)`。

## 参数

| 名 | 取值 | 说明 |
|---|---|---|
| `n` | 2–12 的整数 | 数值位数；商有 q_0…q_n 共 n+1 位 |
| `notation` | `小数` `整数` | 整数时乘比例因子 2^-n，化成小数再算 |
| `x`、`y` | `{ as: '真值', text }` 或 `{ as: '机器数', bits }` | 机器数是 n+1 位原码，小数可带小数点 |

## 要求

1. 商符必须单独算：q_f = x_f ⊕ y_f；数值部分用 |x|、|y| 两个正数相除（p49）。
2. 部分余数必须是 n+1 位、单符号位、带小数点的写法（例 2.25）。「减 y」是加 [−|y|]补，「加 y」是加 [|y|]原（p50）。
3. 步骤：写 [x]原、[y]原并算商符；写 [|x|]原、[|y|]原、[−|y|]补；第 0 轮「减 y」；以后每轮先上商，再左移，再按上一位商「减 y」（商 1）或「加 y」（商 0）；第 n 轮后上商 q_n；余数为负时再「加 y」纠余；最后写商和余数。加减各一步，层级 `beat`；上商、左移、写数、结论是 `explain`。
4. 上商：余数 ≥ 0 商 1，< 0 商 0（p50）。每次加减必须记下符号位向外的进位，并说明它等于这一位商（p50「有进位时结果为正」，p53 每行最左单元的进位输出就是商）。
5. 左移：整串左移一位，最高位移出丢掉，最低位补 0。
6. 余数：纠余后的部分余数乘 2^-n，写成 2n 位小数；符号与被除数相同（p50）。
7. 状态里要有阵列视图 `rounds`：第 i 轮是图 2.10 的第 i 行，记 P（1 减、0 加；第 0 行固定为 1）、这一行的和、最左单元的进位输出（= q_i）（p52–53）。
8. 必须拒绝：y = 0；|x| ≥ |y|（商不小于 1，定点小数放不下）；位数不对；超出原码范围；小数写法的真值不是纯小数。错误用 `BitsError`，写明原因。
9. 预测题两道，答案取自状态：第一次出现「余数为负之后的那一轮」的加减步问做「减 y」还是「加 y」（没有这种轮次时问第 1 轮）；最后一步之前问要不要纠余。
10. `table` 按例 2.25 的版式：列为 行名、符号位、2^-1…2^-n、判断、上商。行名依次是 被除数 x、减 y / 加 y、余数为正 / 余数为负 / 余数为 0、左移……，纠余那一行的上商栏写「纠余」。每行指回写出它的一步。
11. `result`：`[q]原`、`商的真值`、`余数`（2n 位小数，带被除数的符号）、`验证`（|x| = q·|y| + r 的十进制等式，精确）。

## 场景

- WHEN x=0.10110、y=0.11111、n=5 THEN 商 0.10110，第 5 轮余数为负要纠余，余数 0.0000010110（例 2.25）。
- WHEN x=0.1001、y=0.1011 THEN 商 0.1101，余数 0.00000001，不纠余（p49 的数）。
- WHEN 整数、x=11000、y=−11111 THEN 化成 0.11000 ÷ 0.11111，[q]原 = 1.11000，余数 +0.0000011000（习题 8(1)）。
- WHEN x=−0.01011、y=0.11001 THEN 余数带负号（被除数为负）。
- WHEN x=0.1100、y=0.1010 THEN 抛错，说明 |x| ≥ |y|。

## 性质

1. 任意合法参数：Q = ⌊|X|·2^n / |Y|⌋，R = |X|·2^n − Q·|Y|（X、Y 以 2^-n 为单位），与 BigInt 参照相同。
2. 每轮加减之后部分余数 r 满足 −|y| ≤ r < |y|，且与参照逐轮相同。
3. 第 i 轮的商位 = 这一轮符号位向外的进位 = 1 − 符号位；下一轮做减法当且仅当商位是 1。
4. 纠余发生当且仅当 q_n = 0。
5. 同样的参数得到同样的 Trace；`validateTrace` 为空；`generate(seed)` 同种子同参数，且总能 `run`。

固定用例：`evals/golden/div-cases.json`：例 2.25（p53–54）、p49 的数、习题 8 两组（p68）、自拟的被除数为 0 的例子。
不做：恢复余数法的走查（教材只有文字）、补码除法、双倍长被除数（解析计算 16，解析书的答案也有错）、CAS 门级的逐单元借位。

## 待确认

- 阵列视图只到每行的 P、和、进位输出，不画单个 CAS。
