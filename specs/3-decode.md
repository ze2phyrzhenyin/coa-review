# 3-decode：ROM、RAM 地址译码引擎

困惑：ROM、RAM 各占一段地址，译码器接哪几根线。学完能由地址空间分配写出选片数量、译码器输入、每个 Y 输出的去向、局部译码的门；反过来给一个地址说出选中哪组芯片。
教材依据：3.2.4 字扩展与图 3.8（p77）；教材习题 7（p122）；解析书设计题 3、4（p50–53，74LS139、74LS138）。教材正文没有混合设计的例题。
代码：`src/engines/decode/model.ts`，入口 `run(params)`；另有 `validateParams`、`design`、`locate(params, address)`、`generate(seed)`。

## 参数

| 名 | 取值 | 说明 |
|---|---|---|
| `addressBits` | 8–24 | CPU 地址线 A(n−1)–A0 |
| `dataBits` | 1–64 | 数据线 D(dataBits−1)–D0，也是存储字长 |
| `regions` | 1–8 项 `{ kind, start, end, chip? }` | `kind` 为 `ROM` 或 `RAM`；`start`、`end` 是首尾地址（含）；`chip` 为 `{ words, bits }`，`words` 可写 `'8K'`。ROM 可以不给 `chip`，表示已有的一整块 ROM |
| `decoder` | `74138` 或 `74139`，可选 | 缺省：译码位数为 2 用 74139（2:4），不少于 3 用 74138（3:8） |
| `groupWords` | 2 的幂，可选 | 每个 Y 输出管多少个地址；缺省取各芯片字数（无芯片的 ROM 不算）的最大值 |
| `probe` | 地址，可选 | 看这个地址选中谁 |

## 要求

1. 区域必须不重叠；每个区域的长度是芯片字数的整数倍，首地址按芯片字数对齐；芯片位数整除 `dataBits`。不合格时 `run` 抛出错误，原因与 `validateParams` 相同。
2. 选片：区域长度 ÷ 芯片字数 = 组数，`dataBits` ÷ 芯片位数 = 每组片数；组内各片做位扩展，第 j 片接 D((j+1)b−1)–D(jb)。没给芯片的 ROM 算 1 组 1 片，字数为区域长度。
3. 组大小 g = `groupWords`；g 位数 k = log2 g；A(k−1)–A0 不进译码器。译码位数 h = n − k。译码器输入取紧挨着的低 2 或 3 位（A(k+1)、Ak 或 A(k+2)–Ak），74138 写 C、B、A，74139 写 B、A，C/B 接高位。
4. 更高的地址线（h 多于输入数时）必须在所有区域里取值不变，否则报错。74138：MREQ 接 /G2A；取值恒为 0 的一根接 /G2B，恒为 1 的一根接 G1，各最多一根；没用的 G1 接高电平、/G2B 接地。74139：MREQ 接 /G，不能吸收多余地址线。
5. Yi 管的地址段是 基址 + i·g 到 基址 + (i+1)·g − 1，基址由接使能端的地址线定。Yi 的去向：
   - 芯片字数等于 g：直接接这一组芯片的片选；
   - 芯片字数大于 g（含无芯片 ROM）：这一组占的几个 Y 输出经「与门」合成一个片选（低电平有效，任一为 0 输出为 0）；
   - 芯片字数小于 g：Yi 经非门，与 A(k−1)…A(c) 中该组取值为 1 的线一起进「与非门」，取值为 0 的线先经非门，输出接片选（c = log2 芯片字数）；
   - 段内没有任何芯片：空。
6. 控制线：R/W 接 RAM 的 WE；ROM 不接 R/W；MREQ 接译码器使能。
7. 步骤顺序：地址空间分布（一步）→ 每个区域选片（每区域一步）→ 组大小与组内地址线 → 译码器输入和使能 → 每个 Y 输出（每个一步）→ 控制线 → 查地址（给了 `probe`）。全部是 `explain`。
8. 芯片组命名：ROM 区按地址顺序 ROM1、ROM2…（只有一组时叫 ROM），RAM 同理 RAM1、RAM2…，组号跨区域连续。
9. `table` 列为 译码输出 | 地址范围 | 接到 | 门电路，每个 Y 一行，指回该 Y 的步。地址写十六进制，位数 ⌈n/4⌉，后缀 H。
10. `result` 有 芯片（如 `RAM：8K×8 位 10 片`，ROM 同理，换行分隔用「；」）、译码器、译码输入（如 `A15、A14、A13`）、每个 `Yi`（去向，空写「空」）；给了 `probe` 再加 选中（`RAM3（Y4），片内地址 0005H` 或 `没有芯片`）。
11. `locate` 必须与 `probe` 步给出相同的芯片组和片内地址。预测题：每个 Y 步问「Yi 接到哪里」（选择，选项为各芯片组名和「空」），`probe` 步问「选中哪一组」。

## 场景

- WHEN ROM 0000H–3FFFH（无芯片），RAM 6000H–FFFFH 用 8K×8 位，16 位地址、16 位数据 THEN RAM 10 片，74138 输入 A15、A14、A13，Y0、Y1 经与门接 ROM，Y2 空，Y3–Y7 接 RAM1–RAM5。
- WHEN 再加最高 2K 用 2K×16 位芯片，组大小 8K THEN 该片经 Y7、非门、与非门（A12、A11）选中。
- WHEN 两个区域重叠，或 h 多出的地址线在区域间取值不同 THEN `run` 抛出错误。

## 性质

1. 每个区域里的每个地址，`locate` 都选中这个区域的某一组，且片内地址 = (地址 − 组首地址)。区域外的地址 `locate` 返回没有芯片。
2. 每个地址最多被一组芯片选中。
3. 各组片数之和等于结果里的芯片总数。
4. 同样的参数得到同样的 Trace，`validateTrace` 为空。

固定用例：`evals/golden/decode-book.json`：教材习题 7 的推算（p122）、解析书设计题 4 的地址分配（p52–53）、本站自拟一例。
不做：芯片挑选（几种芯片里选哪种）、2:4 以外的多级译码、ROM 写入、按字节编址的字节允许线。

## 待确认

- 无芯片的 ROM 跨几个 Y 时用与门合成片选，教材和解析书都没画这一步。
- 组大小缺省取最大的芯片字数；解析书两题都是 8K，与此一致。
