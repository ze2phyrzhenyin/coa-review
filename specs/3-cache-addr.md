# 3-cache-addr：cache 地址字段划分引擎

困惑：同一个地址，三种映射各切成哪几段。学完能由容量求出 w、r 或 d、u、s 和标记位数，写出地址格式，把十六进制地址切成字段（例 3.5–3.7 型）。
教材依据：3.6.2，p102–108，例 3.5（p107）、例 3.6（p107–108）、例 3.7（p108）；习题 13–15（p123）。
代码：`src/engines/cacheaddr/model.ts`，入口 `run(params)`；另有 `validateParams`、`widths(params)`、`generate(seed)`。位数和切分复用 `src/engines/cache/model.ts` 的 `layout`、`splitAddress`。

## 参数

| 名 | 取值 | 说明 |
|---|---|---|
| `mapping` | `全相联` `直接` `组相联` | |
| `rowsPerSet` | 2 的幂 | 每组行数 v，只有组相联用 |
| `unit`、`wordBytes` | `字`（缺省）或 `字节`；1、2、4、8（缺省 1） | 按字节编址时每块占 k × `wordBytes` 个地址，最低字段仍叫字地址 |
| `blockWords` | 2 的幂，≤ 2^16 | 每块字数 k |
| `memoryBlocks` 或 `memoryUnits` | 2 的幂，二选一 | 主存块数 2^s，或主存的编址单位数 2^(s+w) |
| `cacheRows` 或 `cacheUnits` | 2 的幂，二选一 | cache 行数 m，或 cache 容量（编址单位数）；全相联可不给 |
| `fields` | `{ tag, index, word }` | 直接给出各字段位数（例 3.5 型），此时上面的容量参数都不给；全相联 `index` 为 0 |
| `address` | 十六进制串，可选 | 要切分的地址，不带 H |

地址总位数 1–32；标记至少 1 位；行数、组数不超过主存块数。

## 要求

1. 按容量求位数时，步骤顺序跟例 3.6：w（2^w = 每块的编址单位数）→ 组相联时 v → r（m = 2^r）或 d（uv = m，u = 2^d）→ 组相联时 u → s（由块数；或由 s + w = 主存单位数的位数）→ 标记（全相联 s，直接 s − r，组相联 s − d）→ 地址长度 s + w。每个量一步，`explain`。全相联不求 r。
2. 给 `fields` 时跳过求位数，第一步写出给定格式，地址长度为三段之和。
3. 给了 `address` 时再加三步：十六进制 → 二进制（按地址长度补 0）；按位数切成三段；每段转回十六进制（例 3.5 的顺序）。
4. 中间一段的名字：直接映射叫「行号」，组相联叫「组号」，全相联没有这一段。条件里同时列出图中叫法 区号 | 区内块号 | 字地址（全相联除外）。
5. 状态 `w`、`v`、`r`、`d`、`u`、`s`、`tag`、`length` 为数字或 null，`format` 为地址格式串；`address` 为 null 或 `{ hex, bits, tagBits, indexBits, wordBits, tagHex, indexHex, wordHex }`，逐步填上。
6. `table` 列为 项目 | 算式或二进制 | 结果；每个求出的量一行，切分时地址、标记、行号或组号、字地址各一行，都指回对应的步。
7. `result` 有 标记位数、行号位数或组号位数（全相联没有）、字地址位数、地址位数、地址格式（如 `标记 8 位 | 组号 4 位 | 字地址 7 位`）；给了地址再加 标记、行号或组号、字地址，写十六进制带 H（如 `2EEEH`）。
8. 一段 0 位时（如每块 1 字），该段十六进制写「无」。
9. 预测题：求标记位数的那一步问「标记几位」（数字）；切分步问「标记是多少」（文本，答案如 `BBH`）。

## 场景

- WHEN 直接映射、给定格式 8 | 14 | 2、地址 BBBBBB THEN 标记 BBH、行号 2EEEH、字地址 3H。
- WHEN 组相联 64 行、每组 4 行、主存 4K 块、每块 128 字 THEN w = 7，d = 4，u = 16，s = 12，标记 8 位，地址 19 位。
- WHEN 全相联、按字节编址、主存 1M 字节、每块 16 字节、地址 B0010 THEN 标记 16 位、字地址 4 位，标记 B001H，字地址 0H。
- WHEN 组相联没给 `rowsPerSet`，或 `memoryBlocks` 与 `memoryUnits` 同时给 THEN `run` 抛出错误。

## 性质

1. 标记位数 + 中间段位数 + 字地址位数 = 地址位数。
2. 三段二进制拼起来等于地址的二进制。
3. 字地址 = 地址 mod 每块单位数；中间段 = 块号 mod 行数（直接）或 mod 组数（组相联）；标记 = 块号 ÷ 行数或组数取整。
4. 同样容量下，组相联的标记位数介于直接映射与全相联之间。
5. 同样的参数得到同样的 Trace，`validateTrace` 为空。

固定用例：`evals/golden/cacheaddr-book.json`：例 3.5、例 3.6、例 3.7、习题 15 的位数（自行推算 w = 2、r = 14、s = 22、标记 8 位），本站自拟 (A3C6)16 的直接映射与 2 路组相联。
不做：cache 总位数、有效位、找映射到同一行的两个地址（习题 14，留给练习出题器）。
