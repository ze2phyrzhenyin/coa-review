# 6-serial：串行帧与总线带宽引擎

困惑：一帧到底几位；波特率、字符速率、有效数据率各是什么；总线带宽里的 M 是多少。学完能画出一个字符的波形，算出这几个速率和带宽。
教材依据：6.2.1 串行传送低位在前（p208–209）；例 6.2 波特率和每位时间（p211，图 6.9）；总线带宽 Dr = D × f 和例 6.1（p204–205）；习题 3、10、19（p229–230）。
代码：`src/engines/serial/model.ts`，入口 `run(params)`；另有 `validateParams`、`frameBits(p)`（发送次序的 0/1 数组）、`rates(p)`（`{ frameLength, baud, charRate, bitTime, dataRate }`，bitTime 单位秒，没给速率的为 null）、`bandwidth(p)`（MB/s 数值）、`generate(seed, task?)`。

## 参数

`task` 二选一。

| 名 | 取值 | 说明 |
|---|---|---|
| `task: '串行帧'` | | |
| `code` | 0 到 2^dataBits − 1 的整数 | 字符编码；`char` 可选，只用于显示 |
| `dataBits` | 5–8 | 数据位数 |
| `parity` | `无` `奇` `偶` | 校验位，有则 1 位 |
| `stopBits` | 1 或 2 | 停止位位数；起始位固定 1 位 |
| `baud` 或 `charRate` | 正数，最多给一个 | 波特率（位/秒）或字符速率（字符/秒） |
| `task: '总线带宽'` | | |
| `widthBits` | 8 的倍数，8–256 | 一个总线周期并行传送的位数 |
| `freqMHz` | 正数，不超过 10000 | 总线时钟频率 |
| `clocksPerCycle` | 1–16 的整数 | 一个总线周期占几个时钟周期；例 6.1 是 1 |

## 要求

1. 帧的位必须按发送次序：起始位 0，数据位从最低位 D0 到最高位，校验位（如有），停止位 1。线路空闲为 1（p208–211，图 6.9）。
2. 奇校验使数据位和校验位里 1 的个数为奇数，偶校验为偶数。
3. 每帧位数 = 1 + dataBits + 校验位数 + stopBits。波特率 = 字符速率 × 每帧位数（例 6.2）；每位时间 Td = 1 ÷ 波特率；有效数据率 = 字符速率 × dataBits。
4. 带宽：D = widthBits ÷ 8 字节；总线周期 = clocksPerCycle ÷ f；Dr = D × f ÷ clocksPerCycle，单位 MB/s，M 取 10^6（例 6.1）。
5. 串行帧的步序：写出编码（`explain`）、求校验位（`explain`，无校验没有这步）、每一位时间一步（`beat`，依次是起始、D0…、校验、停止）、每帧位数（`explain`），给了速率时再有 波特率或字符速率、每位时间、有效数据率 三步（`explain`）。
6. 带宽的步序：化成字节、总线周期、带宽，三步都是 `explain`。
7. 状态（串行帧）：`codeBits`（编码，高位在左）、`ones`、`parityBit`、`line`（已发出的电平，按时间先后）、`current`（正在发的位的名称）、`frameLength`、`baud`、`charRate`、`bitTime`、`dataRate`；还没算出的为 null。状态（带宽）：`bytes`、`cycleNs`、`bandwidth`。
8. 预测题：D0 那一步问「先发哪一位」（选项 最低位 / 最高位）；校验步问校验位（`bits`）；每帧位数那一步问位数（`number`）；有速率时在速率步问结果（`number`）。带宽步问 MB/s（`number`）。
9. `table` 列为 项目 | 算式 | 结果，按纸面解题的先后，每行指回一步。串行帧的「发送次序」一行把整帧位串写在结果栏。
10. `result`：串行帧必须有 帧（发送次序的位串）、每帧位数，给了速率时加 波特率、字符速率、每位时间、有效数据率；带宽必须有 带宽。
11. 非整数结果写 4 位有效数字并带「≈」；每位时间一律用 ms（例 6.2 的写法）。
12. 参数不合格时 `run` 必须抛出错误，原因与 `validateParams` 相同。

## 场景

- WHEN 编码 0x53、7 位数据、偶校验、1 位停止 THEN 帧是 0 1100101 0 1，每帧 10 位。
- WHEN 编码相同、奇校验 THEN 校验位变 1，其余不变。
- WHEN 字符速率 150、帧 11 位 THEN 波特率 1650，每位时间 ≈ 0.6061 ms。
- WHEN 64 位、50 MHz、每个总线周期 2 个时钟 THEN 带宽 200 MB/s。

## 性质

1. 帧长 = 1 + dataBits + 校验位数 + stopBits；第一位 0，最后 stopBits 位都是 1。
2. 把数据位按发送次序当作从低到高拼回去，得到 `code`。
3. 奇偶校验：数据位加校验位里 1 的个数，奇校验为奇、偶校验为偶。
4. 波特率 = 字符速率 × 帧长，两种给法互逆；有效数据率 < 波特率。
5. 带宽与 widthBits、freqMHz 成正比，与 clocksPerCycle 成反比；同样参数同样 Trace，`validateTrace` 为空。

固定用例：`evals/golden/serial-cases.json`。例 6.2 的数值（120 字符/秒、10 位 → 1200 波特、0.8333 ms，p211）；例 6.1 的两组数值（132、528 MB/s，p205）；习题 10 的帧格式和波特率（7+1+1+1 位、9600 波特 → 960 字符/秒，p229）；两个手算字符波形。
不做：同步串行、曼彻斯特等编码、1.5 位停止位、突发传送的总线事务时间、PCIe 速率。
