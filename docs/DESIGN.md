# 视觉规范

负责人 2026-11-14：「更易懂」「更专业」「更美观」，「没有 AI 味」。方向：像一本排得好的教材，安静、清楚，颜色只用来表示含义。变量只在 `src/styles/tokens.css` 定义一次；新代码只用 `--c-*`、`--fs-*`、`--sp-*` 这些名字，不写死颜色和像素。反面清单见 `.agents/skills/no-ai-flavor/references/design.md`，这里不重复。

## 字

- 两个家族，都是系统字体，不下载：黑体 `--font-sans`（苹方、冬青黑体、思源黑体、微软雅黑），等宽 `--font-mono`（SF Mono、Menlo、Consolas，中文落回黑体）。不用 Inter、Roboto、Arial，不用衬线标题。
- 数、位串、地址、机器码、寄存器的值一律等宽（`.mono` 或 `<code>`），自带等宽数字；黑体里出现的数（步数、页码、计数）加 `font-variant-numeric: tabular-nums`（`.tnum`）。位串按教材分组，组间用窄空格 U+2009，不靠字距。
- 字号阶梯（16 px 为正文）：

| 变量 | 大小 | 用在 |
|---|---|---|
| `--fs-xs` | 13 | 侧栏章名、图例、出处「教材 p38」、页脚 |
| `--fs-sm` | 14 | 说明、次要文字、术语卡正文、分段控件 |
| `--fs-md` | 16 | 正文、按钮、输入框（输入框不许小于 16） |
| `--fs-lg` | 18 | 这一步的标题、首页的章名 |
| `--fs-xl` | 20 | 区块标题（少用） |
| `--fs-h1` | 26，手机 21 | 页面标题，全页唯一 |

- 字重只有 400 和 600。层级靠字号、字重、灰度和留白，不靠颜色、下划线、全大写。
- 行高：正文 1.7，标题 1.35，控件 1.25。正文一行不超过 `--measure`（42rem，约 40 个汉字）。
- 上下标：一律 `<sub>`/`<sup>`（页面里用 `Rich`），0.75em，不撑行距（`base.css` 已处理）。S<sub>f1</sub>、C<sub>0</sub>、2<sup>6</sup>、[x]<sub>补</sub> 这样排；字母正体，和场景一致。运算符两边留一个空格：`V = S_f1 ⊕ S_f2`。公式单独成行时居左，不居中，不加底色。

## 颜色

页面底色是近白的纸色，场景台面稍暗一点的纸色，像书放在桌上。颜色只表示含义，每种都同时配文字或形状。

| 变量 | 浅色 | 深色 | 含义 | 场景里 |
|---|---|---|---|---|
| `--c-page` | #faf9f6 | #181715 | 页面底色 | |
| `--c-surface` | #f6f3ec | #1f1e1b | 台面 | `paper` |
| `--c-raised` | #fffefb | #26251f | 浮层、输入框 | |
| `--c-ink` | #22211f | #ece9e2 | 正文 | `text` |
| `--c-muted` | #6f6a60 | #a8a397 | 次要文字（对底色 ≥ 5:1） | `muted` |
| `--c-line` | #e0dcd3 | #32302b | 列表和表格的细线 | |
| `--c-border` | #c9c3b6 | #4a4740 | 控件、舞台的边 | |
| `--c-line-strong` | #a8a294 | #6b675e | 章与章之间、没接通的线 | `line` |
| `--c-data` | #2c63a8 | #78a9e6 | 数据（实线） | `data` |
| `--c-addr` | #1e7d6b | #5fbfa8 | 地址（双线） | `addr` |
| `--c-ctrl` | #7a5195 | #b998d4 | 控制（虚线） | `ctrl` |
| `--c-change` | #d4472a | #f0795c | 变化（图形） | `accent` |
| `--c-change-text` | #c53d21 | #f0795c | 变化（文字，对台面 ≥ 4.6:1） | `accentOnTile` |
| `--c-ok` | #3b7a1c | #9acb6b | 正确，配「对」和 ✓ | 待加 `ok` |
| `--c-bad` | #b0184d | #f27a9e | 错误，配「不对」和轻摇 | 待加 `bad` |

- 变化用朱红，像老师的红笔；错误用偏紫的深红，两者色相差 30° 以上，而且错误总带字。正确用黄绿，和地址的青绿错开 70°。
- 当前项、悬停只用墨色的浅底（`--c-tint`、`--c-tint-strong`），不用彩色。主按钮是实心墨色，一屏最多一个。
- 不用渐变、发光、彩色阴影、大面积色块、有色底的提示框。
- 墨色以 `src/scene/theme.ts` 为准；`src/styles/tokens.test.ts` 核对两边一致，改一边就要改另一边。旧名 `--ink` `--paper` `--line` `--mark` 仍然有效（指向新变量），新代码别用。

## 间距、圆角、线、阴影

- 间距只用 4 的倍数：`--sp-1`…`--sp-8` = 4、8、12、16、24、32、48、64。相关的东西靠近（8–12），不同区块之间 24–32。
- 圆角三档：`--r-sm` 4（位格、标签）、`--r-md` 8（按钮、输入框、术语卡）、`--r-lg` 12（舞台）。不用更大的圆角，不用药丸形。
- 线 1 px。表头下一条墨线，行间细线，章与章之间 `--c-line-strong`。
- 阴影只给浮在上面的东西（术语卡、贴在部件旁的答题框）：`--shadow-float`。卡片不加阴影，卡片里不再套卡片。
- 焦点：全站一种，2 px 实线 `--c-focus`（墨色），离开元素 2 px。只在键盘操作时出现（`:focus-visible`）。

## 动效

- 一族三次曲线：到达用 `--ease-out`（减速），镜头和换位用 `--ease-in-out`。和 `src/scene/motion.ts` 的 `easeOut`、`easeInOut` 是同一族。不过冲，不弹跳。
- 时长：颜色和按下 `--dur-fast` 120 ms，浮层出现 `--dur-base` 200 ms（只淡入，不位移），场景移动 280–900 ms 按距离，镜头 760 ms（`theme.ts` 的 `timing`）。
- 系统要求减少动态效果时四个时长都是 0。界面上没有入场动画、悬停位移、数字滚动。

## 控件（`src/styles/components.css`）

- 触控目标不小于 44 × 44 px（`--target`）；行内术语用透明的内边距把点的范围扩到 44 px，字不动。
- 按钮 `.btn`：描边，44 px 高，16 px 字；`.is-primary` 实心墨色；`.is-quiet` 只有下划线（「看答案」「重置」这类）。文字用「动词 + 对象」，2–6 个字。
- 分段控件 `.seg`：几个互斥的选项连成一条浅底，选中的实心墨色，按钮带 `aria-pressed`。选例题、粒度、映射方式用它；例题是算式时加 `.is-mono`。手机上放不下五项以上时换成 `.select`。
- 标签页 `.tabs` > `[role=tab]`：灰字，当前页墨色加 2 px 下划线。只用于讲解、试一试、练习、弄坏它这一层。
- 输入框 `.input`、下拉 `.select`：44 px 高，16 px 字，底色 `--c-raised`；填数用 `.is-mono`。表单 `.field`：标签在上（14 px 粗），说明在标签下一行（灰），错误在输入框下方（`--c-bad`），占位符只放格式示例。
- 判分：`.is-ok-text`、`.is-bad-text` 只改字色，旁边必须有「对」「不对」。
- 考试版式的表 `.sheet`：表头墨线，44 px 行高，数等宽右对齐，可以直接照抄到卷子上。

## 版面

- 桌面：左侧栏 `--nav-w` 15rem，细线隔开，单独滚动；正文区最大 `--content-max` 76rem，靠左，左右留白 `--gutter`（16–40 px）。舞台可以占满正文区，讲解文字不超过 `--measure`。
- 侧栏从上到下：站名（18 px 粗）、章名（13 px 灰，「第 2 章 运算方法和运算器」）、页面短名（14 px，44 px 高）。当前页是 600 字重加浅底，不用彩色、不用竖条。
- 手机（≤ 720 px）：顶栏一行 52 px（站名、「章节」按钮），展开的章节列表最多占六成屏高。正文左右 16 px；舞台贴满屏宽。
- 每页底部一行页脚：教材全名、版次、出版社、年份。

## 首页

- 标题「计算机组成原理」，下面不加副标题。
- 「上次学到」：一行，灰色标签加页面短名和「讲解，第 3 步」，点了回到当时的网址。记录在本机 localStorage（`src/app/last-visit.ts`，读写都包在 try/catch 里），没有记录就整行不出现。
- 目录照教材目录页的样子：左栏「第 n 章」，右栏章名；每页一行：短名、它回答的问题、教材页码。还没有页面的章只留灰色章名。不放统计数、图标、卡片。

## 术语卡

`src/content/glossary.ts` 是全站共用的词表：术语、别名、一句定义（自己的话，≤ 70 字）、教材页码、本站讲它的页面。`src/app/TermCard.tsx` 导出 `Term`：

```tsx
import { Term } from '../../app/TermCard';
<p>两数都写成<Term k="变形补码" />，结果的 <Term k="S_f1" /> 表示正负。</p>
<Term k="缺失">没命中</Term>   // 显示自己的字，按 k 查卡片
```

- 每个术语只在一页里第一次出现时包 `Term`（讲解的条件区、第一个用到它的步骤），之后照常写字。按钮、标签页、场景里的字不包。
- 点一下或 Tab 到它按 Enter 打开；再点、Esc、点别处、焦点离开、滚动都会关上；同时只开一张。卡片写术语、定义、「教材 p38」，术语在别的页讲时附那一页的链接。
- 词表里没有的词，`Term` 原样显示文字，不报错；需要新词先加进 `glossary.ts`（`src/app/glossary.test.ts` 会查重名、页码格式、句号）。
- 卡片用 `position: fixed`，祖先元素不能有 `transform`、`filter`、`contain`，否则位置会错。
