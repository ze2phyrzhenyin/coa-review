文字规则以 `.agents/skills/no-ai-flavor` 为准（先读 `SKILL.md`，做界面再读 `references/design.md`）。这里只补本项目自己的。

## 标题

- 页面只有一个标题：学生会问的那句话，不带问号。侧栏用名词短名。两者都在 `src/content/pages.ts`。
- 页面里不再写小标题下的说明行。

## 术语

- 用教材的说法。对照表在 `scripts/terms.json`，门禁会查。第七版改了名的（成组连续传送、周期挪用、透明 DMA、分散式刷新），用新名，旧称只在该页出现一次并在那一行注 `terms-ok`。
- cache 一侧叫「行」，主存一侧叫「块」。最低字段叫「字地址」。
- CPU 周期、节拍、指存、数存、三态门、微命令、微指令，照教材写法。

## 数和记号

- 二进制位串按教材分组，定点小数写出小数点（`11.10001`）。十六进制用 H 后缀（`0AC5H`），与教材一致。
- 机器码写 `[x]补`、`[x]原`、`[x]移`、`[x]变补`。
- 公式里的量用教材的字母：h、t_c、t_m、t_a、e、r；T_k、T_p、C_k。
- 容量写「字数×位数」，K、M 是 2^10、2^20。
- 教材出处写「教材 p53」「教材 例 2.25」。只引页码，不引原文。

## 每一步的两句话

- 做了什么：主语是部件或数，写清从哪到哪。例：「R2 的值经 C2 上 DBUS，打入 DR」。
- 为什么：写触发它的条件或规则，一句。例：「DBUS 一拍只能传一个值，地址已经在上一个 CPU 周期送进 AR」。
- 不写感受和评价，不写「注意」「非常重要」。

## 题面

- 自己的话，自己的数。条件写全：位宽、编址单位、初始状态、约定。
- 一道题只问一件事；连问的分成小问。
