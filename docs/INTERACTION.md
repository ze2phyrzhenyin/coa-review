# 交互、场景和动效

负责人的要求（2026-11-14）：交互做到最好；学生能理解；动画精美、有趣、好玩；交互和答题都在 3D 场景里；没有 AI 味。做页面、审页面都按这份。文案另见 `.agents/skills/no-ai-flavor`。

## 三件事

每一步都显示：现在的状态、这一步为什么能发生、哪里变了（旧值和新值）。只让一条线闪一下不算讲解。三样都来自 Trace（`src/engines/trace.ts`），页面不自己编。

## 操作

- 下一步：`→` 或空格。上一步：`←`。回到开头：`Home`。按钮和键盘等价。
- 点解题表或步骤列表里的任一行，直接跳到那一步。
- 回退是精确的：回到第 n 步，画面与第一次到第 n 步时相同。
- 输入永远优先。动画没播完时按下一步，当前动画立刻到位，再开始下一段。长按可以快速连翻，不排队。
- 默认不自动播放。有「播放」时可以调速、可以随时停。
- 步数、参数、所选例题都写进网址（步数用参数 `s`）。刷新、分享、浏览器返回，回到同一画面。
- 步的粒度有三层：讲解小步、一个节拍或一次访问、一个 CPU 周期或一条指令。同一拍里为了讲清楚拆开的小步标为讲解步，不冒充多个时钟。

## 场景

- 整站是同一个 3D 实验台，风格是桌面教具：哑光的实体部件摆在纸一样的台面上，柔和的棚拍光，有接触阴影。不要霓虹、发光描边、辉光、渐变、深色机房。
- 颜色表示含义，全站一致：数据、地址、控制信号各用一种墨色；变化用同一种强调色。颜色都同时配文字或形状，不靠颜色单独区分。
- 文字、位串、表格始终正对屏幕，任何时候都读得清。文字用系统字体，不下载字体。
- 构图固定：部件不在步骤之间换位置。镜头只在焦点移出画面时平滑移动，不旋转世界；学生可以小幅转动和缩放，双击复位。
- 手机上镜头跟着当前步骤走，不把整张图缩成小图。
- 场景只由 Trace 的状态决定。同一步的画面每次都一样。
- 场景里每个可操作的部件都有对应的页面控件（可以只对键盘和读屏可见），`Tab` 能走到，`Enter` 能选。
- 不支持 WebGL 或设备太旧时用平面模式：同样的步骤、文字、解题表和答题控件。

## 在场景里答题

- 预测题出现在有辨别力的步骤上，不是每一步都问。
- 回答就是动手：点选接收的寄存器、把值拖上总线、翻位片、选 cache 的行。要填数时，输入框贴在对应部件旁边，文字不小于 16 px。
- 答错时场景按学生的答案演一遍后果，再退回让他重选，并指出该看哪里。不只给一个叉。
- 随时可以直接看答案，不卡住进度。
- 「弄坏它」：允许故意做错的操作，后果演出来，并说明真实硬件里会怎样。
- 纸面题是台面上的一张答题纸，按考试版式填表，不给动画。

## 形象、直观、有趣

负责人 2026-11-14：「希望动画更形象更直观更有趣」。做法是让机制本身变成看得见、摸得着的东西，不加与内容无关的装饰。

### 比喻（每个主题选一个，全站一致）

| 主题 | 实物 | 关键动作 |
|---|---|---|
| 补码、溢出 | 刻度盘（模 2^n 的一圈）加数轴 | 加法是指针转过的格数；溢出是指针越过 +最大 与 −最小 的接缝，接缝处亮起 |
| 进位 | 位片 | 进位是一枚小片从这一列跳到左边一列，落下时左边的位片翻面 |
| 乘法 | 位积方阵 | 部分积一行行落下，斜着对齐；加法器一格格亮起，进位顺对角线流走 |
| 除法 | 天平 | 余数和除数比较时天平倾斜，够减就上商 1，不够就上商 0 并改为下一步加 |
| 浮点 | 带放大镜的尺子 | 对阶时小阶数的尾数向右滑，移出去的位掉进旁边的小盒子（舍入要用）；规格化时小数点滑动 |
| 总线、三态门 | 轨道和闸门 | 闸门真的抬起、落下；值是一张卡片，沿轨道滑到接收的寄存器，打入时寄存器盖子合上「咔」一下 |
| 控制信号 | 沿控制线跑的脉冲 | 信号先从控制器出发，沿虚线跑到部件，部件才动；脉冲和电位用不同形状 |
| 时序 | 节拍盘 | T1–T4 四格依次点亮；打入动作和对应的格子同时发生 |
| 存储器扩充、译码 | 芯片插在板上 | 地址线是一束线，按位分开插进芯片；片选线从译码器伸出，选中的芯片抬起 |
| cache | 抽屉柜（主存）和小格架（cache） | 标记比较是两张卡并排对齐，一致就扣上，不一致就弹开；换出的块从格架滑出，修改位为 1 的先送回抽屉 |
| 虚存、页面替换 | 传送带（a 进 c 出） | 新页从 a 端进，整排后移，c 端的页掉下去；命中时那一页被拎回 a 端（FIFO+LRU） |
| 流水线 | 装配线 | 指令是盒子，在各工位间前进；停顿是一个空泡塞进装配线，后面的盒子原地等 |
| 相关 | 两条指令之间的连线 | 写的寄存器和读的寄存器之间拉一根线，RAW、WAR、WAW 各用一种线形 |
| 总线仲裁 | 接力棒 | 链式查询时授权像接力棒沿链往下传，被第一个举手的设备接住 |
| 中断 | 一叠程序卡 | 响应中断时当前程序卡被压到下面，断点写在卡角上；返回时抽回上面那张 |
| DMA | 货车 | DMA 控制器接管总线把一车数据直接拉进内存，CPU 那边的闸门暂时落下 |

### 编排

- 每个动作分三拍：起因（信号到达、条件成立，短促提示）→ 移动 → 落定（部件盖合、数字翻好、读数更新）。落定要有一点回弹感，只在这一下。
- 主角一次只有一个：其他部件变淡一点，动作结束再恢复。
- 能用位置和形状说明的，不写字。字只放在落定后的读数上。
- 学生答错时演他的选择：卡片真的飞向他点的部件，然后被弹回或撞车；不只亮红字。
- 「弄坏它」要夸张一点：总线冲突时两张卡片撞在一起冒出火花状的碎片，然后复位。
- 声音：可选的轻微音效（翻片、合盖、撞车），默认关闭，开关在页面上，选择记住。

### 不做

吉祥物、表情、彩带、计分动画、与当前步骤无关的循环动画、霓虹和发光。

## 易懂、专业、美观

负责人 2026-11-14：「更易懂」「更专业」「更美观」。

### 易懂

- 第 0 步是全景：整套部件都在，标出这一页要回答的问题落在哪里，再开始走。
- 讲解的最后一步是一句话结论，回答页面标题那个问题，可以直接抄进笔记。
- 每个术语第一次出现时可以点开看一句定义和教材页码（术语卡，全站共用一份词表）。没出现过的术语不进题目。
- 先讲一道完整的例子，再给只改一个条件的变式，最后才是练习。
- 常见错误单独列出：每页两三条，写成「容易错成 X，因为 Y」，点开能看到这个错法在场景里会怎样。
- 页面开头写一行「需要先会」，链接到前置页面。

### 专业

- 记号和教材一致：[x]补、[x]变补、S_f1、C_f、t_a、T_k 这类写成规范的上下标；公式用排版好的数学式，不用纯文本拼。
- 每一步标教材出处；用到教材没讲的规则时（比如 LRU 计数范围），在那一步标「本站约定」。
- 解题表的版式就是考试答题的版式，可以直接照着写在卷子上。
- 数值带单位，进制标清楚（二进制位串分组、十六进制加 H）。
- 不为了好看简化成错的说法。拿不准的地方宁可写明两种口径。

### 美观

- 全站一套视觉规范（`docs/DESIGN.md`）：字体、字号阶梯、颜色、间距、圆角、阴影、控件样式，在 CSS 变量里定义一次。
- 场景的材质、灯光、颜色和页面的控件来自同一套颜色。
- 任何一步停下来截图，都要像教材里排好的插图：对齐、留白、线宽一致。

## 动效标准

「精美」的检查项。审看时逐条过。

1. 每个运动有起点、路径、落点。值从具体的出口出发，沿真实的连线走，落到接收的部件里；旧值被顶出或淡出，看得见它去了哪。
2. 一次只讲一条因果：起因、移动、结果、读数更新，依次发生。硬件里同一拍发生的事一起动，并标明是同一拍。
3. 时长随距离：一次移动 280–900 ms。多位一起动时逐位错开 20–40 ms，方向与进位或移位方向一致。
4. 缓动只用一族：到达用减速，镜头用先加速后减速。弹跳只用在有含义的地方（进位跳到左边一列，被拒绝的选择轻摇）。
5. 镜头移动 600–900 ms，移动中文字不糊。
6. 学生没操作时画面静止。只有题目里真有时钟的地方才有节拍指示。
7. 任何一步停下来截图，都像一张排好版的插图：对齐、间距、线宽、字号一致。
8. 转场 60 帧，手机上不掉帧。只动位置、缩放、透明度；空闲时不重绘。
9. 系统设置了减少动态效果时，位移改为直接切换，内容不少。
10. 不做：整屏淡入上滑、数字滚动、脉冲圆点、悬停位移、自动轮播、与内容无关的粒子和光效。

## 手机

- 按 360–390 px 宽设计和检查：不横向滚动，触控目标不小于 44 px，输入框文字不小于 16 px。
- 控制条在拇指够得到的底部。键盘弹出时答题框不被遮住。

## 自动检查靠的约定

- 播放器根元素 `[data-player]`，属性 `data-step-index` 是当前步数（0 是初始状态）。
- 场景容器 `[data-stage]`：画面稳定后 `data-settled="true"`，`data-scene-hash` 是当前画面目标状态的摘要。
- 可点选的部件有对应的 `button[data-pick="<位置 id>"]`。
- 细节见 `specs/_player-contract.md` 和 `specs/_scene-contract.md`。
