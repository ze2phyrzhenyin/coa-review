### 1. 虚存 + TLB + cache 的地址变换（统考综合 9 次）

- 出处：2011-44、2014-45（后半）、2016-45、2018-44、2019-46、2021-44、2023-43；只考 cache 的 2010-44、2020-44。选择题另有 10 道同类小题。
- 结构：给出虚拟/物理地址空间、页大小、cache 组织方式和块大小，再给一张页表、TLB 或 cache 内容表（或一张访问过程示意图），问字段划分、某个虚拟地址是否在主存、对应的物理地址、cache 是否命中、cache 总容量。
- 典型参数：虚拟地址 24–32 位，物理地址 20–28 位，页 4KB 或 8KB；cache 8 行直接映射，或 2/4/8 路组相联，块 32B 或 64B，数据区 512B–64KB；TLB 全相联或 2/4 路组相联。
- 步骤：
  1. 页大小定页内偏移位数；虚页号位数 = 虚拟地址位数 − 偏移位数；页框号位数 = 物理地址位数 − 偏移位数。
  2. 物理地址从低到高分成块内地址、组号（直接映射时是行号）、标记。组数 = 数据区容量 ÷（块大小 × 路数）。
  3. 拿到一个虚拟地址：取虚页号，先查 TLB（组相联 TLB 用虚页号低位选组、高位作标记），缺失再查页表；有效位为 0 就是缺页。
  4. 页框号拼上页内偏移得物理地址，再按第 2 步拆开，到 cache 对应行/组比较标记，同时看有效位。
  5. cache 总位数 = 行数 ×（数据位 + 标记位 + 有效位，回写策略加 1 位脏位，LRU 再加替换位）。
- 页内偏移相同这一点常被用来直接从虚拟地址读出 cache 组号（2018-44、2019-46）。

### 2. 数组访问的 cache 命中率（统考综合 4 次，选择 1 次）

- 出处：2010-44、2014-45、2020-44、2023-43；选择 2016-15。
- 结构：一段 C 循环顺序读写 int 数组，问缺失次数或命中率；有时比较按行与按列两种循环次序。
- 典型参数：int 占 4B；块 16B、32B 或 64B；数组 1000–1024 个元素，或 256×256、24×64 的二维数组；数组首地址给定（用来确认是否对齐到块边界）。
- 步骤：每块能放的元素数 = 块大小 ÷ 4；顺序访问时每块只缺失第一次，命中率 =（每块访问次数 − 1）÷ 每块访问次数；同一元素先读后写算两次访问；按列访问时要判断同一行/组里的块在再次用到之前是否已被换出（容量够大、路数够多时命中率不变，2023-43 就是这样）。

### 3. 数据通路 + 控制信号（统考综合 4 次；第11章设计题 4 道）

- 出处：2009-44、2015-43、2015-44、2022-43；设计题 11–14（p189–191）。
- 统考结构：给一张单总线（内总线）CPU 结构图，寄存器的输入/输出控制信号记作 Xin/Xout，有 MAR、MDR、IR、PC、ALU 和一两个暂存器。问法有三种：按时钟节拍列出"功能 + 有效控制信号"；补全图中缺的连线或说出某部件是什么；问控制信号位数、为什么要暂存器、取指需要几个时钟周期。
- 典型参数：字长 16 位，定长 16 位指令，4 个通用寄存器 R0–R3；ALU 7 种操作、移位器 3 种操作；一个 CPU 周期含 4 个节拍 C1–C4。
- 步骤：取指固定为 PC→MAR；读主存到 MDR，同时 PC 增量；MDR→IR；译码。执行阶段按寻址方式逐拍写：每拍总线上只能有一个输出源；ALU 的一个操作数必须先进暂存器；访存前先把地址送 MAR。控制信号位数 = 对操作种数取以 2 为底的对数再向上取整。
- 第11章结构：双总线（A 总线、B 总线）数据通路，寄存器输入信号带下标 i、输出信号带下标 o，G 是总线间的门。要求画指令周期流程图：一个方框是一个 CPU 周期，框右写微操作控制信号，取指和执行分段标出。这是教材第5章的画法。

### 4. 指令格式 + 寻址方式 + 机器码（统考综合 4 次）

- 出处：2010-43、2013-44、2021-43，2015-44 前半，2014-44 前半；设计题 10。
- 结构：给出指令字各字段和寻址方式编码表，问最多多少条指令、多少个寄存器、MAR/MDR 位数、转移范围；把一条汇编指令译成十六进制机器码，或反过来；给出寄存器和主存初值，问执行后哪些内容改变。
- 典型参数：16 位定长指令，操作码 4–7 位，寄存器号 2–3 位，寻址方式 1–3 位，偏移量 8 位补码；2014 年是 32 位、6+5+5+16 的类 MIPS 格式。
- 步骤：字段位数决定条数和寄存器数；MAR 位数由主存单元数定，MDR 位数由字长或数据线定；相对转移目标 = PC 当前值 + 本指令长度 + 偏移量 × 每条指令占的地址数（由"下一条指令地址 = PC+2 或 PC+4"反推编址单位）；带自增的寻址要记得寄存器本身也变。

### 5. 流水线阻塞与时空图（统考综合 2 次，选择 9 次）

- 出处：2012-44、2014-44 后半；选择 2016-19、2019-18、2023-19 等；计算题 9–11。
- 结构：五段流水线 IF、ID、EX、M、WB，给出指令序列，问哪些指令被阻塞、原因、总共多少时钟周期，或要求画时空图。
- 典型参数：4–6 条指令；不采用转发；同一寄存器的读写不能在同一周期；分支引起 3 个周期阻塞。
- 步骤：找出后一条指令读、前一条指令写的同一寄存器；不转发时后一条的 ID 要排到前一条 WB 之后；前面指令停在 ID 时后面指令的 IF 也跟着停；无阻塞时 n 条指令需 5 +（n − 1）个周期。有转发时只剩"取数后立即使用"这一种要停。
- 第11章的流水线题只到时空图和 k + n − 1 的时间公式，不涉及相关。

### 6. 整数/浮点表示与 C 语言（统考综合 3 次；选择题里补码、C 类型转换、IEEE 754 三行合计 23 道）

- 出处：2011-43、2017-43、2020-43。
- 结构：给一小段 C 代码，变量类型有 unsigned、int、short、float，问寄存器里的机器数、变量的十进制值、是否溢出、两种类型结果为何不同。
- 典型参数：8 位或 32 位字长；数值取在边界附近（如 134 与 246、2 的 24 次方附近、2 的 31 次方附近）。
- 步骤：先写出机器数，再按类型解释；无符号与带符号加减用同一个加法器，区别只在溢出判断；带符号溢出看最高位进位与符号位进位是否不同；float 只有 24 位有效数字，超过后要舍入；阶码全 1、尾数全 0 表示无穷大；乘法取低 n 位时用高 n 位（带符号是高 n+1 位）判溢出。

### 7. x86 机器级代码分析（统考综合 3 次）

- 出处：2017-44、2019-45、2023-44。
- 结构：给 C 函数和反汇编清单（行号、虚拟地址、机器码、汇编指令），问 CISC 还是 RISC、代码占多少字节、某条转移指令的偏移量、大端还是小端、某条指令执行后的标志位、是否在同一页。
- 步骤：指令长度不等即 CISC；代码长度 = 末指令地址 − 首指令地址 + 末指令长度；相对转移偏移 = 目标地址 −（本指令地址 + 本指令长度）；把机器码里的立即数或偏移量字节序与数值对照判断端模式。
- 这一类教材没有对应内容，见"注意"。

### 8. I/O 方式的 CPU 开销（统考综合 3 次，选择 3 次；第11章分析题 7 道）

- 出处：2009-43、2016-44、2018-43；选择 2011-22、2014-22、2019-21；分析题 16–18、20–22、25。
- 结构：给 CPU 主频、CPI、设备数据传输率和接口缓冲寄存器宽度，分别按定时查询、中断、DMA 计算 CPU 用于该设备的时间占比，或判断某设备能否用中断方式。
- 典型参数：主频 50MHz–1GHz，CPI 4 或 5；设备速率 50KB/s–40MB/s；缓冲寄存器 32 位；一次查询 10 条指令或 500 个时钟周期；一次中断 20 条指令或 400–1000 个时钟周期；DMA 块 1000–5000B，预处理加后处理 500 个时钟周期。
- 步骤：每秒请求次数 = 设备速率 ÷ 每次传送的字节数（中断/查询按缓冲寄存器宽度，DMA 按块大小）；每次开销换成时钟周期（指令数 × CPI）；占比 = 每秒次数 × 每次开销 ÷ 主频。判断中断是否可行：比较设备准备好一次数据的时间与一次中断的处理时间，前者更短就会丢数据。
- 2016-44 加了异步串行帧：1 位起始 + 7 位数据 + 1 位校验 + 1 位停止 = 10 位，并区分"完成任务的总时间"和"CPU 实际花的时间"。

### 9. 性能 + 存储 + 总线的串联计算（统考综合 2 次）

- 出处：2012-43、2013-43。
- 步骤：MIPS = 主频 ÷（CPI × 10 的 6 次方）；每秒缺失次数 = 每秒指令数 × 每条指令访存次数 × 缺失率；主存带宽至少 = 每秒缺失次数 × 块大小；总线带宽 = 每个时钟周期传的字节数 × 总线时钟频率；一次突发读事务 = 1 个地址周期 + 存储器准备时间 + 数据周期数 × 总线时钟周期；CPU 时间 = 指令数 × CPI × 时钟周期 + 缺失次数 × 一次缺失的额外时间；m 体交叉存储器连续读的带宽 = m 个字的信息量 ÷ 一个存储周期。

### 10. 教材风格的 cache 地址格式题（第11章 14 道，模拟卷选择 4 道）

- 出处：分析题 9–15，设计题 3–9；模拟卷四第5题、五第4题、七第3题、八第4题。
- 结构：给主存容量、cache 容量、块大小和映射方式，求各字段位数并画地址格式；或给一个十六进制地址，拆出标记、行（组）、字的值。
- 典型参数：主存 16M×32 位、cache 64K×32 位、块 4 个字（按字编址）；或主存 1MB、cache 64KB、块 16B；每组 2 行或 4 行。
- 记号（教材第3章，p102–105）：块内字地址 w 位，主存块号 s 位，直接映射的行号 r 位、标记 s − r 位；组相联的组号 d 位、标记 s − d 位；全相联标记 s 位。
- 步骤：块大小定 w；主存容量定 s + w；cache 行数定 r，或组数 = 行数 ÷ 每组行数定 d；余下是标记。

## 注意

### 统考题与教材在约定上的差别

1. 编址单位和 cache 用语。统考题几乎都写"按字节编址"，块大小以字节计，字段叫 Tag、组号（组索引）、块内地址。教材和第11章的 cache 题多按字编址，字段用 s、r、d、w 表示，cache 一侧叫"行"，主存一侧叫"块"（教材 p102–105）。同一道题换一种说法答案不变，页面上两套名称应并排标出。
2. 组相联的地址划分。解析书在 2012-17 的答案里给了两种解法和两个答案（A 或 C，p208），原因是"三段地址"和"四段地址"两种理解。出这一类练习时要写明用哪一种。
3. 浮点数。教材和统考都用 IEEE 754（教材 p27–29，含无穷大、NaN、非规格化数）。教材的浮点加减例题还用"阶码、尾数都是补码，双符号位"的格式（教材 p62–64），2009-13 是这种格式；2010 年以后的统考题只用 IEEE 754，并和 C 的 float/double 绑在一起。
4. 标志位。教材记作 C、Z、N、V（教材 p141、p152）；统考记作 CF、ZF、SF（或 NF）、OF，并采用 x86 的约定：减法时 CF 表示借位（2017-44、2018-19、2023-16）。
5. C 语言。大纲的考查目标第 3 条要求能分析 C 程序中的相关问题（p250）。教材里 C 语言只在少数几页出现（教材 p12–16、p141–145），没有类型转换、struct 对齐这类内容。统考选择题里这类题约 8 道，综合题 3 道以上。
6. 指令集。教材第4章讲了 MIPS R4000 的 R/I 型格式（教材 p131–132）、IA-32 指令格式（教材 p132）和 ARM 汇编（4.5 节），全书检索不到 RISC-V。2014-44 的类 MIPS 代码能和教材对上；2017、2019、2023 年的 x86 反汇编题在教材里没有对应练习，"过程调用"一词全书检索不到。大纲"指令系统"下的"高级语言程序与机器级代码之间的对应"（p251）教材基本未覆盖。
7. 数据通路的画法。统考是单总线内总线 + 按时钟节拍的控制信号表，信号名 Xin/Xout。教材和第11章是 CPU 周期为单位的指令周期流程图，框外标微操作控制信号。教材只讨论多周期 CPU（教材 p153），"操作元件/状态元件"这两个词教材检索不到（2023-18 用到）。
8. 流水线用语。教材叫资源相关、数据相关、控制相关，解决办法叫后推法、定向（旁路）（教材 p189–191），p189 提到"冒险"是同义说法。统考叫结构冒险、数据冒险、控制冒险、转发、阻塞。段名 IF/ID/EX/MEM/WB 两边一致。
9. 中断与异常。教材 8.3.1 节把中断看作广义异常的一种，狭义异常也叫内中断（教材 p263）。统考常用的"故障、陷阱、终止"三分法、"中断隐指令"、"中断屏蔽字"、"不可屏蔽中断"这几个词在教材正文里检索不到；教材用的是"中断屏蔽触发器、中断屏蔽寄存器"（教材 p265–270），"终止"只出现在 ARMv8-A 小节（教材 p273–274）。屏蔽字题型的具体写法以第8章摘要为准。
10. DMA。教材的名称是成组连续传送方式（停止 CPU 访存）、周期挪用方式（周期窃取）、透明 DMA 方式（DMA 与 CPU 交替操作）（教材 p276–278）；解析书第8章仍用旧称"停止 CPU 访问内存、周期挪用、DMA 与 CPU 交替访内"（p126–127）。统考默认周期挪用，并反复用两条结论：缓冲寄存器每填满一次发一次总线请求；DMA 的总线优先级高于 CPU（2012-43、2020-22、2022-44）。第11章解答里还出现"突发模式""停止 CPU 访内"的说法。
11. 总线。带宽公式两边一致。统考的"总线事务""分离事务"在教材里检索不到；"突发（猝发）传送"教材在 6.4.2 节的块传送（教材 p218）和 PCI 一节（教材 p219–222）里讲，半同步定时在教材 p216–217。
