## 记号与约定

### 指令格式（p127–133）
- 指令字 = 操作码字段 OP + 地址码字段 A。地址码个数：三地址 `A3←(A1)OP(A2)`，二地址 `A1←(A1)OP(A2)`，一地址 `AC←(AC)OP(A)`（AC 为累加寄存器，隐含操作数），零地址只有 OP。
- `(X)` 表示 X 单元/寄存器的内容，`←`、`→` 表示传送。A1 称源操作数地址，A2 称终点操作数地址，A3 为结果地址（p129 原文如此）。
- 二地址指令按操作数位置分：SS 型（存储器-存储器）、RR 型（寄存器-寄存器）、RS 型（寄存器-存储器）。RR 最快。
- 指令字长度与机器字长比较：单字长、半字长、双字长；等长指令字结构 / 变长指令字结构。
- 带寻址特征的单地址格式（p135）：`OP | X（变址） | I（间址） | A（形式地址）`。形式地址 A 也称偏移量。p136 提到"由寻址模式给予指示，如 X1=0"。
- 例 4.4 与习题 6 用另一套字母：`OP | — | 通用寄存器 | I | X | 偏移量 D`，有效地址写作 E。字段位数 6/（未标）/4/1/2/16（p140）。
- 注意 D 有两个意思：p136 "D 表示操作数，D=(A)"；例 4.4、习题和解析书里 D 是偏移量/位移量/形式地址。页面上要按题目给的字母显示。
- 助记符（表 4.3，p130）：ADD 001，SUB 010，MOV 011，JMP 100，JSR 101，STO 110，LAD 111。取数是 LAD，存数是 STO；书中多处又写成 LDA（p156、习题 16、17），解析书用 LDA、STA。

### 扩展操作码（例 4.1、表 4.2，p129–130）
16 位等长指令，4 位基本 OP + 三个 4 位地址字段 A1、A2、A3。做法是"向地址码字段扩展操作码"：

| 类别 | 操作码编码范围 | 条数 | 留作扩展的编码 |
|---|---|---|---|
| 三地址 | 0000～1110 | 2^4−1=15 | 1111 |
| 二地址 | 1111,0000～1111,1101 | 2^4−2=14 | 1111,1110 与 1111,1111 |
| 一地址 | 1111,1110,0000～1111,1111,1110 | 2^5−1=31 | 1111,1111,1111 |
| 零地址 | 1111,1111,1111,0000～1111,1111,1111,1111 | 2^4=16 | — |

通用关系（解析书 析18、设9 的做法）：每留下 1 个上一级编码，下一级多出 2^(地址位数) 个编码。

### 寻址方式（p134–141）
指令寻址：顺序寻址（PC 加 1）、跳跃寻址（下条指令地址由本条指令给出）。
数据寻址，表 4.5（p135）的名称与算法：

| 方式 | 算法 | 备注 |
|---|---|---|
| 隐含寻址 | 操作数在专用寄存器 | 如 AC、AX |
| 立即寻址 | 操作数=A | 地址字段就是操作数（立即数） |
| 直接寻址 | EA=A | 操作数 D=(A) |
| 间接寻址 | EA=(A) | I=0 直接，I=1 间接；两次访存 |
| 寄存器寻址 | EA=R | 地址字段是寄存器编号 |
| 寄存器间接寻址 | EA=(R) | |
| 偏移寻址 | EA=A+(R) | 分三种，见下 |
| 段寻址 | EA=A+(R) | 段寄存器 16 位左移 4 位 + 16 位偏移 → 20 位物理地址 |
| 堆栈寻址 | EA=栈顶 | 需要堆栈指示器 |

- 相对寻址：EA=A+(PC)，A 看作补码，可正可负。
- 基址寻址：寄存器里是基地址，A 是偏移量（通常无符号）。
- 变址寻址：A 是主存地址，寄存器里是正偏移量；例：EA=A+(R)，R←(R+1)。
- 例 4.4 的写法（p140）：E=D 直接；E=(PC)±D 相对；E=(R2)±D 变址；E=(R3) 寄存器间接；E=(D) 间接；E=(R1)±D 基址。解析书 析6 再加三种复合：先相对后间接 E=((PC)±D)、先变址后间接、先基址后间接。
- 相对寻址里 PC 取什么值：表 4.5 写"当前 PC 的内容"；IA-32 一段写"下一条指令地址"（p140）；解析书 析10 直接用题目给的 (PC) 相加，不再加指令长度。出题时把 (PC) 作为已知量给出。
- 堆栈（p138）：PUSH 压入栈顶后堆栈指示器减 1，POP 弹出后加 1。解析书 析9 写成：进栈 (R)→Msp，(SP)−1→SP；出栈 (SP)+1→SP，(Msp)→R。
- IA-32 九种（表 4.6，p139）：立即、寄存器、偏移量 EA=A、基址 EA=(B)、基址+偏移量、比例变址+偏移量 EA=(I)×S+A、基址+变址+偏移量、基址+比例变址+偏移量、相对 指令地址=(PC)+A。Power PC 见表 4.7（p140）。

### MIPS 与 ARM（p131–132，p144–146）
- MIPS R4000：R 型 `OP(6) rs(5) rt(5) rd(5) shamt(5) funct(6)`；I 型 `OP(6) rs(5) rt(5) address(16)`。表 4.4 字段值（十进制）：add 0/funct 32，sub 0/funct 34，立即数加 8，lw 35，sw 43。书里把 lw 印成 "IW"（p131、习题 14）。
- 32 位 ARM 格式（p132）：`cond(4) F(2) I(1) opcode(4) S(1) Rn(4) Rd(4) operand2(12)`。I=0 第二操作数在寄存器，I=1 为 12 位立即数。
- 寄存器：r0，r1～r12，SP，lr，PC 共 16 个（p144，书中 lr 印作 "Ir"）；字节编址，相邻字地址差 4。
- 表 4.11 的指令子集（语法照抄）：

| 类别 | 指令 | 示例 | 含义 |
|---|---|---|---|
| 算术 | ADD、SUB | `ADD r1,r2,r3` | r1=r2+r3 |
| 数据传送 | LDR、STR | `LDR r1,[r2,#20]` | r1=存储单元[r2+20]；STR 反向 |
| | LDRH、LDRHS、STRH；LDRB、LDRBS、STRB | `LDRH r1,[r2,#20]` | 半字、字节；带 S 的是带符号数 |
| | SWP | `SWP r1,[r2,#20]` | 寄存器与存储单元交换 |
| | MOV | `MOV r1,r2` | r1=r2 |
| 逻辑 | AND、ORR、MVN | `AND r1,r2,r3`、`MVN r1,r2` | 与、或、取反 |
| | LSL、LSR | `LSL r1,r2,#10` | 逻辑左移、右移 |
| 条件转移 | CMP | `CMP r1,r2` | 条件标志=r1−r2 |
| | B+条件（EQ,NE,LT,LE,GT,GE,LO,LS,HI,HS,VS,VC,MI,PL） | `BEQ 25` | 转移至 PC+8+100 |
| 无条件转移 | B、BL | `B 2500`、`BL 2500` | 转至 PC+8+10000；BL 另有 r14=PC+4 |

- 表 4.12 译码值（十进制）：ADD cond14 F0 I0 opcode4 S0；SUB opcode2；立即数加 I=1 opcode4；LDR cond14 F1 opcode24；STR cond14 F1 opcode25（LDR/STR 的 I、opcode、S 三栏合成一个 6 位字段）。
- 例 4.5（p145–146）：`A[30]=h+A[30]`，r3 存数组基址，h 在 r2 → `LDR r5,[r3,#120]`、`ADD r5,r2,r5`、`STR r5,[r3,#120]`。机器码十进制：14|1|24|3|5|120；14|0|0|4|0|2|5|5；14|1|25|3|5|120。书内不一致：STR 的二进制偏移印成 0000 1111 0000（=240），应与 LDR 相同为 0000 0111 1000。
- RISC 性能式（p143）：P=I×C×T（I 指令数，C 每条指令平均机器周期数，T 机器周期时间）。

### 时间单位的嵌套（p153，p164–165）
- 指令周期：取出一条指令并执行它的时间。由若干 CPU 周期组成。
- CPU 周期 = 机器周期：通常取"从内存读一个指令字的最短时间"。取指占 1 个 CPU 周期。任何指令最短 2 个 CPU 周期（图 5.3）。
- 时钟周期 = T 周期 = 节拍脉冲：处理操作的最基本单位。书中的例子一个 CPU 周期含 T1～T4 四个等间隔节拍脉冲，各 200ns，CPU 周期 800ns。
- 节拍电位：持续一个 CPU 周期的电平信号。硬布线控制器里记 M1、M2、M3。
- 三级体制：主状态周期-节拍电位-节拍脉冲（复杂硬布线控制器）。二级体制：节拍电位-节拍脉冲（微程序控制器）。最基本的体制叫电位-脉冲制：数据加在触发器电位输入端，打入信号加在时钟端，电位必须先稳定。
- 单周期 CPU / 多周期 CPU（p153）：书里只定义，明确"以下仅讨论多周期 CPU"。
- 指令和数据的区分（p163–164）：时间上取指令在第一个 CPU 周期，取数据在执行阶段；空间上指令送 IR，数据送运算器。

### 控制方式（p166–167）
- 同步控制：指令所需机器周期数和时钟周期数固定。三种方案：完全统一的机器周期；不定长机器周期；中央控制与局部控制结合。
- 异步控制：需要多少时间占多少时间，靠执行部件的"回答"信号。
- 联合控制：两者结合。例一：访存靠 READY 信号（半同步）。例二：机器周期的节拍脉冲数固定、各指令的机器周期数不固定（书说微程序控制就是这样）。

### 微程序术语（p167–177）
- 微命令：控制部件通过控制线发给执行部件的控制命令。微操作：执行部件接受微命令后做的操作。
- 相容性微操作：同一 CPU 周期内可并行。相斥性微操作：不能并行。
- 微指令：一个 CPU 周期内一组微命令的组合。分操作控制字段和顺序控制字段。
- 微程序：实现一条机器指令的微指令序列。一条机器指令对应一个微程序。
- 控制存储器（控存，解析书记 CM）：只读，存全部微程序；字长 = 微指令字长。
- 微指令周期 = 读微指令时间 + 执行微指令时间；设计成等于 CPU 周期（图 5.26：T4 读微指令，T1+T2+T3 执行）。
- 微命令编码：直接表示法（一位一个微命令）、编码表示法（相斥微命令编成字段再译码，又叫字段直接译码法；3 位表示 7 个，4 位表示 15 个，留一个编码表示不发命令）、混合表示法。还可附设常数字段。
- 微地址形成：计数器方式（现行微地址加增量，微地址寄存器改为计数器；教材 p176 与解析书出现 μPC 的叫法）；多路转移方式（下地址字段 + 判别测试字段 P + 状态条件；n 位状态条件实现 2^n 路转移）。解析书把多路转移方式也叫"断定方式"（析8、选10）。
- 水平型微指令：一次能定义并执行多个并行微命令，一般格式 `控制字段 | 判别测试字段 | 下地址字段`；分全水平型（不译码）、字段译码法、直接和译码混合三种。
- 垂直型微指令：设微操作码，一条只有 1～2 个微命令。书给 4 种 16 位格式（p176）：寄存器-寄存器传送型 `000|源(5)|目标(5)|其他(3)`；运算控制型 `001|左输入源(5)|右输入源(5)|ALU(3)`；访问主存型 `010|寄存器编址|存储器编址|读写|其他`；条件转移型 `011|D(9)|测试条件(4)`。
- 比较（p176–177）：水平型并行能力强、执行时间短、微指令字长而微程序短、难掌握；垂直型相反。

### 流水线术语（p181–192）
- 并行性：同时性、并发性。三种形式：时间并行（时间重叠，流水）、空间并行（资源重复）、时间并行+空间并行（超标量）。
- 过程段（功能段）、流水周期、缓冲寄存器 L（锁存器）、时钟 C。
- 标量流水：一条指令流水线。超标量流水：两条或两条以上指令流水线，满载时每个时钟周期执行 2 条以上。例 5.7 用"超标度为 2"。书中没有"超流水"一词。
- 分类：算术流水线 / 指令流水线 / 处理器流水线（宏流水线）；线性 / 非线性（段间有反馈，一次任务多次经过某段）；同步 / 异步；顺序 / 乱序。静态/动态、单功能/多功能只提到一句"还可以按功能是否可改变、连接方式是否可动态调整等特性分类"（p184），不展开。
- 三个阶段：填充、稳定流水、排空（图 5.35）。
- 性能公式（p185–186，符号照书）：
  - 时钟周期 τ=max{τi}+τl=τm+τl（τi 各段时间，τl 缓冲寄存器延时），频率 f=1/τ。
  - k 级流水线处理 n 个任务的时钟周期数 Tk=k+(n−1)。
  - 非流水 TL=n·k。
  - 加速比 Ck=TL/Tk=n·k/(k+(n−1))；n≫k 时 Ck→k，k 称潜在加速比。
  - 吞吐率 Tp=n/(Tk·Δt)=n/((k−1+n)Δt)，Δt 为时钟周期；最大吞吐率 Tpmax=1/Δt。单位 MIPS。
  - 书中没有"效率 E"的公式，加速比用 Ck 而不是 S。
- 相关：指令间的依赖使后续指令不能按设计的时钟周期执行。相关导致结果不正确的现象称冒险（hazard）或冲突。
- 资源相关（结构相关）、数据相关（主存数相关/寄存器数相关；RAW 写后读、WAR 读后写、WAW 写后写）、控制相关。
- 对策名称：暂停周期、资源重复设置（双端口存储器，或分设数存与指存）；后推法（流水线互锁）、定向技术（旁路技术）、专用数据通路、编译器调度（插入气泡/空操作）、动态调度；冻结或排空流水线、延迟转移法、转移预测法。

## 模型机

### 图 5.1 CPU 模型的结构（p150）
模型机是多周期、指存与数存分开的结构，取指走指令总线，执行阶段所有传送挤在一条数据总线上。

部件：
- 运算器：ALU；通用寄存器 R0、R1、R2、R3；数据缓冲寄存器 DR；程序状态字寄存器 PSWR（标志 C、V、Z、N）。
- 控制器：程序计数器 PC（有 +1 功能）；指令寄存器 IR（分 OP 码和地址码两段）；指令译码器；时序发生器 + 操作控制器（图中合成一个方块，记 OC），输出控制信号 C1、C2、…、Cn。
- 数据地址寄存器 AR。
- 两个存储器：指存（指令存储器，图中标"指存 cache"）和数存（数据存储器，"数存 cache"）。
- 三组总线：数据总线 DBUS、指令总线 IBUS、地址总线两条——指存地址总线 ABUS(I)、数存地址总线 ABUS(D)。DBUS 另有一路"通往 I/O 接口"。

连接关系（"省略"指图中没画、正文说明存在的部件）：

| 从 | 到 | 经过 | 教材信号名 | 解析书图 5.14 的信号名（p85） |
|---|---|---|---|---|
| PC | 指存地址端 | ABUS(I) | 直通；读命令 RD(I) | IR/W̄=1 |
| 指存数据端 | IR | IBUS | LDIR | SIR |
| PC | PC | 加 1 | PC+1 | PC+1 |
| IR 地址码 | DBUS | 三态门 C3 | C3 | C3 |
| Ri | ALU 两个输入端 | 两个 4 选 1 多路开关（省略），由 IR 的源/目标寄存器字段选 | — | LR0～LR3（读出 Ri） |
| ALU 输出 | DBUS | 三态门 C1 | C1；ALU 功能控制（取反、加…） | C1；± |
| Ri（不经 ALU） | DBUS | 三态门 C2 | C2 | LRi，C2 |
| DBUS | DR | — | LDDR | SDR |
| DR | Ri | 2-4 线译码器选目标寄存器（省略） | LDRx / LDRy | SR0～SR3（写入 Ri） |
| DBUS | AR | — | LDAR | SAR |
| AR | 数存地址端 | ABUS(D) | 直通 | — |
| 数存 | DBUS | — | RD(D) | DR/W̄=1 |
| DBUS | 数存 | — | WE(D) | DR/W̄=0 |
| DBUS | PC | — | LDPC | SPC |
| ALU 标志 | PSWR | — | — | SPSW |

要点：
- 教材图 5.1 上只印了 C1、C2、C3、…Cn 和 "+1"；LDxx、RD、WE 这些名字出现在 5.2.7、例 5.3、表 5.2。解析书设计题 2～4 用同一台机器但换了一套名字（S=写入，L=读出）。网站的模型机要能在两套名字间切换，或者同时显示。
- DBUS 是单总线，任何时候只能有一个数据（p156）。地址和数据要分时传送，这是 LAD、STO 的执行周期需要 2 个 CPU 周期的原因（p157、p159）。
- ALU 的结果不直接进通用寄存器，必须 ALU→C1→DBUS→DR→Ri。寄存器之间传送也要绕这一圈。
- 取指不占 DBUS：PC→ABUS(I)→指存→IBUS→IR。
- 没有累加器 AC，没有 MAR/MDR 的叫法（教材图 5.14"经典 CPU 模型"和解析书其他题才出现 AC、MAR、MDR、MBR）。
- 图 5.14 经典 CPU 模型（p161）：单存储器，ALU、寄存器组、状态条件寄存器、DR、IR、PC、AR，数据总线 DB、地址总线 AB，只作思考题对比用。

### 样例程序（表 5.1，p153–154；图 5.5）
初值：R0=00，R1=10，R2=20，R3=30，PC=101。数值按十进制书写；NOT 10 得 245，可推出按 8 位取反（教材没有明说字长）。

| 指存地址 | 指令 | 含义 | 执行后 |
|---|---|---|---|
| 101 | NOT R0,R1 | NOT R1→R0 | R0=245 |
| 102 | LAD R1,6 | 数存 6 号单元→R1 | R1=100 |
| 103 | ADD R1,R2 | R1+R2→R2 | R2=120，进位存 PSWR |
| 104 | STO R2,(R3) | R2→数存 (R3) 单元 | 数存[30]=120 |
| 105 | JMP 101 | 101→PC | PC 由 106 变为 101，程序死循环 |
| 106 | AND R1,R3 | R1 AND R3→R3 | 不会被执行 |

数存：5 号 70，6 号 100，7 号 66，8 号 77，…，30 号 40，31 号空。

- 101 号指令：5.2.2 的标题、图 5.5、图 5.6 写 NOT；图 5.1、p154 取指步骤(3)、p156、图 5.15、图 5.30、例 5.3、图 5.32 写 MOV（方框内容是 R1→R0）。应是第七版把 MOV 改成 NOT 时没改全。
- 取数助记符 LAD / LDA 混用。
- 操作数顺序不统一：NOT、LAD 目标在前，ADD 目标在后，STO 源在前；习题 2、3 写成 `STO R1,(R2)`、`LAD (R3),R0`（源在前）。每条指令旁边必须标箭头含义。
- 图 5.1 的数存第 4 行地址印 10，表 5.1 和图 5.5 以后印 8。
- 图 5.11、图 5.13 里 R1 仍印 10（LAD 之后应为 100）。
- 模型机指令没有给二进制编码，只给助记符。教材说"6 条指令"，实际只跟踪 5 条。

### 五条指令的指令周期
取指周期对所有指令相同，1 个 CPU 周期（图 5.5，p154–155）：
1. PC 的内容（101）放到 ABUS(I)，指存译码并启动读命令 RD(I)。
2. 读出的指令经 IBUS 装入 IR。
3. PC 加 1（变 102）。
4. IR 的 OP 译码，识别出指令。

教材把"PC 装入起始地址"列为第(1)步，共 6 步；它是程序启动的初始条件。

各指令的执行周期：

| 指令 | 执行周期数 | 指令周期 | 步骤（圈号按原图） |
|---|---|---|---|
| NOT R0,R1 | 1 | 2 | ①按 IR 源寄存器字段选 R1 ②OC 指定 ALU 取反 ③打开 ALU 输出三态门（C1），结果上 DBUS ④DBUS→DR（245） ⑤按目标寄存器字段选 R0，DR→R0 |
| LAD R1,6 | 2 | 3 | 第一周期：①打开 IR 输出三态门（C3），地址码 6 上 DBUS ②DBUS→AR。第二周期：③RD(D)，数存 6 号单元的 100 上 DBUS ④DBUS→DR ⑤DR→R1 |
| ADD R1,R2 | 1 | 2 | ①选 R1、R2 ②ALU 做加法 ③C1 打开，120 上 DBUS ④DBUS→DR，进位存 PSWR ⑤DR→R2 |
| STO R2,(R3) | 2 | 3 | 第一周期：①选 R3 ②打开通用寄存器输出三态门（C2，不经 ALU），30 上 DBUS ③DBUS→AR。第二周期：④选 R2 ⑤C2 打开，120 上 DBUS ⑥WE(D)，写入数存 30 号单元 |
| JMP 101 | 1 | 2 | ①C3 打开，IR 地址码 101 上 DBUS ②DBUS→PC |

各图：NOT 图 5.4–5.6，LAD 图 5.7–5.8，ADD 图 5.9，STO 图 5.10–5.11，JMP 图 5.12–5.13。指令周期示意图（图 5.4、5.7、5.10、5.12）用圆圈表示动作：取指令 PC+1 → 对指令译码 → 执行指令；LAD 为 送操作数地址 → 取出操作数 → 装入通用寄存器；STO 为 送操作数地址 → 送操作数 → 写数存；JMP 为 送转移地址。

节拍级时序（来自图 5.30 与例 5.3，p178–179；解析书图 5.15–5.17，p86）：

| CPU 周期 | 电位信号（整个周期有效） | T3 打入 | T4 打入 |
|---|---|---|---|
| 取指 | RD(I)（解析书 IR/W̄=1） | LDIR（SIR） | PC+1 |
| NOT/MOV 执行 | 寄存器选择、ALU 功能、C1 | LDDR | LDRx |
| ADD 执行 | 寄存器选择、+、C1 | LDDR（SDR），SPSW | LDRy |
| LAD 执行一 | C3 | — | LDAR |
| LAD 执行二 | RD(D)（DR/W̄=1） | LDDR（SDR） | LDRx（SR） |
| STO 执行一 | 寄存器选择（LR）、C2 | — | LDAR（SAR） |
| STO 执行二 | 寄存器选择、C2；WE(D) 在 T3 发脉冲（解析书写 DR/W̄=0） | — | — |
| JMP 执行 | C3 | — | LDPC |

书内不一致：解析书 设4 把 ADD 的执行拆成两个 CPU 周期（先 `LR2,LR0,+,C1,SDR(T4),SPSW(T4)`，再 `SR0(T4)`），共 3 个 CPU 周期；教材图 5.15/5.30 是一个 CPU 周期内 T3 打入 DR、T4 打入寄存器，共 2 个。练习判分要两种都认，或按任课教师口径定。

### 方框图语言（5.2.7，p161–162）
- 一个方框 = 一个 CPU 周期，框内写该周期的数据通路操作或控制操作，写成"源→目的"。
- 菱形 = 判别或测试（译码）。时间上依附于它前面那个方框的 CPU 周期，自己不占周期。
- "～"= 公操作符号：指令执行完，转入指令结束前的公操作（处理中断、通道等外设请求；没有请求就取下一条指令）。取指令也算公操作。
- 控制信号写在方框旁边：图 5.15 写在框的左上方（RD(I)、RD(D)、WE(D)）；例 5.1 和解析书写在框右侧，一行一个周期，逗号分隔。
- 图 5.15（p162）五条指令的完整方框图：

```
开始
 │ RD(I)
[ PC→ABUS(I) ; IBUS→IR ; PC+1 ]
 │
<译码>
 ├─ MOV(NOT): [ R1→R0 ] ─ ～
 ├─ LAD: [ IR→AR ] ─ RD(D) ─ [ AR→ABUS(D) ; DBUS→DR ; DR→R1 ] ─ ～
 ├─ ADD: [ R1+R2→R2 ] ─ ～
 ├─ STO: [ R3→AR ] ─ WE(D) ─ [ R2→DBUS ] ─ ～
 └─ JMP: [ IR→PC ] ─ ～
```

- 方框里的写法是省略式：R1→R0 实际经过 ALU、DBUS、DR；IR→AR 指 IR 的地址码经 DBUS 到 AR。
- 教材 p173 明说：图 5.15 就是这五条指令的微程序流程图，每个 CPU 周期对应一条微指令（共 8 条：取指 1，NOT 1，LAD 2，ADD 1，STO 2，JMP 1）。这 8 条微指令的二进制编码教材没有给。

### 例 5.1 双总线机（图 5.16、5.17，p161–163；解析书 析4 同图）
- 部件：IR、PC（具有自增功能）、AR、主存 M（受 R/W̄ 控制，指令和数据都放在里面）、DR、R0～R3、暂存器 X 和 Y、ALU（+、− 两个控制信号）、门 G。
- 两条总线：A 总线在上，B 总线在下。寄存器从 A 总线接收（输入控制信号下标 i：IRi、PCi、ARi、DRi、R0i～R3i、Xi、Yi），向 B 总线送出（输出控制信号下标 o：IRo、PCo、DRo、R0o～R3o、ALUo）。G 是 B 总线到 A 总线的桥。AR 直接接 M 的地址端，M 与 DR 双向相连。线上的小圈表示有控制信号，没标字的线是直通线。
- `ADD R2,R0`（R0+R2→R0）的流程，每框一个机器周期，共 6 个，〔〕内是框右侧标注的信号：
  - 取指：PC→AR〔PCo, G, ARi〕；M→DR〔R/W̄=R〕；DR→IR〔DRo, G, IRi〕；菱形（译码）。
  - 执行：R2→Y〔R2o, G, Yi〕；R0→X〔R0o, G, Xi〕；Y+X→R0〔+, G, R0i〕；～。
- `SUB R1,R3`（R3−R1→R3）：取指相同；R3→Y（R3o, G, Yi）；R1→X（R1o, G, Xi）；Y−X→R3（−, G, R3i）。教材图 5.17(b) 最后一行印成 "X3i"，解析书图 5.5 印 R3i。
- 流程里没有单独写 PC+1（PC 自增）。被减数放 Y、减数放 X。
- 思考题（p163）与解析书 析5、析6：增设指令存储器 IM 并让 PC 直接作 IM 的地址、IM 输出接 IR，可缩短取指周期；让 R0～R3 的输出经多路开关或三态门直接接 X、Y，可缩短执行周期。

## 控制器

### (a) 时序发生器（5.3.2，p164–166）
- 组成（图 5.18）：时钟源 → 环形脉冲发生器 → 节拍脉冲和读写时序译码 → 启停控制逻辑。
- 时钟源：石英晶体振荡器 + 与非门正反馈电路，输出方波 CLK。
- 环形脉冲发生器：产生一组有序脉冲序列（图 5.19 中的 C4、C1、C2、C3），供译码用。解析书 析2 的译码式：T1=C1·C̄2，T2=C2·C̄3，T3=C3，T4=C̄1（图 5.2，p75–76，电路为循环移位寄存器）。
- 译码输出原始信号 T1°～T4°、RD°、WE°（带上标 °）；经启停控制逻辑的与门后成为 T1～T4、RD、WE。
- 图 5.19 时序图的结构（自上而下）：CLK（标 1～10）；C4、C1、C2、C3；虚线；RD、R̄D̄、WE、W̄Ē；T1、T2、T3、T4；底部标两个"一个 CPU 周期"。第一个 CPU 周期 RD 为高，第二个 CPU 周期 WE 为高；T1～T4 依次各占四分之一周期。
- 节拍电位：硬布线控制器里由时序产生器产生；微程序控制器里由微指令提供，持续一个 CPU 周期。
- 启停控制逻辑（图 5.20）：核心是运行标志触发器 Cr（D 触发器），下面接一个 SR 触发器（启动、停机两个输入），Cr 用 T̄4° 作时钟。Cr=1 时放行，Cr=0 时关闭。要求：启动必须从 T1 前沿开始，停机必须在 T4 结束后，保证送出的脉冲完整。
- 微命令的时间控制（图 5.23，p169）：微指令给的是节拍电位信号（记 LDR1′ 等，带撇）；打入类信号要与 T4 相与得到 LDR1（不带撇）。前 600ns 运算，T4 的 200ns 打入。

### (b) 微程序控制器（5.4，p167–177）
框图（图 5.24，p170）：
- 控制存储器（带地址译码）。
- 微指令寄存器 = 微地址寄存器 + 微命令寄存器。微命令寄存器保存 P 字段和控制字段，控制字段输出微命令信号。
- 地址转移逻辑：输入为 IR 的 OP、状态条件、P 字段；输出修改微地址寄存器。
- 回路：控存读出 → 下地址进微地址寄存器、P 字段和控制字段进微命令寄存器 → 微地址寄存器经地址译码再读控存。

执行部件（图 5.21 简单运算器，p168）：
- R1、R2、R3 三个通用寄存器，DR，ALU（+、−、M 传送 三种操作），Cy 最高进位触发器。
- ALU 的 X 输入端多路开关可选 R1、R2、DR；Y 输入端可选 R1、R2、R3。ALU 输出经公共总线回到三个寄存器。
- 相斥组：{+，−，M}；{4，6，8}（X 端）；{5，7，9}（Y 端）。X 端任一个与 Y 端任一个相容。

微指令格式（图 5.22，p168）：字长 23 位，操作控制 17 位（直接表示法）+ 顺序控制 6 位。

| 位 | 微命令 | 位 | 微命令 | 位 | 微命令 |
|---|---|---|---|---|---|
| 1 | LDR1′（ALU→R1） | 7 | R2→Y | 13 | RD(D)′ |
| 2 | LDR2′ | 8 | DR→X | 14 | LDDR′ |
| 3 | LDR3′ | 9 | R3→Y | 15 | LDIR′ |
| 4 | R1→X | 10 | + | 16 | LDAR′ |
| 5 | R1→Y | 11 | M | 17 | PC+1 |
| 6 | R2→X | 12 | − | 18、19 | P1、P2 |
| | | | | 20–23 | 直接微地址（4 位） |

P1、P2 都为 0：直接按 20–23 位取下一条。P1=1：用 IR 的 OP 字段形成下一微地址。P2=1：用进位 Cy 修改微地址最后一位。

"十进制加法"微程序（图 5.25，p170–172）：常数 6、a、b 事先在 R1、R2、R3 中（隐含寻址），a、b 在 0～9；指令操作码假定为 1010。

| 微地址 | 操作 | 1–17 位 | P1 P2 | 下地址 | 发出的微命令 | 实际后继 |
|---|---|---|---|---|---|---|
| 0000 | 取指：PC→ABUS(I)，IBUS→IR，PC+1 | 000 000 000 000 00101 | 1 0 | 0000 | LDIR′（同时发 RD(I)）、PC+1 | P1 测试：OP=1010 → 1010 |
| 1010 | R1+R2→R2（6+a） | 010 100 100 100 00000 | 0 0 | 1001 | R1→X，R2→Y，+，LDR2′ | 1001 |
| 1001 | R2+R3→R2（6+a+b） | 010 001 001 100 00000 | 0 1 | 0000 | R2→X，R3→Y，+，LDR2′ | P2 测试：Cy=0 → 0001；Cy=1 → 0000 |
| 0001 | R2−R1→R2（减 6） | 010 011 000 001 00000 | 0 0 | 0000 | R2→X，R1→Y，−，LDR2′ | 0000 |

- Cy=1 说明 a+b+6>15，R2 即结果；Cy=0 说明和不超过 9，多加的 6 要减掉。
- 流程图中微地址写在方框右上角，下地址写在方框右下角；菱形 P1、P2 依附于前一个方框。
- 一个 CPU 周期一条微指令：T4 读下一条微指令，T1 上升沿打入微指令寄存器（p173）。

例 5.2 微地址转移逻辑（p175）：微地址寄存器 6 位 μA5～μA0，通过触发器强制置位端 S 置 1。三处分支：取指后按 OP（IR3～IR0）16 路；条件转移按进位 C 2 路；控制台指令按 IR5、IR4 4 路。设 P1、P2、P3 三个判别位，加时间因素 T4：

```
μA5=P3·IR5·T4     μA4=P3·IR4·T4
μA3=P1·IR3·T4     μA2=P1·IR2·T4
μA1=P1·IR1·T4     μA0=P1·IR0·T4+P2·C·T4
```

前 5 个用与非门，最后一个用与或非门。由于只能把某位由 0 置成 1，带分支的微指令的下地址字段在被修改的位上应为 0。

机器指令与微指令的对应（图 5.27，p173）：指令/程序/地址对应内存；微指令/微程序/微地址对应控存。微程序属于硬件，对软件不可见。

控存容量与字段位数的算法（教材习题 6、11；解析书 析8、析12、设5）：
- 微指令条数：共用一条取指微指令，其余每条指令各自若干条。教材习题 6 的参数：80 条指令、平均 4 条微指令、微指令 32 位 → (80×3+1)×32 位。
- 控存 2^m 单元 → 下地址字段 m 位。解析书 析8：512×48 位、4 个转移条件 → 下地址 9 位，判别测试 4 位，微命令 48−4−9=35 位。
- 相斥组编码：含 k 个微命令的组占 ⌈log2(k+1)⌉ 位。解析书 析12：五组 4、5、8、15、20 个 → 3、3、4、4、5 位，2 个条件 → 2 位，字长 29 → 下地址 8 位，控存 2^8×29 位。
- 解析书 设5：10 个直接控制 + 四组 7、15、3、5（3、4、2、3 位）共 22 位，判别字段 3 位，字长 32 → 下地址 7 位，控存 128 单元。
- 书内不一致：判别测试字段的位数有两种算法——每个条件占 1 位（析8：4 个条件 4 位；析12：2 个条件 2 位），或者编码（设5：4 个条件 P1～P4 编成 3 位）。题目没说明时，答案要写清采用哪种假设。

### (c) 硬布线控制器（5.5，p177–181）
- 结构（图 5.29）：树形逻辑网络 N。输入：指令译码器输出 I1…Im；结果反馈信息 B1…Bj；节拍电位/节拍脉冲发生器的 M1…Mi、T1…Tk（该发生器有启动、停止、时钟、复位输入）。输出：微操作控制信号 C1…Cn。另有信号反馈回时序发生器，用来跳过某些节拍。
- 基本原理：`C=f(Im, Mi, Tk, Bj)`。一般形式（式 5.1）：`Cn=Σ_i(Mi·Tk·Bj·Σ_m Im)`。
- 书中的小例子（p178）：主存读信号 C3 在 M1（取指）有效，在 M4 时 LAD、ADD、AND 三条指令取操作数也有效，`C3=M1+M4(LAD+ADD+AND)`。
- 指令周期流程图（图 5.30，p178），节拍电位 M1～M3，每个节拍电位内 T1～T4：

| 节拍 | 指令 | 框内操作与所在节拍脉冲 |
|---|---|---|
| M1 | 全部（取指，RD(I)） | T1：PC→ABUS(I)；T3：IBUS→IR；T4：PC+1；随后译码 |
| M2 | MOV | T3：Ry→DR；T4：DR→Rx |
| M2 | LAD | T4：IR→AR |
| M2 | STO | T4：Ry→AR |
| M2 | JMP | T4：IR→PC |
| M2 | ADD | T3：Rx+Ry→DR；T4：DR→Ry |
| M3 | LAD（RD(D)） | T1：AR→ABUS(D)；T3：DBUS→DR；T4：DR→Rx |
| M3 | STO（WE(D)，T3） | T1：Rx→DBUS |

  Rx、Ry 是指令地址码里的第一个、第二个寄存器。
- 同步方式下所有指令都按 M1～M3 三拍走，MOV、ADD、JMP 在 M3 空过；也可以让短指令在 M2 后跳回 M1，代价是节拍发生器更复杂（p179）。
- 例 5.3 的逻辑表达式（p179）。写法：从流程图里找出产生该信号的全部条件，按出现先后列出；电位信号只与节拍电位，脉冲信号再与节拍脉冲。

```
RD(I)=M1（电位）               RD(D)=M3·LAD（电位）
WE(D)=M3·T3·STO（脉冲）        LDPC=M1·T4+M2·T4·JMP
LDIR=M1·T3                     LDAR=M2·T4·(LAD+STO)
LDDR=M2·T3·(MOV+ADD)+M3·T3·LAD PC+1=M1·T4
LDRx=M2·T4·MOV+M3·T4·LAD       LDRy=M2·T4·ADD
```

- 基于有限状态机的硬布线控制器（p180–181）：状态寄存器 + 状态转移逻辑 + 微命令发生器（图 5.31）。不设节拍脉冲，每步一个时钟周期，流程图的每个操作定义成一个状态。图 5.32：S0 空闲 → S1、S2、S3（取指）→ 按指令分支 → 回 S1。表 5.2 各状态的操作〔有效信号〕：
  - 取指：S1 PC→ABUS(I)〔RD(I)〕；S2 IBUS→IR〔RD(I)，LDIR〕；S3 PC+1〔RD(I)，LDPC，PC+1〕。S0 空闲，无信号。
  - MOV：S4 Ry→DR〔LDDR〕；S5 DR→Rx〔LDRx〕。
  - LAD：S6 IR→AR〔LDAR〕；S7 AR→ABUS(D)〔RD(D)〕；S8 DBUS→DR〔RD(D)，LDDR〕；S9 DR→Rx〔RD(D)，LDRx〕。
  - STO：S10 Ry→AR〔LDAR〕；S11 Rx→DBUS〔WE(D)〕。
  - JMP：S12 IR→PC〔LDPC〕。ADD：S13 Rx+Ry→DR〔LDDR〕；S14 DR→Ry〔LDRy〕。
- 解析书 设11 的硬联线例子（图 5.27–5.29，p93–95）：累加器机（AC、DR、AR、PC、IR、主存 M，信号 C1～C11），指令 LDA、STA、ADD、COM、JMP、JPZ；只用节拍电位 W1～W6（模 6 计数器），取指占 W1～W3；表达式如 `C3=W2+W5(LDA+STA+ADD)`、`C8=W4·JMP+W6·JPZ`。节拍电位的字母各题不同（M、W），按题目给的用。

## 流水线

### 5.6.1 原理与指标（p181–186）
- 四段指令流水线（图 5.33a）：IF 取指、ID 指令分析/译码、EX 运算执行、WB 结果写回，段号 S1～S4。讲相关时改用五段（图 5.40，p190）：IF、ID（译码并读寄存器）、EX（计算有效地址或执行）、MEM（访存取数）、WB（结果写寄存器堆）。
- 时空图的两种画法，书里都用：
  - 画法一（图 5.33、图 5.35、解析书图 5.10）：横轴"时间 T"，刻度为时钟周期 1、2、3…；纵轴"空间 S"，自下而上 IF、ID、EX、WB；格子里填指令号 I1、I2…；顶部向上的箭头表示指令完成输出。
  - 画法二（表 5.3、表 5.4、图 5.37、图 5.41c）：每行一条指令（或一个任务），每列一个时钟，格子里填段名。
- 图 5.33 的四张图：(b) 非流水，每 4 个周期出一个结果；(c) 标量流水，8 个单位时间完成 5 条；(d) 超标量流水（两条流水线），8 个单位时间完成 10 条。
- 图 5.35 线性流水线三个阶段：段数记 m，每段 Δt0，T0=mΔt0 后出第一个结果，总时间 T=nΔt0+(m−1)Δt0。正文公式改用 k 记段数（见"记号与约定"）。
- 书内不一致（解析书 析16，p83，五段、8 条、100ns）：吞吐率按 12 个时钟周期算（8/(12×100ns)），加速比一步却印成 Tk=k+(n+1)、8×5/(5+11)=40/16=2.5；按教材公式应为 40/12≈3.33。出题和判分以教材公式为准。
- 流水线特点（p186）：不减少单个任务的处理延迟，只提高吞吐率；填充和排空时间越长加速比越低；各段时间应大致相同，速率受最慢的段限制。

### 5.6.2 例题（p186–188）
- 例 5.4：4 级流水浮点加法器，τ1=70ns，τ2=60ns，τ3=90ns，τ4=80ns，缓冲寄存器 τl=10ns。时钟周期 τ=90+10=100ns；非流水时间取四段之和 300ns；加速比 Ck=300/100=3。各段都是 75ns（含缓冲寄存器）时 Ck=300/75=4。这里的加速比是"一个任务的时间之比"，不是 nk/(k+n−1)。
- 图 5.36：三段浮点加法器（阶码比较与对阶 → 尾数加/减 → 规格化及舍入），段间锁存器 L，标出 x=1.1000×2²、y=1.1100×2⁴ 在各级的中间值，结果 1.0001×2⁵。
- 例 5.5：四段 C（阶码比较）、S（对阶）、A（尾数相加）、N（规格化），向量 x+y 六对元素，画时空图（图 5.37，画法二，空间轴向下）。填满后每个时钟周期出一个结果。
- 流水计算机（图 5.38）：指令部件（取指令、指令译码、计算操作数地址、取操作数）→ 指令队列（FIFO）→ 执行部件；存储器用多体交叉存储器加 cache。

### 5.6.3 相关（p189–192）
- 拥挤问题（图 5.39）：瓶颈段 S2 耗时 3Δt。办法一：细分为 S2a、S2b、S2c。办法二：重复设置三个 S2，前后加数据分配器和数据收集器。
- 资源相关（表 5.3）：五段流水，时钟 4 时 I1(LAD) 在 MEM、I4 在 IF，同时访问存储器。办法：I4 暂停一拍；或用双端口存储器；或分设指存和数存。
- 数据相关的定义（指令 i 先于指令 j 进入流水线）：
  - RAW：j 要用 i 的结果，却在 i 写入之前读了。
  - WAR：j 在 i 读某个源操作数之前就写了它。
  - WAW：i、j 目标相同，j 先于 i 写入。
- 表 5.4 的例子：`ADD R1,R2,R3`（R2+R3→R1）、`SUB R4,R1,R5`、`AND R6,R1,R7`。ADD 在时钟 5 写 R1；SUB 在时钟 3、AND 在时钟 4 读 R1 → 两处 RAW。三地址写法里目标在最前。
- 例 5.6 的三组（p191–192）：
  - `ADD R1,R2,R3` 后接 `SUB R4,R1,R5` → RAW（后一条读前一条的目标）。
  - `STO M(x),R3` 后接 `ADD R3,R4,R5` → WAR（后一条写前一条要读的 R3）。
  - `MUL R3,R1,R2` 后接 `ADD R3,R4,R5` → WAW（目标相同，加法可能先完成）。
- 判断规则：对相邻两条指令各列出"读集合"和"写集合"。后读 ∩ 前写 → RAW；后写 ∩ 前读 → WAR；后写 ∩ 前写 → WAW。一对指令可以同时有几种（例 5.7 的 I5、I6 既有 WAW 又有 RAW）。
- 推迟多少拍（教材习题 12、解析书 设12、析15）：书的约定是后一条指令要等到前一条把结果写回寄存器堆之后的下一个周期才能读。四段流水（取指、译码并取数、运算、送结果）相邻两条指令相关，不采取措施推迟 2 个时钟周期；采用专用通路（定向）可不停顿。解析书 析15：五段流水，SUB 之后四条指令都读 R2，不处理时紧随的三条取到错误操作数；用推迟法共需 12 个时钟周期（表 5.4b：后一条的 ID 排在 SUB 的 WB 之后一个周期，其余依次顺延）。
- 控制相关：由条件转移或中断引起。办法：冻结或排空流水线；延迟转移法（编译程序重排指令，"先执行再转移"）；转移预测法（硬件，转移取/顺序取两路预取队列、目标指令 cache）。
- 例 5.7 超标量（图 5.41，p192–193）：超标度为 2，四段 F、D、E、W；F、D、W 各 1 个时钟周期；E 段的取数/存数部件 1 周期，加法器 2 周期，乘法器 3 周期，都已流水化；F、D 段成对输入；E 段有内部数据定向，结果生成即可用。按序发射、按序完成。六条指令：

| 指令 | 含义 | F | D | E | W |
|---|---|---|---|---|---|
| I1 `LAD R1,A` | M(A)→R1 | 1 | 2 | 3 | 4 |
| I2 `ADD R2,R1` | R2+R1→R2 | 1 | 2 | 4–5 | 6 |
| I3 `ADD R3,R4` | R3+R4→R3 | 2 | 4 | 5–6 | 7 |
| I4 `MUL R4,R5` | R4×R5→R4 | 2 | 4 | 5–7 | 8 |
| I5 `LAD R6,B` | M(B)→R6 | 4 | 5 | 6 | 9 |
| I6 `MUL R6,R7` | R6×R7→R6 | 4 | 5 | 7–9 | 10 |

  I1、I2 有 RAW，I2 推迟一个时钟发射；I3、I4 有 WAR，按序发射不出错；I5、I6 有 WAW 和 RAW，I5 在时钟 6 执行完但等到时钟 9 才写回以保持按序完成。共 10 个时钟周期。图 5.41(b)"各段推进情况图"按时钟逐行列出译码段、执行段（取/存、加法器、乘法器三栏）、写回段里各有哪些指令。上表的时钟数读自图 5.41(c)。

### 5.6.4 动态流水线调度（p192–194）

### 5.7 RISC 与鲲鹏（p194–200）
- RISC 三要素：有限的简单指令系统；大量通用寄存器；强调指令流水线优化。十条特征见 p194，表 5.5 对比 CISC/RISC（指令数 >200 / <100；格式和寻址方式 >4 / <4；字长不固定 / 等长；可访存指令不限 / 只有取数存数；控制器微程序 / 硬布线）。"RISC 机器一定是流水 CPU"（p200，解析书 选13）。
- 鲲鹏 920：最多 64 个 TaiShan V110 内核，兼容 ARMv8-A；取指部件每周期最多发 4 条指令；L1 指令 cache 64KB 4 路组相联，L2 cache 512KB 8 路；内核集群 CCL（四个内核）、超级内核集群 SCCL、I/O 集群 ICL、超级 I/O 集群 SICL。只出概念选择题（解析书 选22、选23）。

通用模型至少要参数化的东西：
1. 总线条数和每个部件对每条总线的输入口、输出口，桥（G）。
2. 每个口的控制信号名（题目给什么名就显示什么名），电位型还是脉冲型，脉冲型在哪个 T 有效。
3. ALU 输入来自暂存器、总线还是多路开关；输出去总线、暂存器还是直接进某寄存器。
4. 存储器一个还是两个，地址和数据寄存器的名字（AR/DR、MAR/MDR、MAR/MBR、IAR/IDR、DAR/DDR）。
5. PC 有没有自增功能。
6. 一步（一个方框）内的合法性规则：一条总线只能有一个输出源；同一步里可以有多个接收者。
7. 命名陷阱：LRi 在解析书图 5.14 表示"读出 Ri"，在图 5.34 表示"打入 Ri"；LDRi 在教材表示"打入 Ri"。同一个缩写不能全站固定一个含义。

## 与通用讲法的差异

按 Patterson-Hennessy 的 RISC-V/MIPS 讲法做页面，下面这些地方会和教材冲突：

1. 模型 CPU 是多周期的，没有单周期数据通路。教材 p153 明确只讨论多周期 CPU；没有"加法器算 PC+4、ALU 算地址、存储器、写回"这样一条贯通的组合通路，也没有 RegDst、ALUSrc、MemtoReg 这类多路选择控制信号。
2. 数据通路以总线为中心。部件之间靠"打开某个三态门上总线，再把总线上的值打入某个寄存器"来传送，一条总线一次只能传一个值。教学重点是"这一步谁上总线、谁接收"，不是多路选择器选哪一路。
3. 指存和数存分开，但目的不是配合流水线。取指走 IBUS，不占 DBUS；讲流水线时又说"分设数据存储器和指令存储器"是解决资源相关的办法（p190）。
4. 有 AR 和 DR 两个中间寄存器。运算结果要先进 DR 再进通用寄存器，访存地址要先进 AR。
5. 时间单位是三层：指令周期 ⊃ CPU 周期（机器周期）⊃ 节拍脉冲 T1～T4。每条指令的 CPU 周期数不同（2 或 3）。P-H 的"时钟周期"在这里对应节拍脉冲。CPI 的概念不用，只在 P=I×C×T 里出现"平均机器周期数 C"。
6. 控制器是课程重心，分微程序和硬布线两种，都要会设计：微指令格式、控存容量、微地址转移逻辑、控制信号的布尔表达式。P-H 里的"主控单元真值表 + ALU 控制"在这里没有对应内容。
7. 指令是抽象助记符（NOT/MOV、LAD、ADD、STO、JMP、AND），没有二进制编码，没有固定的操作数顺序。PC 每次加 1，不是加 4。寄存器只有 R0～R3。
8. 汇编语言讲的是 32 位 ARM（表 4.11、例 4.5），MIPS R4000 只在 4.2.5 讲格式、在习题里做互译，RISC-V 完全没有。条件转移靠 CMP 置条件标志再 B+条件码；转移目标按 PC+8+偏移×4 计算。
9. 寻址方式是第 4 章的大头，包括间接寻址、变址、基址、相对、段寻址、堆栈寻址和它们的复合；计算题用十六进制指令字。RISC-V 课程里只有寄存器、立即数、基址偏移、PC 相对四种。
10. 操作码扩展是必考设计题。定长操作码的 RISC 课程不讲。
11. 流水线先讲四段（IF、ID、EX、WB），讲相关时才用五段（IF、ID、EX、MEM、WB）；没有流水线寄存器 IF/ID、ID/EX 的内容划分，没有带转发单元和冒险检测单元的流水线数据通路图。
12. 词汇不同：相关（不是"依赖"）、冒险或冲突；资源相关（结构相关）；数据相关按 RAW、WAR、WAW 三类命名；控制相关；后推法、流水线互锁；定向技术（旁路技术）；气泡；延迟转移法、转移预测法。没有 load-use 冒险这种说法。WAR、WAW 在顺序五段流水线里不会出错，教材把它们和超标量、乱序执行连在一起讲。
13. 停顿拍数的算法不同。教材和解析书默认"写回完成后的下一个周期才能读"，相邻相关不采取措施推迟 2 拍（四段）；五段时后一条的 ID 排在前一条 WB 之后。P-H 默认寄存器堆前半周期写、后半周期读，结果会少一拍。
14. 性能指标是加速比 Ck 和吞吐率 Tp，按 Tk=k+(n−1) 的时钟周期数计算，时空图是必画的图。没有效率 E 的公式。
15. 超标量有专门的作图题（例 5.7、习题 17）：按序发射、按序完成、功能部件多周期。动态调度（保留站、重排序缓冲器）和鲲鹏八级流水线只要求概念。
16. 没有异常与中断的数据通路处理；中断只在"公操作"里一句带过，详细内容在后面的章节。

## 建议的交互页面

按"考试分量 × 逐步演示的价值"排序。每项是：学生的困惑 → 需要的模型 → 接到的练习。

1. "LAD 为什么比 ADD 多一个 CPU 周期？" → 图 5.1 模型机逐步演示：五条指令，逐 CPU 周期、逐圈号高亮通路，显示总线上的值和寄存器变化；DBUS 被占用时给出提示。→ 给一条新指令排出每个周期的传送。
2. "方框图旁边的信号怎么写，哪些要带 T？" → 模型机 + 方框图联动：点方框亮通路，点信号亮三态门或打入端；教材和解析书两套信号名可切换；电位信号、T3 打入、T4 打入分色。→ 教材习题 5.2、5.3 类型：画流程图并标信号。
3. "换一张数据通路图我就不会了。" → 通用总线型数据通路编辑/演示器，预置双总线（图 5.16）、单总线带暂存器、内部总线三种；学生每步选"谁输出、过不过桥、谁接收、ALU 做什么"，系统检查总线冲突。→ 解析书设计题 9、13–16 类型。
4. "取指微指令怎么知道下一条去哪？" → 微程序控制器演示：控存表、微地址寄存器、微命令寄存器、地址转移逻辑；跑十进制加法微程序的 4 条微指令，P1 用 OP 改地址、P2 用 Cy 改末位，旁边联动图 5.21 运算器。→ 读一条 23 位微指令说出它做什么；给操作写编码。
5. "微指令每个字段该几位，控存多大？" → 字段计算器：输入微命令分组、条件数、字长或控存容量，逐步推出各字段位数，并显示"留一个不发命令的编码"。→ 微指令格式设计与控存容量题。
6. "分支微地址怎么分配，转移逻辑表达式怎么来？" → 微程序流程图标地址练习器：给流程图和 P 测试规则，学生填微地址，系统模拟置位修改并验证能否到达正确分支；自动生成 μAi 表达式。→ 解析书 析10、设8、设10 类型。
7. "LDDR=M2·T3·(MOV+ADD)+M3·T3·LAD 是怎么写出来的？" → 硬布线信号推导器：在图 5.30 上点选某个信号，高亮它出现的所有（M、T、指令）格子，逐项拼成表达式；可切换到有限状态机表 5.2。→ 给流程图写全部控制信号表达式。
8. "扩展操作码到底留几个码？" → 操作码树：逐级显示编码空间，拖动"留作扩展的码数"，实时算出下一级容量，判断方案是否可行。→ 扩展操作码设计、最多多少条零地址指令。
9. "这串十六进制指令的有效地址是多少？" → 寻址方式演示：指令字切字段，按寻址特征位走不同路径（寄存器、内存两次访问、PC 相加），显示 E 和操作数；覆盖表 4.5 和复合寻址。→ EA 计算题、寻址方式命名填表。
10. "时空图怎么画，12 个周期是怎么数出来的？" → 时空图生成器：输入 k、n、Δt，逐周期填格，两种画法可切换，同步显示 Tk、Tp、Ck 的代入过程；可设各段时间和锁存器延时求时钟周期。→ 教材习题 5.13 类型和例 5.4 类型。
11. "RAW、WAR、WAW 总是分不清。" → 相关判别器：两条指令并排，列出读集合和写集合，高亮交集并给出类型；附五段时空图显示读写发生在哪一拍。→ 例 5.6、习题 5.16 类型。
12. "相关之后要停几拍，定向以后呢？" → 带停顿的五段流水线演示：选"不处理 / 后推 / 定向"，逐拍显示气泡和各指令所在的段，统计总周期数；按教材的口径（写回后下一周期才能读）计算。→ 解析书 析15、设12 类型。
13. "超标量的推进图怎么排？" → 例 5.7 演示器：两路取指译码、三种功能部件、按序写回，逐时钟推进，标出每次推迟的原因。→ 教材习题 5.17。
14. "T1～T4 和 CPU 周期是什么关系，为什么打入要与 T4？" → 时序波形演示：CLK、环形计数器、T1～T4、节拍电位、带撇与不带撇的 LDR 信号，启动/停机按钮演示启停逻辑只放行完整脉冲。→ 时序产生器题、电位与脉冲配合方案选择。
15. "指令格式设计题从哪下手？" → 字段分配器：输入字长、指令数、寄存器数、主存容量、寻址方式数，逐步分配位数并写出每种寻址模式的 E 和可寻址范围。→ 指令格式设计与格式分析题。
16. "ARM 汇编怎么变成 32 位机器码？" → 字段填充器：按表 4.12 把一条 ADD/SUB/LDR/STR 填成十进制字段再转二进制；附 C 语句到 ARM 的三步翻译（数组偏移乘 4）。MIPS 同法。→ 教材习题 4.13–4.16。
17. "相容和相斥微命令怎么分组？" → 分组器：给"微指令 × 微命令"表，自动找从不同时出现的微命令，学生拖拽成组，检查控制字段是否不超过限定位数。→ 教材习题 5.8、解析书 析11。
