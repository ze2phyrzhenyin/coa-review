## 记号与约定

### 容量、编址、端模式

- 层次术语（p71）：存储位元（存 1 位）→ 存储单元（若干位元）→ 存储器。
- 容量写法（p73）：存储字数 × 存储字长。定义处写 `1M×1bit`、`128K×8bit`、`512K×4bit`；3.2 节起写 `32K×8 位`、`1M×4 位`、`256K×8 位`。例 3.2 写 `2048K×8 位`，不写 2M。
- 单位（p73）：1KB=2^10 B，1MB=2^20 B，1GB=2^30 B，1TB=2^40 B。K=2^10，M=2^20 贯穿全章。
- 字节数换算：`1M×32 位` = 4MB（p86、p98 的写法）。
- 编址（p72）：存放一个机器字的单元叫字存储单元，地址叫字地址；存放一字节的叫字节存储单元，地址叫字节地址。编址最小单位是字则为“按字编址”，是字节则为“按字节编址”。
- 寻址范围题（解析书选择题 4、7–9，p31）：答案写单元个数，如字长 32 位、容量 256MB、按字编址 → 64M（不带 B）。
- 端模式（p73，图 3.3）：大端把高有效字节放低地址，小端把低有效字节放低地址。示例数 (0A0B0C0D)16，地址 a 到 a+3：大端依次为 0A、0B、0C、0D；小端依次为 0D、0C、0B、0A。
- 十六进制写法：正文用 (BBBBBB)16、0000H；习题 29 用 0x1234；解析书用 0A2C(H)、25301H。

### 技术指标（p73）

- 存取时间（存储器访问时间）：从收到读/写命令到读出或写入完成的时间。存储周期（存取周期）：连续两次访问存储器的最小间隔，略大于存取时间。
- 存储器带宽（数据传送速率、频宽）：单位时间存取的信息量，单位 位/秒或字节/秒。总线宽度 W 位时，带宽 = W / 存取周期（bit/s）。

### 芯片信号名

- SRAM（p74–76）：地址线 A0–A14，数据线 I/O0–I/O7，片选 CS（低有效），读出使能 OE（低有效），写命令 WE（低有效）。简化图用 R/W：高电平读，低电平写。习题 5 用 W/R=1 读、=0 写。
- 时序参数（图 3.6，p76）：读周期 tRC、tAQ（地址有效到数据有效）；写周期 tWC、tSA、tWD、thD。图中另有两个读周期参数，下标较小，读作 tEQ、tGQ，未确认。
- DRAM（p78–80）：行选通 RAS、列选通 CAS、行地址/列地址、行地址锁存器、列地址锁存器、刷新计数器（刷新行地址发生器）、刷新周期。
- CPU 侧：MREQ（访存，低有效）、R/W、A15–A0、D15–D0（习题 7，p122）；32 位 CPU 不送 A1、A0，改送字节允许 BE3–BE0（p86、p99）。
- 译码器：教材图 3.8 画成“3-8 译码”方框，文字称“三-八线译码器”（p77）；解析书写“2:4 译码器”“3:8 译码器”，并出现 74LS139、74LS138（解析书 p52–53）。教材正文没有出现 74138 型号。

### 并行存储器（p97–98）

- T：模块存取一个字的存储周期；τ：总线传送周期；m：交叉模块数。
- 式(3.1) T ≤ mτ；m_min = T/τ 称交叉存取度。
- 式(3.2) 交叉方式连续读 m 个字：t1 = T + (m−1)τ。式(3.3) 顺序方式：t2 = mT。
- 例 3.3 记号：信息总量 q，数据传输率 W1 = q/t1（交叉）、W2 = q/t2（顺序），单位 Mbit/s；解析书写“位/s”。

### cache（p100–109）

- CPU 与 cache 之间以字为单位交换，cache 与主存之间以块为单位交换（p100）。“字是 CPU 每次访问存储器时可存取的最小单位”（p102）。
- 命中 / 缺失（未命中）；命中率 h，未命中率（缺失率）1−h。式(3.4) h = Nc / (Nc + Nm)。Nc 为 cache 完成存取的总次数，Nm 为主存完成存取的总次数。
- 式(3.5) ta = h·tc + (1−h)·tm。tc 为命中时的 cache 访问时间，tm 为未命中时的主存访问时间。
- 式(3.6) r = tm/tc；访问效率 e = tc/ta = 1 / [h + (1−h)r] = 1 / [r + (1−r)h]。书中说 r 以 5～10 为宜。
- 字母大小写：教材正文用小写 h、tc、tm、ta；习题 12 用 Ta、T1、T2、H；解析书用 H、Tc、Tm、Ta。
- 行与块（p102）：cache 的数据块叫“行”，记 Li，i=0…m−1，共 m=2^r 行；主存的数据块叫“块”，记 Bj，j=0…n−1，共 n=2^s 块；每块（行）有 k=2^w 个字。
- 标记（tag）：存于 cache 行内；全相联时全部标记用相联存储器（CAM）实现。主存地址长度 = s+w 位，寻址单元数 = 2^(s+w)。
- 全相联地址格式：`标记 s 位 | 字地址 w 位`。
- 直接映射：式(3.7) i = j mod m。地址格式：`标记 s−r 位 | 行 r 位 | 字地址 w 位`。书中把主存分“区”，每区 m 块；s−r 位是区号，r 位是区内块号。
- 组相联：cache 分 u 组，每组 v 行，m = u×v，u = 2^d。式(3.8) 组号 q = j mod u。地址格式：`标记 s−d 位 | 组号 d 位 | 字地址 w 位`。组记 S0…S(u−1)，称“v 路组相联 cache”，v 典型值 2、4、8、16。
- 同一字段有两套名字：例题写“标记 / 行 / 字地址”和“标记 / 组号 / 字地址”；图 3.31(c)、3.32(c) 写“区号 / 区内块号 / 字地址”。本站应同时展示。
- 替换算法（p108–109）：最不经常使用（LFU）、近期最少使用（LRU）、随机替换。
- 写策略（p109）：写回法（write back, copy back）、全写法（write through）、写一次法（write once）。全写法写未命中分 WTWA 法（取主存块到 cache 并分配行）和 WTNWA 法（不取）。
- 行的状态信息：标记、修改位、行计数器（p109）。教材 cache 部分没有“有效位”。
- 多级 cache（p110）：缺失损失、基本 CPI、总的 CPI = 基本 CPI + 每条指令中存储器停顿的时钟周期。

### 虚拟存储器（p110–118）

- 虚地址 = 逻辑地址，实地址 = 物理地址；虚存空间（逻辑地址空间），主存空间（物理存储空间、实存）；再定位。
- 页式（p112）：逻辑页、物理页；虚地址 = `逻辑页号 | 页内地址（偏移量）`；实存地址 = `物理页号 | 页内地址`。图中物理页号一列标“主存页面号”。
- 页表表项：有效位（是否已调入主存）+ 物理页号；页表基地址存于页表基址寄存器。替换用的修改位在 p117–118。
- 内页表（虚地址→主存地址）、外页表（虚地址→辅存地址）、缺页中断（p113）；二级页表、页目录表、反向页表（p113）。
- TLB：转换后援缓冲器，又称快表；主存中的完整页表称慢表（p114）。
- 段式（p115）：虚地址 = `段号 | 段内地址（偏移量）`，正文用 s 表示段号、d 表示段内偏移量；段表表项至少有有效位、段起址、段长；地址越界中断、缺段中断。
- 段页式（p116）：`(基号 N) | 段号 S | 段内逻辑页号 P | 页内地址偏移量 D`。
- 虚存替换算法（p117）：FIFO、LRU、LFU；例 3.11 另用“FIFO+LRU 算法”。
- MMU：存储管理部件；再填充机制（table walking）（p118）。

## 算法与步骤

### (a) 存储器容量扩充（p76–77）

教材步骤：

1. 算芯片数：d = 设计要求的存储器容量 / 已知芯片存储容量，两边都写成“字数×位数”。
2. 位扩展（字数够、位数不够）：多片并行工作；地址线、控制线共用，数据线分开接。
3. 字扩展（位数够、字数不够）：多片分时工作；片内地址线、数据线、读写控制线共用，地址总线高位译码产生片选。
4. 字位扩展（都不够）：先位扩展，再字扩展。教材只有这一句话，没有例题和图（p77）。

### (b) DRAM 刷新（p79–80）

- 为什么刷新：读出是破坏性的，读后必须重写；未读写的存储元电荷会泄漏，也要定期刷新。刷新按行进行，一次刷新一整行，不送出数据。
- 自动刷新：行地址由片内刷新计数器给出，计数器宽度 = 行地址锁存器宽度；用 CAS 先于 RAS 有效启动。
- 第七版只讲两种策略，并用同一组数字说明（8192 行，刷新周期 64ms）：
  - 集中式刷新：64ms 分两段，前段正常读写，后段连续刷新 8192 行；刷新期间读写暂停，存在“死时间”。
  - 分散式刷新：各行刷新均匀分布在刷新周期内，64ms ÷ 8192 ≈ 7.8μs，每隔 7.8μs 刷新一行。
- 第七版教材没有“异步式刷新”这个名称，也没有“每个存取周期后附带刷新一行、周期加倍”的旧式分散刷新。教材的“分散式”就是其他教材所说的“异步式”。
- 解析书仍用旧名称和旧参数：
  - 分析题 8（p38）：128 行、2ms 内全部刷新一遍、存储器周期 500ns，每行刷新 = 一次读 + 一次写 = 1μs；刷新开销 = 128μs / 2ms = 6.4%。
  - 设计题 7(2)（p53–54）：答“异步式刷新”，刷新间隔 = 2ms / 128 = 15.6μs，取 15μs。
- 教材没有刷新时序图，只有读/写周期时序图（图 3.11）。

### (c) 多模块交叉存储器（p96–98）

步骤（例 3.3 的顺序）：

1. 信息总量 q = 字长 × m。
2. 顺序方式 t2 = mT；交叉方式 t1 = T + (m−1)τ。
3. W2 = q/t2，W1 = q/t1。

例 3.3（p98）：m=4，字长 64 位，T=200ns，τ=50ns。q=256bit；t2=800ns，t1=350ns；W2=320Mbit/s，W1=730Mbit/s。730 是 731.4 取两位有效数字；解析书写 73×10^7 位/s。

本站自拟小例：m=4，字长 32 位，T=120ns，τ=30ns。q=128bit；t2=480ns，t1=210ns；W2≈267Mbit/s，W1≈610Mbit/s。先核对 T ≤ mτ（120 ≤ 120）。

地址分配（图 3.23）：32 字、4 模块、每模块 8 字，5 位地址。顺序方式高 2 位选模块、低 3 位选字；交叉方式低 2 位选模块、高 3 位选字。

### (d) cache

**替换算法（p108–109）**：教材只给文字规则，没有数值例题。

- LFU：每行一个计数器；新行调入后从 0 计数，每访问一次该行计数器加 1；替换时换出计数值最小的行，同时把这些候选行的计数器都清零。
- LRU：每行一个计数器；每命中一次，命中行计数器清零，其他各行加 1；替换时换出计数值最大的行。
- 2 路组相联的 LRU：每组一个二进制位。A 行装入新数据置 1，B 行装入新数据置 0；替换时为 0 换出 A，为 1 换出 B。
- 随机替换：从候选行中随机取一行。直接映射不需要替换算法，直接换出该行。
- 解析书选择题 18（p32）：速度最快的是随机替换，命中率最高的是 LRU。

**写策略（p109）**：

| 策略 | 写命中 | 写未命中 | 修改位 |
|---|---|---|---|
| 写回法 | 只改 cache；该行被换出时才写回主存 | 先把主存块调入 cache 分配一行，再改；主存留到换出时写 | 每行一个，换出时为 1 才写回 |
| 全写法 | cache 与主存同时写 | 直接写主存；WTWA 取块到 cache，WTNWA 不取 | 不需要 |
| 写一次法 | 与写回法基本相同，但第一次写命中时同时写主存 | 与写回法基本相同 | 教材未单独说明，按写回法应有 |

**多级 cache（例 3.8，p110）**：时钟 5GHz（0.2ns/周期），基本 CPI=1.0，访问主存 100ns，一级缺失率 2%，二级访问 5ns，访问主存的缺失率降为 0.5%。步骤：主存缺失损失 = 100/0.2 = 500 周期；只有一级时 CPI = 1.0 + 2%×500 = 11.0；二级缺失损失 = 5/0.2 = 25 周期；两级时 CPI = 1 + 2%×25 + 0.5%×500 = 4.0；性能比 11.0÷4.0 ≈ 2.8。

解析书分析题 15（p41）用另一模型：Ta = 1T×0.95 + (1T+10T)×0.05×0.5 + (1T+10T+100T)×0.05×0.5 = 4T，访问时间逐级累加。

### (e) 虚拟存储器

**页式地址变换（p112，图 3.33）**：

1. 把虚地址分成逻辑页号和页内地址。
2. 页表基地址 + 逻辑页号，索引页表得到表项。
3. 查有效位；为 1 则取物理页号。
4. 物理页号与页内地址拼接成实存地址。

**段式变换（p115，图 3.35）**：按段号 s 取段表第 s 项；有效位为 0 产生缺段中断；有效位为 1 时比较段内偏移量 d 与段长，超出产生地址越界中断；否则段起址 + 段内偏移量 = 主存实地址。这里是相加，不是拼接（习题 27 专门问这一点）。

**段页式变换（例 3.10，图 3.36，p116–117）**：基号 C → 基址寄存器得段表基址 SC；SC + 段号 S(=1) 得页表起始地址 b；b + 页号 P(=2) 得物理页号 10；物理页号与页内地址拼接。

**页面替换列表法（例 3.11，p118；解析书分析题 18，p43）**：

- 表格布局：第一行是页面访问序列；下面三行是页框 a、b、c；第四行在命中的列写“命中”；最右一列写命中率。命中的页号加圈。
- 约定：主存 3 个页面，“a 进 c 出”的 FIFO 队列。新页进 a，原有页依次下移，从 c 换出。
- FIFO 算法：命中时队列不动。
- FIFO+LRU 算法：命中时把该页移到 a 位置，其余页下移。它的替换顺序与常规 LRU 相同。
- 例 3.11 的序列是 0、1、2、4、2、3、0、2、1、3、2：FIFO 命中 2 次，2/11=18.2%；FIFO+LRU 命中 3 次，3/11=27.3%。书中指标是“命中率”，不是缺页次数。

**选择题反复考的知识点**（解析书 p31–35）：

- 分级存储的目的；存储周期的定义；存取时间不是“连续两次读操作的最小间隔”。
- cache 的目的是解决速度匹配；cache 功能全部由硬件实现；cache 不与主存统一编址。
- 影响命中率的因素：块大小、组织方式、容量、程序行为；与主存存取时间无关。
- 三种映射的名称；随机替换最快，LRU 命中率最高。
- 闪存是只读存储器；NOR 可随机读出，NAND 不能；SDRAM 是易失性存储器；DDR SDRAM 采用差分时钟。
- 虚存由主存–辅存两级组成，目的是扩大存储空间并自动管理调度；地址映射由操作系统完成；MMU 是虚实地址转换的核心部件。
- “多级存储体系由 cache、主存和虚拟存储器构成”是错误说法（应为 cache、主存、外存）。
- 段页式的特点：空间浪费小、共享容易、保护容易、能动态连接。
- 鲲鹏 920：L1/L2 私有，L3 数据块不私有，L3 是组相联而不是全相联。

**设计题结构：ROM+RAM 混合、地址空间分配、与 CPU 连线**

三道同型题：教材习题 7（p122）、解析书设计题 3（p50–52，图 3.16）、设计题 4（p52–53，图 3.17、3.18）。

题面给出：

- CPU 信号：地址总线 A15–A0、数据总线 D15–D0、R/W（高读低写）、MREQ（低有效）。
- 已有 ROM 区的地址范围；RAM 芯片规格和控制端（CS、WE）；RAM 区容量和起始地址；有时给多种芯片让学生挑。

要求：(1) 画地址译码方案；(2) 把 ROM、RAM 与 CPU 连接，说明选哪些芯片、各多少片。

解析书的解题顺序：

1. 画地址空间分布图：一列方框，左侧标起止地址，框内写 ROM/RAM，右侧写大小。
2. 把空间按相同大小分组（设计题 3、4 都以 8K 为一组），算出组内地址线（8K → A12–A0）。
3. 每组内做位扩展：两片 8K×8 位并联成 8K×16 位，一片接 D15–D8，一片接 D7–D0。
4. 选译码器：组数不超过 4 用 2:4 译码器（图 3.16 标 74LS139，输入 A14、A13），否则用 3:8 译码器（图 3.18 标 74LS138，输入端 A、B、C 分别接 A13、A14、A15）。
5. MREQ 接译码器使能端。
6. 译码输出接各组 CS：图 3.16 中 Y0 接 ROM，Y1、Y2 各接一组 RAM，Y3 空；图 3.18 中 Y0 接 ROM，Y1–Y3 各接一片 8K×16 RAM。
7. 不足一组的小芯片加门电路做局部译码：设计题 4 最高 2K 区用 2K×16 位芯片，Y7 经非门后与两条地址线一起进与非门，输出接该片 CS。按地址范围 F800H–FFFFH 推算这两条线应为 A12、A11；图中连线较密，未确认。
8. CPU 的 R/W 接 RAM 的 WE；ROM 只读，不接 R/W。

设计题 4 的地址用十进制给出（0–8191 ROM，8192–32767 RAM，中间 30K 空，最高 2K RAM），选片结果为 ROM 8K×16 位 1 片、SRAM 8K×16 位 3 片、2K×16 位 1 片。

教材习题 7 自行推算：ROM 占 0000H–3FFFH；RAM 为 40K×16 位，用 8K×8 位芯片共 10 片，分 5 组；起始 6000H，占 6000H–FFFFH；4000H–5FFFH 空。A15–A13 进 3:8 译码器，Y0、Y1 对应 ROM，Y2 空，Y3–Y7 对应 5 组 RAM。

常见错误：

- 地址空间图的起止地址算错（8K = 2000H，16K = 4000H，40K = A000H）。
- 译码器输入位选错，或组内地址线位数与芯片字数不符。
- 漏接 MREQ；把 R/W 接到 ROM；小容量芯片未做局部译码，造成地址重叠；位扩展时两片数据线接到同一位段。

## 与通用讲法的差异

1. **cache 地址以“字”为最小单位**。教材定义块由若干字组成，最低字段叫“字地址 w”，不叫块内偏移或字节偏移。例 3.6 按字编址；例 3.7 用“字长 1B”让字等于字节。CS:APP 式的三段（tag / set index / block offset，按字节）在教材里对应“标记 / 组号（或行）/ 字地址”。
2. **“行”与“块”分工**。cache 一侧叫“行”（Li，共 m=2^r 行），主存一侧叫“块”（Bj，共 2^s 块）；通用讲法两侧都叫 block。字母 s 表示主存块号位数，不是组索引位数；组数用 u=2^d，每组行数用 v。
3. **“区”的说法**。直接映射和组相联都先把主存分区，标记等于区号，行号或组号等于区内块号。
4. **访问效率 e = tc/ta**，并以 r = tm/tc 写成 1/[r+(1−r)h]。通用教材一般只算平均访问时间。
5. **ta = h·tc + (1−h)·tm**。未命中时只计 tm，不写成 tc + 缺失损失。习题 22 和解析书分析题 15 又采用逐级累加模型，做题时按题面文字判断。
6. **没有有效位**。教材的 cache 行只有标记、修改位、行计数器；解析书分析题 20 的答案却算了 1 位有效位。
7. **“修改位”就是脏位**；教材不用“脏位”一词。
8. **写策略三种**，多出“写一次法”；写分配只以 WTWA/WTNWA 出现在全写法下，写回法默认写未命中时调入。
9. **替换算法以计数器规则描述**，LFU 排在 LRU 前；LFU 在替换时把候选行计数器清零；cache 部分没有 FIFO。
10. **没有缺失分类**，也没有 cache 访问序列的例题。
11. **组相联脚注**（p106）：提到另一种主存和 cache 都分组的映射方式，教材不采用。
12. **刷新只有集中式和分散式**，教材的“分散式”等于别处的“异步式”；典型数字是 64ms、8192 行、7.8μs，不是 2ms、128 行。解析书仍用旧名称和旧数字。
13. **页面替换用“a 进 c 出”队列表**，页面在三行之间下移，而不是页框固定、只改被替换的那一格；指标是命中率；“FIFO+LRU”是教材特有的名称。
14. **TLB 称“转换后援缓冲器”**（快表），页表称慢表；“同时查快表和慢表”。
15. **段页式地址有可选的“基号”字段**。
16. **交叉存储器**用 T、τ、m 和“交叉存取度”，带宽题按“连续读 m 个字”计算。
17. **容量写法**“字数×位数”，K、M 直接作 2^10、2^20 的乘数（2048K×8 位）。

1. **为什么 8 片芯片只要 2 位片选？** 模型：可调目标规格和芯片规格的扩充连线图，分三步点亮：位扩展成组 → 字扩展成列 → 高位地址进译码器；点任一地址，显示被选中的组和片内地址。 练习：算芯片数、每组片数、片选位数、各组地址范围；补全框图连线。
2. **ROM 在 0000H–3FFFH，RAM 从 6000H 开始，译码器该接哪几根地址线？** 模型：左边地址空间条形图，右边 CPU、译码器、芯片；拖动区域边界时译码输入和 Y 输出随之变化；含 MREQ 使能和小芯片的门电路局部译码。 练习：给地址空间分配，写译码输入位和每个 Y 输出的去向；给一个地址，判断哪片被选中。
3. **同一个地址，三种映射各切成哪几段？** 模型：一条二进制地址带，三种映射下分隔线移动；字段同时标“标记 / 行或组号 / 字地址”和“区号 / 区内块号 / 字地址”；可切换按字或按字节。 练习：由容量参数求 w、r、d、s 和标记位数；把十六进制地址拆成字段（例 3.5–3.7 型）。
4. **主存块 j 会落到 cache 的哪一行，为什么会被换出？** 模型：主存分区图加 cache 行表，逐次访问显示 i = j mod m 或 q = j mod u、标记比较、命中或换入；可切换直接映射和 2 路组相联，可选 LRU、LFU、随机。 练习：访问序列填命中/缺失表，求 h；找两个映射到同一行但标记不同的地址。
5. **h、ta、e、r 之间怎么互相求？** 模型：四个量的关系图，输入 Nc、Nm、tc、tm 后按例 3.4 顺序逐步出数；拖动 h 观察 e 的变化。 练习：正向求 e 和 ta；由 ta 反求 h；由 h 和 r 求 e。
6. **FIFO 和 FIFO+LRU 的表格每一列怎么填？** 模型：“a 进 c 出”三行表，逐列推进，页面下移有动画；命中时 FIFO 不动、FIFO+LRU 上移到 a。 练习：给序列和页框数，填表并求命中率或缺页次数、淘汰页号；给字地址序列先换成页号。
7. **虚地址 0AC5H 怎么变成物理地址？** 模型：地址带按页大小切分，页号指向页表行，检查有效位，物理页号与页内地址拼接；可切换十六进制和十进制输入；可加 TLB 一层。 练习：页式变换；缺页判断；有 TLB 时的有效访问时间。
8. **段式为什么是相加，段页式要查几次表？** 模型：段表（有效位、段起址、段长）加加法器和越界比较；段页式的两级查表，带访问方式检查。 练习：填物理地址或写出段错误、页面错误、保护错误（解析书分析题 31 型）。
9. **交叉存储器读 4 个字为什么是 T+3τ？** 模型：图 3.25 式的时间条，可调 m、T、τ；顺序和交叉上下对照；T > mτ 时提示冲突。 练习：求两种方式的带宽；判断给定 m 是否满足 T ≤ mτ。
10. **TLB、页表、cache 三处缺失，哪些组合不可能？** 模型：一次访存的流程图，三个开关分别设命中或缺失，不可能的组合显示理由。 练习：判断组合是否可能并说明原因（例 3.9 型）。
11. **集中式和分散式刷新，哪段时间不能读写？** 模型：64ms 时间轴，两种策略下刷新时隙的分布；可调行数和周期。 练习：求刷新间隔和刷新开销；旧名称“异步式”的对照题。
12. **0x1234 在大端和小端内存里各怎么放？** 模型：寄存器到内存字节的连线图，切换端模式；支持 16 位和 32 位数。 练习：填各地址的字节值；由内存内容还原数值。
13. **写命中、写未命中时，cache 和主存谁被改？** 模型：一行 cache 和对应主存块，三种写策略下逐步显示数据和修改位的变化。 练习：概念判断；按策略数写主存的次数。
14. **加了二级 cache，CPI 从 11 降到 4 是怎么算的？** 模型：CPI 堆叠条（基本 CPI + 一级停顿 + 二级停顿），可调缺失率和损失。 练习：求总 CPI 和性能比；三级累加模型的平均访问时间。
