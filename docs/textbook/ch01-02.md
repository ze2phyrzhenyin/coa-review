## 第1章要点（短）

**性能公式（例1.1，p14–15）**，记号照抄教材：I_N 指令总数，t_CPU 程序 CPU 时间，T 时钟周期，f 时钟频率，N_C 时钟周期数，CPI_i / I_i 第 i 类指令的平均周期数 / 执行次数，n 指令种类数。

- CPU 执行时间＝CPU 时钟周期数×CPU 时钟周期长（p14）
- t_CPU = N_C × T = N_C / f = I_N × CPI × T = (Σ CPI_i × I_i) × T
- CPI = N_C / I_N = Σ (CPI_i × I_i / I_N)
- MIPS = I_N / (t_CPU × 10^6) = f / (CPI × 10^6)
- N_C = Σ (CPI_i × I_i)
- FLOPS 单位：MFLOPS 10^6、GFLOPS 10^9、TFLOPS 10^12、PFLOPS 10^15（p14）

例1.2（p15）给出标准写法：50 MHz，四类指令（数目/周期数），求得 CPI=1.55（周期/指令），MIPS≈32.26（百万条指令/秒），t_CPU = 31×10^-4 (s)。结果保留 2–3 位小数、带单位。习题16（p21）是同型题（400 MHz，解析 p6 的答案：CPI=1.776，MIPS=225.225，575 μs）。
教材第1章没有 Amdahl 定律、没有"加速比"公式，也没有性能比较的"A 比 B 快 n 倍"题型。

**层次结构（1.6.4，p18–19）**，五级，自下而上：第1级 微程序设计级（逻辑电路级）；第2级 一般机器级（机器语言级）；第3级 操作系统级（混合级）；第4级 汇编语言级；第5级 高级语言级。第1–3级用二进制语言，第4、5级用符号语言。1、2 级是硬件级。

**其他定义**：存储容量、单元地址、字/字节/字长、数据字/指令字（p8、p10）；取指周期/执行周期（p10）；取指周期读出的是指令流（流向控制器），执行周期读出的是数据流（流向运算器）（p10）；CPU = 运算器+控制器（p10）；硬件 = 运算器、存储器、控制器、适配器、总线、输入/输出设备（p11）；系统软件四类：服务性程序、语言类程序、操作系统、数据库管理系统（p12、p21）；计算机组成 = 系统结构的逻辑实现，计算机实现 = 组成的物理实现（p20）。

**可考内容（依据解析第1章 24 道选择、20 道填空、3 道分析，p1–6）**：
- 选择/填空大量是记忆题：五代年份与器件、Intel 芯片年份、摩尔定律、国产处理器架构、测试基准侧重点、冯·诺依曼特点、层次结构各级名称、硬件六部件、指令流/数据流、利用率/CPI。
- 分析题只有三种：(1) 主频→时钟周期→机器周期→平均指令周期→MIPS 的互算；(2) 用 CPI 差值反推被替换的指令条数；(3) 给指令混合表求平均 CPI、MIPS、执行时间。
- 教材习题 1–14 是简答，15 是动手测基准，16 是计算。

## 记号与约定

### 位编号与小数点（有两套，必须都支持）
- 教材 2.1 的约定：n+1 位字，x = x_n x_{n−1}…x_1 x_0，**x_n 是符号位（最左），x_0 是最低位**（p23）。纯小数时小数点在 x_n 与 x_{n−1} 之间，范围 0≤|x|≤1−2^-n（式2.1）；纯整数时小数点在 x_0 右边，范围 0≤|x|≤2^n−1（式2.2）。
- 教材明说"目前计算机中多采用定点纯整数表示，因此将定点数表示的运算简称为整数运算"（p23）。第七版的 2.1–2.3 例题几乎全是**定点整数**，写成不带小数点的串，如 x=+1001，[x]补=01001，符号位粗体（p35）。
- 但 2.4 除法改用**定点小数**，写成 x_f . x_{n−1}…x_1 x_0，如 0.10110（p49、p53）；式(2.16) 又写成 [y]补=y_0 y_1…y_n（y_0 为符号位，p36）；习题2 写 [x]补=a_7.a_6a_5…a_0（p68）。
- 解析书通篇是**定点小数、下标从高到低**：[x]补=x_0.x_1x_2…x_n，x_0 为符号位（解析 p10–12），双符号位写 11.10001（解析 p14）。
- 乘除法里符号位记 x_f、y_f，商符 q_f（p43、p49）。

### 原码（p24–25）
定点整数，形式 x_n x_{n−1}…x_1 x_0：

    [x]原 = x,                2^n > x ≥ 0
    [x]原 = 2^n − x = 2^n + |x|,   0 ≥ x > −2^n        (2.5)

[+0]原=0000…0，[−0]原=1000…0。教材没有给定点小数的原码公式。

### 补码（p25–26）
定点整数（模 2^(n+1)）：

    [x]补 = x,                         2^n > x ≥ 0
    [x]补 = 2^(n+1) + x = 2^(n+1) − |x|,   0 > x ≥ −2^n      (mod 2^(n+1))   (2.6)

定点小数（模 2）：

    [x]补 = x,               1 > x ≥ 0
    [x]补 = 2 + x = 2 − |x|,   0 > x ≥ −1                    (mod 2)        (2.7)

"式(2.7)中，可以将 −1 定义为特定的小数"（p26）。0 的补码只有一种形式。
补码→真值：x = −2^n·x_n + Σ_{i=0}^{n−1} 2^i·x_i（式2.8，p26；例2.1、2.2 用 9 位）。
解析书的小数版：x = −x_0 + Σ_{i=1}^{n} x_i·2^-i（解析 p10 证明题1）。

### 反码（p26–27）
教材只有文字定义，没有公式：正数的机器码等于真值；负数符号位为 1，数值位逐位取反。原码→补码两步规则（p27）：(1) 原码符号位为 1 不变，数值部分每一位求反得到反码；(2) 反码符号位为 1 不变，数值部分最低位加 1，得到补码。
解析书用小数公式 [x]反 = 2 − 2^-n + x（0 ≥ x > −1），并证明 [x]补=[x]反+2^-n（解析 p11–12）。

### 移码（p27）
"移码通常用于表示浮点数的阶码"。阶码是 k 位整数，移码形式 e_k e_{k−1}…e_1 e_0（最高位为符号位）：

    [e]移 = 2^k + e,   2^k > e ≥ −2^k      (2.9)

例：e=+10101 → [e]移=1,10101；e=−10101 → 0,01011。逗号只表示左边一位是符号位。移码符号位规律与原、补、反码相反；"补码值与移码值差别仅在于符号位不同"（例2.8 表，p29–30：8 位时 −127 的移码 00000001，0 的移码 10000000，+127 的移码 11111111）。
注意 2.6.1 里同一定义换了字母：[x]移=2^n+x，2^n > x ≥ −2^n（p63）。

### 由[y]补求[−y]补（p36）
"对[y]补包括符号位在内'各位取反，末位加 1'"，式(2.16)：[−y]补 = ¬[y]补 + 1（教材用带尖角的 ¬ 符号表示含符号位求反）。"若为定点纯小数，则最末位加 1 需改为加 2^-n"。

### 变形补码与溢出判断（p37–38）
- 术语：正溢（两正数相加超过最大正数）、负溢（两负数相加小于最小负数），图2.2 数轴 −2^n … 0 … +2^n。
- **第一种方法 双符号位法，即"变形补码"**：[x]补 = 2^(n+2) + x (mod 2^(n+2))；正数两个符号位 00，负数 11。两个符号位都当数码参加运算，最高符号位上产生的进位丢掉。结果符号位 01 = 正溢出，10 = 负溢出；"最高符号位永远表示结果的正确符号"。逻辑式 **V = S_f1 ⊕ S_f2**（S_f1 最高符号位，S_f2 第二符号位）。
- **第二种方法 单符号位法**："当最高有效位产生进位而符号位无进位时，产生正溢；当最高有效位无进位而符号位有进位时，产生负溢"。逻辑式 **V = C_f ⊕ C_0**（C_f 符号位产生的进位，C_0 最高有效位产生的进位）。图2.3(b) 中同一逻辑写成 C_n ≠ C_{n−1} 时溢出。
- 教材没有"一正一负必不溢出""用操作数与结果符号位比较"的第三种写法；解析分析题1 把单符号位法展开成 V = C_0 ⊕ C_1 = A_0B_0¬C_1 + ¬A_0¬B_0C_1（此处 C_0 是符号位进位、C_1 是最高有效位进位，下标含义与教材相反，解析 p21）。

### 浮点数格式
1. **一般格式**（p24）：阶符 E_s | 阶码 E_{m−1}…E_1E_0 | 数符 M_s | 尾数 M_{n−1}…M_1M_0。N = 2^e·M（式2.4），M 尾数是纯小数，e 指数是整数；机器里的指数"常称为阶码"。
2. **IEEE754**（p27–28，教材的主格式）：32 位 S(31) | E(30–23) | M(22–0)；64 位 S(63) | E(62–52) | M(51–0)。"符号位 S 和尾数域 M 组合起来可以看作是尾数的原码表示形式"；阶码"采用移码形式"。
   - x = (−1)^S × (1.M) × 2^(E−127)，e = E − 127（式2.10）；64 位偏移 1023（式2.11）。
   - 五种情况（p28）：E=255 且 M<>0 → NaN；E=255 且 M=0 → (−1)^S ∞；E=0 且 M=0 → (−1)^S 0（机器 0，有正零负零）；0<E<255 → 规格化数，E 取 1～254，e 为 −126～+127；E=0 且 M<>0 → 非规格化数 (−1)^S×(0.M)×2^-126。
   - 例2.5：(41360000)16 → 11.375；例2.6：20.59375 → (41A4C000)16。写法是先分 S、阶码(8位)、尾数(23位)三段，再"指数 e = 阶码 − 127"。
3. **非 IEEE 的 1.M 格式**：x = (−1)^S×(1.M)×2^(E−128)（例2.10，p30），问最大正数、最小正数、最小负数、最大负数。
4. **习题和解析里的教学格式**（教材正文没有专门讲码制规则）：
   - 习题3：32 位，符号 1 位，阶码 8 位移码，尾数 23 位补码（p68）。
   - 习题9、10："阶码 3 位，尾数 6 位"，数写成 2^-011×0.100101（p69），未指定码制。解析 p20 的做法：阶码用补码（如 11011），尾数用双符号位补码（如 11.110101）。
   - 解析计算29：阶码 4 位移码，尾数 8 位原码（含 1 位符号）（解析 p20–21）。
   - 解析计算30：阶码 7 位补码，尾数规格化补码；最小正尾数 0.10000000，最大负尾数 1.01111111（解析 p21），即补码尾数规格化 = 符号位与最高数值位不同。**这条"补码规格化"规则教材正文没有写**，只在解析里出现。
5. **规格化定义**（p28）："当浮点数尾数的值不为 0 时……这种形式表示的浮点数的尾数的最高有效位就是有效数字"。解析选择17：原码尾数规格化的条件是"尾数的最高数值位为 1"。
6. 运算例题的写法（例2.30、2.32，p65–67）：用 (1.xxx)2×2^e 的形式、"尾数有效位为 4 位"，溢出检查写"127 ≥ e ≥ −126"。

### 舍入（p64、p67）
- 2.6.1 讲 IEEE754 的四种：**就近舍入**（多余位 10010 → 进 1；01111 → 截尾；恰为 10000 时最低有效位为 0 则截尾、为 1 则进 1 使其变为 0）、**朝 0 舍入**（截尾）、**朝 +∞ 舍入**、**朝 −∞ 舍入**。
- 2.6.2 讲两种简单办法：**截断处理**；**舍入处理**——"当尾数用原码表示时"：(a) "只要尾数最低位为 1，或移出的几位中有为 1 的数值位，就使最低位的值为 1"（教材没有给它起名，不要自行标成"恒置 1"）；(b) **0 舍 1 入法**："当丢失的最高位的值为 1 时，把这个 1 加到最低数值位上"。
- 图2.19 有"0 舍 1 入硬件"框，图2.20 第 4 步写"将有效位 0 舍 1 入"。解析计算29 用 0 舍 1 入。教材没有补码尾数的舍入规则，没有保护位/舍入位/粘滞位的名称。

### 校验码（p33–34）

## 算法与步骤

### A. 补码加减与溢出检测（2.2.1–2.2.3）
步骤：写出 [x]补、[y]补（减法先求 [−y]补）→ 竖式相加，符号位一起参加运算 → 超出模的进位丢掉（教材把丢掉的进位画在虚线框里，p35、p37）→ 判溢出 → 还原真值。
竖式三行：`[x]补` / `+ [y]补` / 横线 / `[x+y]补`，符号位粗体，定点整数不写小数点。
走查（自拟数，变形补码）：x=+1010，y=+0111 → [x]补=001010，[y]补=000111，和=010001，符号位 01 → 正溢出。x=−1001，y=+0110 → 110111+000110=111101，符号位 11 无溢出，x+y=−0011。
解析的同型题写成小数：[x]补=11.10001，结论写"双符号位不同，结果发生溢出"（解析 p14）。

### B. 行波进位加/减法器（2.2.4）
- FA：S_i = A_i⊕B_i⊕C_i；C_{i+1} = A_iB_i + B_iC_i + C_iA_i = A_iB_i + (A_i⊕B_i)C_i（式2.19）。S_i 延迟 6T，C_{i+1} 延迟 2T（不含异或门 3T）。
- n 位加减器：M=0 做 A+B，M=1 做 A−B（B 各位与 M 异或，C_0 接 M，实现 ¬B+1）。
- 延迟 t_a = n·2T + 9T = (2n+9)T（式2.20）。16 位 = 41T。

### C. 先行进位（2.2.5–2.2.6）
- **G_i = A_iB_i**：进位产生函数（本地进位）；**P_i = A_i⊕B_i**：进位传递函数（进位条件）；P_iC_i：传送进位（条件进位）。注意 P 用异或，不是或。
- C_{i+1} = G_i + P_iC_i（式2.21）；展开（式2.23）：
  C1 = G0 + P0C0
  C2 = G1 + P1G0 + P1P0C0
  C3 = G2 + P2G1 + P2P1G0 + P2P1P0C0
  C4 = G3 + P3G2 + P3P2G1 + P3P2P1G0 + P3P2P1P0C0
- 例2.20 单级分组 16 位：P/G 产生 3T + 组间串行 4×2T + 求和 3T = 14T（串行 16 位为 41T）。
- 组间：本组进位 G3* = G3+P3G2+P3P2G1+P3P2P1G0；组间进位传递函数 P3* = P3P2P1P0；C4 = G3*+P3*C0；BCLA 公式（式2.24）给出 C4、C8、C12、C16（下标 3、7、11、15 的 G*、P*）。例2.21 两级分组 16 位。
- 习题11 / 解析分析4 的下标是 C4C3C2C1 与 G1–G4、P1–P4（从 1 起）。

### D. 原码乘法与阵列乘法器（2.3）
- 规则（式2.25）：乘积符号 = x_f⊕y_f，数值 = 两数绝对值相乘。
- **教材只给笔算式的"被加数矩阵"**：乘数从低位到高位，每位产生一行位积 a_ib_j，逐行左移一位，最后相加。**没有"部分积 / 乘数寄存器 / 操作说明"的迭代表**——"鉴于串行乘法器已被淘汰，下面只介绍并行乘法器"（p44）。
- 无符号阵列乘法器：m×n 个与门产生 a_ib_j；n 位×n 位需要 n(n−1) 个全加器和 n² 个与门；t_m = T_a+(n−1)×6T+(n−1)×T_f+3T = (8n−4)T（式2.26，T_a=T，T_f=2T）。例2.22：A=11011，B=10101，列出 25 个 a_ib_j 的值，P=1000110111（567）。
- 对 2 求补器：C_{−1}=0，C_i = a_i + C_{i−1}；a_i* = a_i ⊕ E·C_{i−1}，0≤i≤n。含义：从最右端起找到第一个"1"，该位及其右边不变，左边各位求反。E=1 求补，E=0 直通。延迟 t_TC = n·2T+5T = (2n+5)T（式2.27）。
- 带求补器的阵列乘法器（"符号求补的阵列乘法器"）步骤：算前求补（两个算前求补器，操作数为负时取绝对值）→ n 位×n 位无符号阵列相乘得 2n 位 → 算后求补（两符号不一致时把积变成补码）→ 符号位 p_2n = a_n⊕b_n 单独形成。原码乘法"算前求补和算后求补都不需要"。
- 例题答题格式（例2.23、2.24，p47–48）：写 [x]、[y] → "符号位运算：0⊕1=1" → "算前求补器输出 |x|=…，|y|=…" → 笔算竖式 → "算后求补器输出为 …" → 拼上符号位得 [x×y]原 或 [x·y]补（共 2n+1 位）→ 换算真值 → "十进制数乘法验证"。
- 走查（自拟数）：x=+1011，y=−0110。原码：|x|=1011，|y|=0110，位积行 0000 / 1011 / 1011 / 0000，和=01000010，符号 0⊕1=1，[x×y]原=101000010（−66）。补码：[x]补=01011，[y]补=11010，算前求补后同上，算后求补 01000010→10111110，[x·y]补=110111110。

### E. 原码除法（2.4.1）与加减交替法（例2.25）
- 商符 q_f = x_f⊕y_f，数值部分做两个正数相除。
- 够减判断：做 [|x|]原+[−|y|]补，"最高位无进位时结果为负；有进位时结果为正"（p50）。
- 恢复余数法：只有一段文字（不够减就把余数加上除数），**没有例题和表格**。
- 不恢复余数法（加减交替法）规则（p50）：r_i' = 2r_{i−1} − |y|；r_i' ≥ 0 时下一步"左移减除数"，r'_{i+1} = 2r_i' − |y|；r_i' < 0 时下一步"左移加除数"，r'_{i+1} = 2r_i' + |y|；最终余数为负时做"纠余"：r_n = r_n' + |y|。
- 例2.25 的版式（p53–54，单符号位、带小数点）。行标签依次是：`被除数 x` / `减 y`（加 [−|y|]补）/ `余数为负 … <0 → q0=0` / `左移` / `加 y` / `余数为正 … >0 → q1=1` / `左移` / `减 y` / … / 最后一位商为 0 时再 `加 y  恢复余数(纠余)`。结果写：商 q = q0.q1q2q3q4q5，余数 r = 0.0000 r5…r10（即最后的部分余数右移 n 位）。
- 走查（自拟，取教材 p49 笔算的数）：x=0.1001，y=0.1011，[−|y|]补=1.0101。
  0.1001+1.0101=1.1110 <0，q0=0；左移 1.1100，加 y → 0.0111 >0，q1=1；左移 0.1110，减 y → 0.0011 >0，q2=1；左移 0.0110，减 y → 1.1011 <0，q3=0；左移 1.0110，加 y → 0.0001 >0，q4=1。q=0.1101，余数 0.00000001。

### F. 阵列除法器（2.4.2）
- CAS 单元：S_i = A_i⊕(B_i⊕P)⊕C_i；C_{i+1} = (A_i+C_i)(B_i⊕P) + A_iC_i（式2.28）。P=0 加法，P=1 减法。每个 CAS 延迟 3T。
- 阵列规则（p52–53）：最上面一行固定做减法（P=1）；每行最左单元的进位输出就是该行的商位；商位反馈为下一行的 P（商 1 → 下一行减，商 0 → 下一行加）；除数沿对角线右移，部分余数保持不动。
- (n+1)位÷(n+1)位需要 (n+1)² 个 CAS，t_d = 3(n+1)²T（式2.30）。
- 解析计算16 的手算版式（解析 p17，"余数固定除数右移"）：被除数写成双倍长，逐行 `+[−y]补` 或 `+[y]补`（每步除数多右移一位），右侧注释"余数为负商 0，下步加除数""除数右移 1 位加"。

### G. 74181 / 74182（2.5.2）
- 一位 ALU：F_i = X_i⊕Y_i⊕C_{n+i}；C_{n+i+1} = X_iY_i + Y_iC_{n+i} + C_{n+i}X_i（式2.31）。
- 表2.3（p56）：S0S1=00/01/10/11 → Y_i = ¬A_i / ¬A_i·B_i / ¬A_i·¬B_i / 0；S2S3=00/01/10/11 → X_i = 1 / ¬A_i+¬B_i / ¬A_i+B_i / ¬A_i。
- 式(2.32)：X_i = ¬(S3A_iB_i + S2A_i¬B_i)；Y_i = ¬(A_i + S0B_i + S1¬B_i)；F_i = Y_i⊕X_i⊕C_{n+i}；C_{n+i+1} = Y_i + X_iC_{n+i}。
- 片内先行进位：C_{n+4} = G + PC_n（式2.33），G = Y3+Y2X3+Y1X2X3+Y0X1X2X3，P = X0X1X2X3。
- M=0 算术操作，M=1 逻辑操作（封锁进位）。表2.4（p58）正逻辑 16 行，列为"逻辑运算 M=1"和"算术运算 M=0，C_n=1（无进位）"，按 S3S2S1S0：

  做减法需在最末位加强迫进位才得到"A 减 B"。
- 74182（式2.34）：C_{n+x} = G0+P0C_n；C_{n+y} = G1+G0P1+P0P1C_n；C_{n+z} = G2+G1P2+G0P1P2+P0P1P2C_n；C_{n+4} = G*+P*C_n，P* = P0P1P2P3（成组进位传送输出），G* = G3+G2P3+G1P2P3+G0P1P2P3（成组进位发生输出）。

### H. 浮点加减（2.6.1）
规则：z = x±y = (M_x·2^(E_x−E_y) ± M_y)·2^(E_y)，E_x ≤ E_y（式2.35）。教材说"大体分为四步"，但小标题列了六项，顺序和名称：
1) 0 操作数检查；2) 比较阶码大小并完成对阶（ΔE = E_x−E_y，**小阶向大阶看齐**，小阶的尾数右移，每右移一位阶码加 1）；3) 尾数加减运算；4) 结果规格化（尾数为 01.x…x 或 10.x…x 时**向右规格化**：尾数右移 1 位，阶码加 1；IEEE754 形式不是 1.M 时**向左规格化**）；5) 舍入处理；6) 溢出处理（阶码上溢 → ±∞；阶码下溢 → 0；尾数上溢 → 右移、阶码增 1；尾数下溢 → 舍入）。
移码阶的加减：[x+y]移 = [x]移+[y]补 (mod 2^(n+1))（式2.36），[x−y]移 = [x]移+[−y]补（式2.37）；双符号位阶码加法器，移码高符号位恒为 0，结果符号位 00 负（无溢出）、01 正（无溢出）、10 正溢出、11 负溢出（表2.5，p63）。
例2.30 的五步标题：第 1 步 对阶；第 2 步 尾数相加；第 3 步 规格化；第 4 步 检查上溢或下溢；第 5 步 舍入操作；末尾"十进制数验证"。
走查（自拟数，4 位有效位）：x=0.75=(1.100)2×2^-1，y=−0.3125=−(1.010)2×2^-2。对阶 y=−(0.101)2×2^-1；尾数相加 (0.111)2×2^-1；规格化 (1.110)2×2^-2；−126≤−2≤127 无溢出；无需舍入；结果 0.4375。
解析的教学格式版本（计算29，解析 p20–21）标题：(1) 0 操作数检查 (2) 比较阶码大小，进行对阶，小阶向大阶看齐 (3) 尾数求和 (4) 结果规格化 (5) 舍入处理。

### I. 浮点乘除（2.6.2）
x×y = 2^(E_x+E_y)·(M_x×M_y)（式2.38）；x÷y = 2^(E_x−E_y)·(M_x÷M_y)（式2.39）。六步：第 1 步 0 操作数检查（被除数为 0 商为 0，除数为 0 商为 ∞）；第 2 步 阶码加/减操作；第 3 步 尾数乘/除操作；第 4 步 结果规格化；第 5 步 舍入处理；第 6 步 确定积的符号。
例2.32（p67）实际写了五步：指数相加（−1+(−2)=−3，移码 −3+127=124）→ 尾数相乘（笔算竖式 1.000×1.110）→ 规格化与溢出检查 → 舍入到 4 位有效数字 → 确定积的符号。没有二进制浮点除法的例题，只有十进制的例2.33。

## 与通用讲法的差异

1. **整数和小数混用**。第七版正文把定义和加减乘改成了定点整数，但除法、习题2、解析全书仍是定点小数（0.1011、11.10001）。同一算法要能用两种写法显示；位下标也有两套（x_n 为符号位 / x_0 为符号位）。旧版残留：例2.14（p36）对整数写了"+2^-4"。
2. **变形补码是首选的溢出判别法**，习题5、6 明确要求"用变形补码计算"。CS:APP 式的"符号位比较"不是教材写法；教材的两个逻辑式是 V=S_f1⊕S_f2 和 V=C_f⊕C_0。
3. **乘法只讲阵列乘法器**。没有移位-加迭代，没有部分积寄存器表，没有 Booth。带符号乘法是"算前求补 → 无符号阵列 → 算后求补"。答题是笔算位积矩阵。
4. **除法是原码加减交替法 + CAS 阵列除法器**，操作数是正小数，要求 |x|<|y|；整数题要先乘比例因子化成小数。商的位数 = n+1 步（q_0…q_n），余数要乘 2^-n。没有补码除法，没有 RISC-V 式的 64 位余数寄存器移位图。
5. **进位传递函数 P_i = A_i⊕B_i**，不是 A_i+B_i。延迟按 T/2T/3T 的门级模型计算，这类延迟估算题在通用教材里少见。
6. **74181/74182 是 ALU 的全部内容**：X_i/Y_i 函数发生器、S3–S0 与 M 的功能表、正逻辑、C_n=1 表示无进位。没有 MIPS/RISC-V 式的一位 ALU 加 ALUOp 的讲法。
7. **移码有两种**：2.1.2 的移码偏移是 2^k（8 位时 128，与补码只差符号位）；IEEE754 的偏移是 2^7−1=127。例2.10 故意用 E−128 的非 IEEE 格式。移码运算要"移码+补码"，并有专门的双符号位溢出表（表2.5）。
8. **浮点例题是两种风格并存**：正文例题用 P&H 式的 (1.xxx)2×2^e、4 位有效位、127≥e≥−126；习题9、10 和解析用"阶码 3 位、尾数 6 位"的纯小数尾数，解析按补码阶+双符号位补码尾数做，另有移码阶+原码尾数的题。左规/右规、小阶向大阶看齐、0 舍 1 入是必须出现的术语。
9. **舍入**：IEEE 四种方式只做文字介绍；计算题实际用 0 舍 1 入或直接截断。没有 guard/round/sticky。
10. **0 操作数检查是独立的第一步**，流程图里还有"对阶时尾数移成 0 则结果取另一数"的分支。
11. **图2.18 的端点值**（(2−2^-23)×2^128、2^-127）与 p28 的规格化范围（E 取 1～254，e 为 −126～+127）不一致，做范围题时以 p28 的文字为准，图只用于说明上溢/下溢分区。
12. **校验码只有奇偶校验**，且例题把校验位放在最低位。
13. **第1章**性能部分只有 CPI、MIPS、t_CPU 三个量的互算，没有 Amdahl 定律和 SPEC 比值计算；层次结构是白中英的五级（微程序设计级在最底层），不是"数字逻辑-微体系结构-ISA-OS-汇编-高级语言"的六级。
14. 教材自身的笔误（做页面时别照抄）：p38"从例 2.17 和例 2.18 中看到"实指例2.16、2.17；p50"将[|x|]原连同符号位…"应为 y；p50"部分余数左移加余数操作"应为加除数；例2.31（p66）"0.3×2^(2−3)"应为 10^(2−3)。

1. **加减交替除法**。困惑："余数为负为什么不恢复，下一步反而加？最后的余数为什么还要乘 2^-n？" 模型：例2.25 版式的逐行走查（被除数/减 y/余数正负/上商/左移/加减 y/纠余），可切换到图2.10(b) 阵列视图，高亮每行的 P 和商位。练习：习题8 型，给 x、y 求商和余数。

3. **变形补码加减与溢出**。困惑："01 和 10 哪个是正溢？进位丢掉算不算溢出？" 模型：双符号位竖式，逐位进位，同时显示 V=S_f1⊕S_f2 与 V=C_f⊕C_0 两个判别结果，数轴上标出结果落点。练习：习题5、6 型。
4. **IEEE754 转换器**。困惑："隐藏的 1 去哪了？E 是加 127 还是 128？" 模型：32 位位条分 S/E/M 三段，十进制 ↔ 二进制 ↔ 1.M×2^e ↔ 十六进制 四栏联动，另有五种特殊情况表。练习：习题4、12、13 型，加非 IEEE 格式（E−128）的极值题。
5. **带求补器的阵列乘法**。困惑："补码相乘为什么先变绝对值？算后求补什么时候做？" 模型：图2.9 的数据流（算前求补器 → 位积矩阵 → 算后求补器 → 符号位），位积矩阵逐行出现；可点开图2.7 的 FA 阵列看进位走向和最长路径。练习：习题7 型，原码法与补码法各做一遍并十进制验证。
6. **原码/反码/补码/移码对照**。困惑："−128 为什么只有补码？补码和移码只差符号位是什么意思？" 模型：8 位滑块，四种码同步显示，配例2.7 的数轴；整数/小数视图切换，显示式(2.5)–(2.9) 对应的分支。练习：习题1、2 型和选择题的码值比较。
7. **先行进位与延迟估算**。困惑："C4 的式子怎么展开？14T 和 41T 是怎么数出来的？" 模型：4 位 G/P 表 + C1–C4 逐级展开；16 位行波、单级分组、两级分组三种结构并排，按 T/2T/3T 模型点亮最长路径并累加。练习：习题11 型和延迟计算。
8. **对 2 求补器与 [−y]补**。困惑："'从右往左找到第一个 1'和'取反加 1'为什么是一回事？" 模型：图2.8 的或门链逐位扫描，对照取反加 1 的竖式。练习：求 [−y]补、原码转补码（解析设计题2）。
9. **浮点格式的表示范围**。困惑："最大负数和最小负数分别是哪个？补码尾数规格化的边界在哪？" 模型：可配置格式（阶码位数与码制、尾数位数与码制、是否规格化），数轴上标出四个极值和上溢/下溢区。练习：习题3、14 型，解析计算5、6、30 型。
10. **74181 功能表**。困惑："S3–S0 怎么决定运算？A 减 B 为什么要 C_n 配合？" 模型：选择 S3–S0、M、C_n，显示 X_i、Y_i（表2.3）和 4 位运算结果，对照表2.4 的那一行。练习：习题16 型（给 8 种功能写控制码）、解析分析题3 型（由逻辑图填功能表）。
11. **浮点乘除五步**。困惑："移码阶相加为什么要减偏移量？" 模型：图2.20 流程逐框执行，阶码用移码+补码相加并显示表2.5 的溢出判别。练习：习题10 型。
12. **CPI / MIPS / 执行时间计算器**（第1章）。困惑："CPI 是加权平均，权是什么？" 模型：指令混合表（类型、条数、周期数）可编辑，逐步代入例1.1 的四个式子。练习：习题16 型、解析分析题1（主频→机器周期→MIPS）。
13. **三种运算器结构的数据通路**。困惑："单总线为什么要三步，三总线为什么一步？" 模型：图2.16 三张图，按步播放一次 R1+R2→R3 的传送。练习：简答与习题15 的框图题。
14. **奇偶校验**。困惑："奇校验位到底取 0 还是 1？" 模型：8 位数据逐位异或，生成校验位，再翻转一位演示 F=1。练习：例2.11 型填表、解析选择11。
